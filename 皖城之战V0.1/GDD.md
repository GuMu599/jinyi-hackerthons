# 皖城之战游戏项目：前期设计总览

**状态：** 两部分五章、八项主线任务的设计稿；待原型验证 · **更新：** 2026-11-23 · [内容索引](#feature-index) · [设计决定](#decisions) · [变更记录](#change-log)

## 已确定的起点

以建安十九年（214）**孙权攻朱光所守皖城**为历史背景。剧情只分**速攻、先登**两部分。开场固定为陈安受伤倒在清晨战场，听见战友与父母呼名、想起家中温暖片段，再看见血与旗、挣扎起身。此时玩家接手，任务一是读懂旗号、与运送队伍汇合；到队后才得知小车卡点与清路分工。后续按史实行动推进：孙权采纳吕蒙四面速攻；甘宁在前登城，吕蒙率精锐跟进击鼓；吴军食时破城，张辽到夹石闻败而退。陈安、丁进只亲历其中局部，玩家通过旗、鼓、地形和同伴反应完成本队任务。两人的个人遭遇与局部战斗均为虚构，水路不进入剧情。[史实清单](../皖城之战-史实清单.md) · [完整剧情](story/皖城之战-完整剧情与关卡章节.md) · [史实剧情玩法节拍](levels/速攻与先登-史实剧情玩法.md)

**核心体验：** 玩家作为普通士兵，观察旗、鼓、地形、同伴和近敌，判断方向与行动时机，再通过搬运、掩护、近身交战、架梯和攀登完成本队任务。进展由车能走、通路能过、梯具能用、后队能上等可见结果确认；人物关系与战争知识在这些行动中展开。

| 部分／章节 | 视角与主线任务 | 本章的承接作用 |
| --- | --- | --- |
| 速攻·第一章《陈安》 | 陈安；**任务一：读懂旗号，与运送队伍汇合** | 战场倒地、家庭记忆、认旗起身；归队后才知道运送任务与车轮卡点 |
| 速攻·第二章《车轮》 | 陈安；**任务二：抽出牵绳、移开木料，让车脱困** | 同伍掩护下清卡点、初次交手；车仅脱困，仍须送往前方 |
| 速攻·第三章《送过去》 | 陈安；**任务三：跟着横纹旗，把器材车送到前方待命队伍处**；**任务四：清开通向城墙的进路** | 玩家控制车的行进方向；同伍伤亡改变分工。车到位停稳先结算任务三，随后清障；陈安交战中受致命伤，仍打开通路后牺牲 |
| 先登·第四章《城下接力》 | 丁进；**任务五：和徐直把梯具抬到指定城墙下**；**任务六：立起梯具，稳住梯脚** | 无名视角与呼名仅作任务前的剧情过渡；操作从任务五开始。认出同一辆车、通过陈安清出的路；箭雨救人冲突发生在抬梯途中 |
| 先登·第五章《先登》 | 丁进；**任务七：沿梯攀上城墙**；**任务八：清出梯口，接应徐直和后续队伍** | 玩家持续攀爬、应对落石与坠落者，上墙后还须让后继站住；任务八后接城破、抬伤兵与战史尾声 |

**四面并攻贯穿任务。** 陈安运车时看见别队沿城外分路，先埋伏笔；丁进抬梯时听清“四面并攻”的传令，架梯前亲见部分守军被邻近攻势牵走，抓住空隙立梯；登墙接应时再收到另一面登墙的消息。别处的进攻实际影响眼前的任务机会，完整议策由战后史料补足。[四面并攻与任务](levels/速攻与先登-史实剧情玩法.md#四面并攻怎样进入任务)

**任务与结局。** 八项任务连续编号，各有明确军令、弹出时机、玩家动作与完成条件；无名视角、身份揭晓和战后短场不另计任务。车未到位、通路未开或攀登失败时可重试相应任务段；陈安完成清路后的剧情牺牲不判为操作失败。丁进以本方梯口能持续接应后继为最后目标，皖城被攻破的历史结果固定。逐项条件见[任务操作草案](levels/速攻与先登-史实剧情玩法.md#陈安四项任务的操作草案)。

## 史实与创作边界

- **战役骨架按史料：** 214 年孙权攻朱光所守皖城；吕蒙主张四面速攻，孙权采纳；甘宁督攻在前，吕蒙率精锐跟进并执鼓；侵晨进攻、食时破城，朱光被获；张辽至夹石闻城破而退。出处和正文、裴注的区别见[史实清单](../皖城之战-史实清单.md)。
- **普通兵经历是创作：** 陈安、丁进及同伍、家人、全部对白、营中回忆、清路送车、局部掩护与伤亡、梯具、滚石、战友坠落和具体登城路线均没有此役个体记录。它们是游戏剧情，不是皖城战况复原。陈安这队按[《汉官旧仪》所载五人为伍](https://zh.wikisource.org/zh/漢官舊儀_(四庫全書本)/卷下)编为伍长、吴成、赵平、无名推车兵、陈安；这不证明214年皖城吴军小队的实际编制，横纹旗也属虚构的较大队列旗号。陈安设为吴郡吴县治所附近人，家中乡音以今天的苏州话为配音参考；214年的实际口音不可由现代方言直接复原。两名主角只知道亲见、接令或战后听到的事；局部旗号、鼓声的可闻范围和传令过程也由本作设定。
- **不能补成既定史实：** 现有材料未记兵力、城门、墙高、城下地形、首登人数或具体器材。诸将议筑土山和增造攻具，不等于实际建成；甘宁“手持练”不证明用了丁进的梯具；地图不证明吴军的精确水路。215 年合肥之战不能作此次前情，也不安排张辽在皖城城下交战。
- **四面并攻的呈现：** [裴注《吴书》](https://ctext.org/text.pl?if=en&node=604229&show=parallel)有“以三军锐气，四面并攻”的记载。将其理解为多向施压、牵制守军调动，是本作的战术解释；陈安见分路、丁进听军令、架梯时守军分人、另一面登墙的传报均为创作。四面各部指挥、兵力、具体城门与进展先后未知，不补造为史实。小兵只能亲见附近，其他方向由传令获知；陈安清出的路服务本队，不设为全军四面进攻的唯一通路。

- **“收拾调理”的用语参照：** [明代戚继光《练兵实纪》卷八“第十二恋伤害”](https://www.shidianguji.com/book/SK1398/chapter/1jzz9oy2thctv)要求交战士卒继续向前，待击败敌人后再处置伤兵，其中有“杀了贼便可收拾调理”。在这一语境中可释为收拢、救治和安置伤兵。徐直在箭雨中说出此词是编剧借意改写，不能作为214年吴军军令、术语或救护制度的证据；科普注释须标明明代出处。箭雨、丁进想扶伤者、徐直催行和战后共同抬人，均为本作虚构。

其他剧情与关卡文档以链接本节为主，只在具体设计判断处保留简短的史料提示；需要核对出处时，再查[史实清单](../皖城之战-史实清单.md)和[前线视角史料边界](story/前线视角史料边界.md)。

## 设计原则

1. **先定历史边界。** 历史人物的参战与指挥关系、战役顺序、结果依史料；虚构士兵的人物关系、个人经历与未知战术细节另行标为创作或推演。
2. **以军队行动为组织轴。** 历史研究保留完整行动链；本次剧情只取同一次清晨攻城中的“速攻”与“先登”。
3. **双前线视角。** 陈安死于初攻后切到丁进的先登准备；两人互不相识。前段从战场受伤倒地切入家庭记忆，再以清障、牵引和运具中的同伍动作显露关系；后段先用无名视角与呼名完成剧情过渡，身份揭晓后交回操作、开始任务五；他取用同一辆车的器材、走过陈安打开的路、亲历登城，回收前段因果。战后消息补全两人都没亲见的结果。
4. **战场信息靠感知。** 旗、鼓、地形和同伴反应可为人物提供可见可听的线索；具体旗语、声音传播、地势与小队战术均须标虚构，不能从一般兵法推作皖城实录。
5. **知识从任务中显现。** 每场先交代玩家必须完成的动作，再让兵器、衣装、信号和队伍反应显示原理；优先替换重复遇敌、卡轮、催快和纯报捷段落。每次改稿主动检查哪些空段可由有依据的生活或军事细节替换，同时保留家庭与同伴关系所需的情感段落。
6. **地图只回答空间问题。** [地理关系图](../皖城之战-地理关系示意.svg)与[现代地形模型](../wancheng_terrain/README.md)不能证明 214 年吴军航线或城墙布局。

## 场景知识的依据与用法

| 知识 | 核对依据 | 进入剧情的方式与范围 |
| --- | --- | --- |
| 旗鼓与协同行动 | [《孙子·军争》](https://www.chineseclassic.com/content/1784)讨论金鼓、旌旗如何统一众人耳目 | 喊话被盖住时认旗；本队横纹、队旗位置与具体鼓声由游戏设定 |
| 行縢与衣装 | [《吕蒙传》](https://www.shidianguji.com/zh/book/LS0004/chapter/1j7fnuxl7ljcq_345)记其早年为兵作绛衣行縢，字义按裹束腿部的衣装理解 | 吴成在回忆中替陈安系紧绑腿；不把某种颜色、现代绑法或五人穿着写成此役实录 |
| 长短兵互助 | [《司马法·定爵》原文与注](https://ctext.org/wiki.pl?chapter=864382&if=gb)讨论长短兵的互补 | 伍长持矛、吴成盾与短兵护近处是游戏局部分工，不是吴军已证实的固定阵式 |
| 弩的机构与装填 | [国家博物馆“铜弩机”](https://www.chnmuseum.cn/Portals/0/web/exhibition/exhibitions/201812han/14.html)展示汉代弩机的扣弦、装箭和悬刀发射结构 | 护住弩手重新张弦装箭的空隙；不规定统一射速、守军齐射间隔，也不宣称皖城此处确有弩手 |
| 四面速攻与援军威胁 | [《吕蒙传》裴注《吴书》](https://ctext.org/text.pl?if=en&node=604229&show=parallel)记吕蒙反对耗时修造、主张四面并攻 | 运车时见分路、抬梯时听明确军令、架梯时见守军分人、上墙后接另一面登墙消息；战史补议策。具体守军调动与机会均为设计推演 |
| 先登、继进与评功 | [《甘宁传》](https://www.shidianguji.com/book/LS0004/chapter/1j7fnuxpav393_354)记甘宁领登与吕蒙功最、甘宁次之；《吕蒙传》记精锐继进和执鼓 | 丁进先使别人能上、自己跟进，再腾出梯口；此役具体计功规则不据此补造 |
| 伤兵的收拢救治 | [明代《练兵实纪》卷八](https://www.shidianguji.com/book/SK1398/chapter/1jzz9oy2thctv)，详见上文用语说明 | 用户确定的救人冲突保留，动作回收词义；“收拾调理”的明代出处在可查阅释义中明示 |
| “男女数万口”是人口记录 | [《吴主传》](https://zh.wikisource.org/wiki/三國志/卷47)记获朱光、董和及男女数万口 | 战后抬伤兵时看见被集中看管的城中男女；妇人与孩子的个体画面是创作，俘获人数不作为杀敌数 |

这张表给创作定依据；[玩法稿中的替换表](levels/速攻与先登-史实剧情玩法.md#场景替换与知识回收)说明各处删换、玩家动作和后续回收。科普不等于把古书的完整编制与战法搬进214年皖城。

## 每章典故的出处与解释

| 章节典故 | 原文与出处 | 可据此解释什么、创作怎样使用 |
| --- | --- | --- |
| 金鼓旌旗 | [《孙子·军争》](https://www.chineseclassic.com/content/1784)：“言不相闻，故为金鼓；视不相见，故为旌旗。” | 解释统一军队行动；具体横纹、鼓点与声传位置由本作设定 |
| 同袍 | [《诗经·秦风·无衣》](https://ctext.org/text.pl?if=gb&node=15066&show=parallel)：“岂曰无衣，与子同袍。”后文联系修治兵器、共同出征 | 用分衣与互保理解战友之情；不要求角色唱整首诗，不把它当吴军同伍制度的记载 |
| 陷阵 | [《三国志·典韦传》](https://ctext.org/text.pl?if=gb&node=602774&show=parallel)：“太祖募陷阵，韦先占。” | 汉末已有陷阵记载；以冒险攻入敌阵解释。陈安与小队突入、开路是虚构，不能写成典韦旧事在皖城重演 |
| 一鼓作气 | [《左传·庄公十年》](https://ctext.org/chun-qiu-zuo-zhuan/zhuang-gong-shi-nian/zh)：“一鼓作气，再而衰，三而竭。”其故事为曹刿论战、长勺之战 | 解释士气与出击时机；以队列配合向前呼应，不能声称皖城吴军照搬等齐军三鼓的战法 |
| 先登之功 | [《甘宁传》](https://www.shidianguji.com/book/LS0004/chapter/1j7fnuxpav393_354)记甘宁升城督、缘城在前；[《乐进传》](https://www.shidianguji.com/book/LS0004/chapter/1j7fnuuoeh4qk_86)有多次先登有功而封侯的例子 | 先登受重视有依据；“先上城的，记先登之功”“城破之后，论功行赏”等为本作激励性喊话，不是此役保存的军令。不许诺固定钱粮、封侯、升官，也不将先登功限成全城唯一一个人的奖项 |

**“冲锋陷阵”的年代：** [《北齐书·崔暹传》](https://www.shidianguji.com/book/LS0011/chapter/LS0011_154)有该四字连用的书证，晚于214年。第三章取汉末已有记载的“陷阵”为核心，现代解说可以联系“冲锋陷阵”；不让人物引用后出故事。此前用户确定的“收拾调理”仍按明代用语借意处理，不与先秦、汉末典故混为同时材料。

每章主题、释义触发与动作回收见[五章典故主线](levels/速攻与先登-史实剧情玩法.md#五章典故主线)。正文中已写出具体喊话、距离、触发动作与听觉层次；重要信息不能只记作“远处传来军令”。
