# 战例与小兵视角 · 剧本素材库

> 配套：[01-设计分析.md](../01-设计分析.md)、[02-考据底本.md](../02-考据底本.md)
> 本篇用途：给剧本提供**可直接改编的战役骨架**，重心是"一个普通人在其中的处境"。
> 调阅方式：维基文库原文逐字比对（下文凡引原文皆已直读）；兵力数字均注明出处；无出处的数字一律标〔存疑推断〕并说明为何不能采信。

## 体例

**来源等级**

| 标记 | 含义 |
|---|---|
| 〔正史〕 | 纪传体正史本纪/列传/志（《史记》《汉书》《三国志》及裴注、《晋书》《旧唐书》《新唐书》《宋史》《明史》） |
| 〔编年〕 | 编年体（《资治通鉴》） |
| 〔兵书〕 | 兵学著作（《吴子》《尉缭子》《纪效新书》《练兵实纪》等） |
| 〔典章会典〕 | 政书、会典、实录（《明会典》《明实录》） |
| 〔出土文献〕 | 简牍、木牍、墓志、考古发掘 |
| 〔私记〕 | 当事人或同时人的第一人称记述（题本、日录、笔记） |
| 〔演义小说〕 | 小说、戏曲、民间说唱 |
| 〔现代研究〕 | 今人论文、考古报告、田野调查 |
| 〔存疑推断〕 | 无直接史料，由旁证推得；或史料本身可疑 |

**置信度**：高＝原文直载且无版本争议；中＝原文直载但数字/细节有争议，或有可靠转述未直读原书；低＝孤证、晚出、或纯推算。

**一条贯穿全篇的原则**：正史给的是**结果**和**将帅**；小兵的脸、声音、饥饿、伤口，只出现在三种地方——**列传的附记、当事人自述、以及出土的私人文字**。本篇把小兵视角单列一节，就是因为那才是剧本真正要的东西。

# 战役档案（十二场）

### 1. 长平之战（前260年，秦昭王四十七年四月—九月）

**交战方与兵力**

| 方 | 数字 | 出处 | 存疑说明 |
|---|---|---|---|
| 赵（廉颇/赵括） | 降卒**四十万**，前后斩首虏**四十五万** | 〔正史〕《史记·白起王翦列传》：「卒四十萬人降武安君……前後斬首虜四十五萬人」 | 见下 |
| 赵（放归者） | **二百四十人** | 同上：「遺其小者二百四十人歸趙」 | 这是长平战后活着回赵的唯一一批人，数字具体到个位，反而是全篇最可信的数字 |
| 秦 | 未载总数 | 同上 | 《史记》没给秦军兵力，任何"秦六十万"的说法都没有史料依据 |
| 秦（自身损失） | 「秦卒死者過半，國內空」 | 同上，白起谏攻邯郸语 | 白起亲口承认秦军死了一半。这条是反驳"秦以极小代价坑赵四十万"的最硬内证 |

**学界对四十万的讨论**：四十万这个数字自汉代起就被质疑，主要理由有四条——① 战国晚期赵的总人口估算撑不起一次性投入并损失四十万青壮；② 《史记》同篇记「秦卒死者过半」，若赵军真被围歼而秦军仅小损，与"死者过半"矛盾；③ 数字是"斩首虏"合计（含杀、俘、降），不是单一坑杀数；④ 秦汉军功制度以首级计功，战报本身有系统性膨胀动力。1995年山西高平永录村一号尸骨坑发掘，**仅清理出遗骸一百三十余具**，与"四十万"相差极远，但考古工作者指出白起杀降是以丹河为轴线多点分散处置，非一处集中掩埋〔现代研究〕（[人民网/山西晚报 2020-07-15](http://m.people.cn/n4/0/2020/0715/c676-14191862-3_2.html)）。**结论：四十万只能作为"文学量级"使用，不能作为关卡内的计数单位。**置信度：数字低，事件高。

**地形与天气**

- 战场在今山西高平市丹河河谷一带，东西两山夹一河，赵军壁垒在西，秦军在东。
- 关键天时只有一句：「**至九月，趙卒不得食四十六日**」（《史记·白起王翦列传》）。九月已入深秋，太行山区夜寒，断粮四十六天意味着最后阶段是纯粹的冻饿与自相残食。史料未记具体天气，[[存疑推断]] 可定为"深秋连阴、昼夜温差极大"。
- 地形决定的战术事实：赵军被「分而為二」，粮道被切断在壁垒之间——**不是被打败的，是被切成两段饿垮的**。

**战前双方状态**

- 赵：廉颇初战连败（四月裨将茄被杀，六月陷二鄣四尉，七月西垒壁被夺），改取坚壁不出。赵王「数以为让」，已经对廉颇不满。秦相应侯「使人行千金于赵为反间」。
- 秦：密遣白起为上将军，「令军中有敢泄武安君将者斩」——**连自己士兵都要瞒**。这一条极重要：秦军基层长期不知道自己主帅是谁。
- 补给：赵军粮道是命门；秦军则靠河内后方。断粮后秦王亲自到河内，「赐民爵各一级，发年十五以上悉诣长平」——**全国十五岁以上全部征发去堵赵国的援军和粮食**。这是中国战史上最早的一次全民动员记载之一。

**战术过程（分阶段）**

1. **接触与试探（四月—七月）**：秦攻上党，上党民走赵，赵军驻长平接应。秦斥兵斩赵裨将茄；六月秦陷赵二鄣四尉；七月赵「筑垒壁而守之」，秦又攻其垒，夺西垒壁。士兵这一段在做的事：筑墙、守墙、被夺墙。
2. **换帅与诱敌（七月后）**：赵括代廉颇，「悉更约束，易置军吏」——上任第一件事是把所有军官换掉。秦军「详败而走」，张两翼奇兵。
3. **合围（决战日）**：赵军逐胜追至秦壁，壁坚不得入。秦「奇兵二万五千人绝赵军后」，另「一军五千骑绝赵壁间」。赵军被切成两段，粮道绝。**注意这两个数字：二万五千步骑 + 五千骑——合围用的是一支不到三万人的机动部队，不是主力。**
4. **困守（四十六日）**：「赵卒不得食四十六日，皆内阴相杀食」。赵军「为四队，四五复之，不能出」——组织了四支突围队，反复四五次，出不去。
5. **主帅战死与投降**：「其将军赵括出锐卒自搏战，秦军射杀赵括」。主帅一死，四十万人降。
6. **处置**：白起以「赵卒反覆，非尽杀之，恐为乱」为由，「挟诈而尽坑杀之」，只放回二百四十个年幼的。

**关键转折点**

**赵括被射死的那一瞬**。不是被俘、不是自杀，是「出锐卒自搏战」时被秦军射杀——一个把兵书背熟的人，最后是自己带着亲兵冲阵被箭射死的。他一死，四十万人的抵抗意志同时消失，因为**这支军队的合法性全部挂在他一个人身上**（他上任第一件事就是换掉所有旧军官，没人能替代他）。

**伤亡与后果**

- 赵：「前后斩首虏四十五万」（《史记·白起王翦列传》）；《史记·廉颇蔺相如列传》作「数十万之众遂降秦，秦悉坑之。赵前后所亡凡四十五万」。数字存疑（见上）。
- 秦：「秦卒死者过半，国内空」（同上）。
- 后果：邯郸被围，赖楚魏救得解。数年后燕人栗腹谋伐赵，理由是「**赵壮者尽于长平，其孤未壮**」（《史记·廉颇蔺相如列传》）——一句话写尽一代人的消失。

**【小兵视角细节】**

- **「皆内阴相杀食」**（《史记·白起王翦列传》）。六个字。不是"易子而食"那种有伦理框架的说法，是"暗中互相杀着吃"。这是全篇最冷的一句，也是长平唯一一句真正写到士兵身体的话。
- **「为四队，四五复之，不能出」**。赵军被围后不是坐着等死，是组织了四次以上的突围，一次次失败。写剧本时这是天然的关卡循环：**突围—失败—再突围—再失败**，每次人数更少。
- **二百四十个孩子**。「遗其小者二百四十人归赵」。白起放他们回去，是要他们带话。这二百四十人是唯一走出长平的人，也是赵国"长平"这两个字唯一的活口。可做结尾：一群孩子走回赵国，一路讲他们看见的事——**这就是"记忆"的最原始形态**。
- **赵括的母亲**（《史记·廉颇蔺相如列传》）。她上书阻止儿子为将，理由是丈夫赵奢为将时「身所奉饭饮而进食者以十数，所友者以百数，大王及宗室所赏赐者尽以予军吏士大夫」；而赵括「一旦为将，东向而朝，军吏无敢仰视之者，王所赐金帛，归藏于家，而日视便利田宅可买者买之」。她还预先讨了一个免罪承诺：「王终遣之，即有如不称，妾得无随坐乎？」——**一个母亲在儿子出征前，先谈好了败战后的免责条款**。战后「赵王亦以括母先言，竟不诛也」。
- **一个秦国征发的十五岁少年**：秦王「发年十五以上悉诣长平」。这些人不打仗，任务是「遮绝赵救及粮食」——站在太行山的小路上拦人和粮车。他们中的大多数不会出现在任何功劳簿上，因为他们没有首级。
- **考古现场的一个农民**（〔现代研究〕，2020年报道）：高平南王庄村46岁的王进保说，土崖下的耕地1983年前是他家的自留地，小时候常帮大人捡裸露的人骨，「大人们就让我用箩头把骨头装上倒在附近的河沟里，**一次捡好几箩头，其中就有好多的头盖骨**」。两千二百年后，长平的骨头仍然是农活的一部分。
- **骷髅庙**：高平谷口村有骷髅庙，当地相传唐玄宗为祭长平死者所建（〔存疑推断〕，庙存、建庙年代与缘由无确证）。这是"给无名者一个地方"的最早样本之一。

**【可玩性评估】**

**最适合：断粮 + 被围 + 突围失败（三幕递减）。**

- 核心张力不是"打不打得过"，是**"还要不要再冲一次"**。玩家每冲一次，队伍少一批人，而对面那圈包围纹丝不动。第四十六天，玩家已经不是在选择战术，是在选择"吃不吃"。
- 天然的三段结构：①筑垒（学守）②断粮（资源耗尽）③突围（必败）。第三段必须设计成**无论怎么打都出不去**，这才是史实。
- 不能做的：把"坑杀"做成玩家可操作的关卡（价值判断会被误读为玩法奖励）；把数字做成 HUD 计数（四十万在屏幕上就是个数字，反而不恐怖）。
- **推荐落点**：让玩家在第三幕扮演"二百四十人"里的一个孩子，被秦军从坑边拉出来放走。整场战役的重量，压在他走回赵国的那条路上。

### 2. 巨鹿之战（前207年，秦二世三年）

**交战方与兵力**

| 方 | 数字 | 出处 | 存疑说明 |
|---|---|---|---|
| 楚（先锋） | **二万** | 〔正史〕《史记·项羽本纪》：「乃遣当阳君、蒲将军将卒二万渡河，救巨鹿」 | 高 |
| 楚（项羽主力） | 未载 | 同上，只作「项羽乃悉引兵渡河」 | 项羽总兵力无史料，任何"五万""七万"皆推算〔存疑推断〕 |
| 秦（王离、涉间） | 未载 | 同上：「章邯令王离、涉间围巨鹿，章邯军其南，筑甬道而输之粟」 | 通说"王离二十万"无直接史料 |
| 秦（章邯） | 未载 | 同上 | 同上 |
| 诸侯救赵军 | **十余壁** | 同上：「诸侯军救巨鹿下者十余壁，莫敢纵兵」 | 只给营垒数，不给兵数 |

**学界讨论**：巨鹿之战最常被引用的"秦军四十万对项羽五万"是一个**现代通俗叙述的合成数字**，《史记》原文对双方总数全部留白。可以确证的只有：楚先锋二万；王离被围歼；章邯军另在巨鹿南；诸侯十余壁全程观望。写剧本时应当把"数字悬殊"换成"**楚军自己的粮已经断了**"——后者有原文。

**地形与天气**

- 战场在今河北平乡一带，巨鹿城被围，章邯在城南筑甬道输粮——**甬道是这场仗的真正目标**，楚军九战的重点就是"绝其甬道"。
- 天气是这场战役最被忽略、却最有戏剧价值的史料（《史记·项羽本纪》，宋义留安阳四十六日不进时）：

> 「天寒大雨，士卒冻饥。」
> 「今岁饥民贫，士卒食芋菽，军无见粮。」

**深秋初冬，连日大雨，士兵吃的是芋头和豆子，军中已经没有存粮。** 而同一时间，上将军宋义在送儿子去齐国做相，路上「饮酒高会」。这是整部《史记》里写得最刻薄的一组对比。

**战前双方状态**

- 楚：主力新败（项梁战死），国兵新破，「王坐不安席，埽境内而专属于将军」。宋义按兵四十六日，想等秦赵两败俱伤。
- 秦：章邯刚破项梁，判断「楚地兵不足忧」，北渡河击赵，势如破竹。
- 诸侯：十余壁救赵，全部「从壁上观」——不是不来，是来了不敢动。
- 内部矛盾：项羽与宋义路线冲突，最后是**项羽早晨进帐斩了宋义的头**，出帐宣布「宋义与齐谋反楚，楚王阴令羽诛之」，诸将「皆慴服，莫敢枝梧」。

**战术过程（分阶段）**

1. **夺权**（晨朝）：项羽于帐中斩宋义，自立为假上将军，遣人追杀宋义之子于齐。
2. **试攻**：先遣当阳君、蒲将军以二万人渡河，「战少利」——小胜，但不足以解围。陈馀再请兵。
3. **决死渡河**：项羽悉引兵渡河，「皆沉船，破釜甑，烧庐舍，持三日粮，以示士卒必死，无一还心」。**士兵此刻手里只有三天干粮，背后没有船。**
4. **九战绝甬道**：「于是至则围王离，与秦军遇，九战，绝其甬道，大破之」。杀苏角，虏王离，涉间不降，自烧杀。
5. **收场**：项羽召见诸侯将，「入辕门，无不膝行而前，莫敢仰视」。

**关键转折点**

**沉船的那一刻，是项羽做的；但真正决定胜负的是"绝甬道"成功的那一天。**

给剧本一个更小的落点：**第三天**。三日粮吃完的那天，甬道还没断，王离还没虏。士兵知道自己回不去了，但胜利还没到手。这是全战最不可写、也最真实的一段——史书直接从"持三日粮"跳到"九战，绝其甬道"，中间那三天没有任何记载。**这段空白正是剧本最该填的地方。**

**伤亡与后果**

- 双方伤亡数字《史记》全无。
- 后果：秦军主力之一的王离部被全歼，章邯部此后陷入孤立，最终于数月后降楚（降卒二十余万后来在新安被坑，见《史记·项羽本纪》）。
- 政治后果：项羽「始为诸侯上将军，诸侯皆属焉」——**这一战把项羽从一个副将变成了联军统帅**。

**【小兵视角细节】**

- **「士卒食芋菽，军无见粮」**。芋头和豆子。这是楚军士兵在开战前的实际伙食，而且是"没有存量"的状态。**项羽破釜沉舟之所以有效，一半原因是本来就没粮了**——砸锅是把"没有选择"变成"不能反悔"。
- **「楚战士无不一以当十，楚兵呼声动天」**。这是现场听觉记录：不是鼓声，不是号令，是**人的喊声大到"动天"**，以至于「诸侯军无不人人惴恐」——**在营垒上观战的诸侯军，是被声音吓住的**。写声音设计时，这一句就是依据：先给远处营垒里的士兵视角，让他们听。
- **「无不膝行而前，莫敢仰视」**。诸侯将进项羽辕门时是跪着用膝盖挪进去的，不敢抬头。写"权力的物理形态"时，这一句比任何台词都狠。
- **一个被斩的上将军**：宋义不是战死的，是被自己人砍头的。他死前刚下过一道军令：「猛如虎，很如羊，贪如狼，强不可使者，皆斩之。」——**这句话本来是用来吓士兵的，结果他自己先死在这套逻辑里**。
- **一个被追杀的年轻人**：宋义的儿子宋襄，被派去齐国做相，项羽「使人追之，及之齐，杀之」。他连战场都没上。

**【可玩性评估】**

**最适合：倒计时决死 + 断粮。**

- 天然机制：**三日粮计数器**。三天之后每一刻都是"本来就该结束的时间"，玩家在超时状态下作战，心理压力和史实完全吻合。
- 核心张力：**没有退路这件事是玩家自己参与制造的**（如果他操控士兵砸锅沉船）。让玩家亲手毁掉自己的退路，比告诉他"你无路可退"强十倍。
- 次强张力：**诸侯在壁上看**。可做一个"求援"支线——玩家去诸侯营垒下喊，对方不开门。史料原文就是「莫敢纵兵」。
- 弱点：这场战役的个体记载几乎为零，全部重量在项羽身上。**做 5 次魂穿会缺材料**，更适合做单视角的短关。

**史料出处**

- 〔正史〕《史记·项羽本纪》：<https://zh.wikisource.org/wiki/史記/卷007>

### 3. 井陉之战（前204年，汉三年十月，即"背水一战"）

**交战方与兵力**

| 方 | 数字 | 出处 | 存疑说明 |
|---|---|---|---|
| 汉（韩信、张耳） | 「兵数万」 | 〔正史〕《史记·淮阴侯列传》：「信与张耳以兵数万，欲东下井陉击赵」 | 高 |
| 汉（实际） | 「其实不过数千」 | 同上，陈馀语：「今韩信兵号数万，其实不过数千」 | 敌方判断，未必精确，但《史记》同时记韩信自述「此所谓驱市人而战之」，可互证兵员质量极差 |
| 赵（陈馀） | 「号称二十万」 | 同上：「聚兵井陉口，号称二十万」 | **"号称"二字是司马迁自己加的**，明示虚数 |
| 汉（奇兵） | **二千骑** | 同上：「选轻骑二千人，人持一赤帜」 | 高 |
| 汉（先锋） | **万人** | 同上：「信乃使万人先行，出，背水陈」 | 高 |

**地形与天气**

- 井陉道是太行山八大隘口之一，原文给了精确的通行条件（李左车语）：

> 「今井陉之道，车不得方轨，骑不得成列，行数百里，其势粮食必在其后。」

**车不能并排走，骑兵不能列队，行军数百里，粮车一定落在最后。** 这是全部胜负的物理基础。
- 天气无直接记载。时间线索是「**平旦**」（拂晓）建大将旗鼓出井陉口——决战从清晨开始。
- 战场结构：赵军先占「便地」筑壁（有利地形 + 营垒），汉军背水列阵（背后是河，无退路）。

**战前双方状态**

- 赵：兵力优势 + 地形优势 + 营垒优势。谋士李左车提出完整方案：请奇兵三万人从小道绝汉军辎重，主力深沟高垒不战，「不至十日，而两将之头可致于戏下」。**陈馀拒绝，理由是「义兵不用诈谋奇计」**——他是儒者，认为用计不光彩，还说「今如此避而不击，后有大者，何以加之！则诸侯谓吾怯」。
- 汉：兵少、兵劣（「驱市人而战之」——驱赶市井平民去打仗）、孤军深入、粮道在敌后。韩信唯一的优势是**情报**：「韩信使人间视，知其不用，还报，则大喜，乃敢引兵遂下。」
- 一个被忽略的细节：韩信直到确认李左车的计策被否决，**才敢进军**。他不是靠勇气赢的，是靠间谍赢的。

**战术过程（分阶段）**

1. **夜半传发**：距井陉口三十里止舍。半夜发令，选二千轻骑，每人一面红旗，从间道傍山隐蔽，命令是：「赵见我走，必空壁逐我，若疾入赵壁，拔赵帜，立汉赤帜。」
2. **传飧**：让裨将传令开饭，说「**今日破赵会食**」——今天破了赵再正式吃饭。诸将没人相信，「详应曰：诺」（假装答应"好"）。
3. **背水列阵**：万人先出，背水布阵。赵军望见，「大笑」。
4. **正兵诱敌**：平旦，韩信建大将旗鼓，鼓行出井陉口。赵开壁出击，大战良久。韩信、张耳「详弃鼓旗」，退入水上军。水上军开门放他们进去，再合力死战。
5. **赵军空壁**：赵军果然全营出动抢汉军鼓旗、追韩信张耳。汉军「皆殊死战，不可败」。
6. **拔帜**：二千骑兵趁赵营空虚驰入，「皆拔赵旗，立汉赤帜二千」。
7. **崩溃**：赵军攻不下，想回营，「壁皆汉赤帜，而大惊，以为汉皆已得赵王将矣，兵遂乱，遁走，**赵将虽斩之，不能禁也**」。汉军夹击，斩陈馀于泜水，擒赵王歇。

**关键转折点**

**赵军回头看见自己营垒上全是红旗的那一秒。**

不是被击败，是**被看见**击败的。司马迁写得很清楚：赵军此时还有战斗力，还能「欲还归壁」，但一看见赤帜就「大惊」，然后「兵遂乱」；赵将当场斩杀逃兵也止不住。**这支军队不是被打散的，是被一个视觉信号解散的。**

这也是整个素材库里最"游戏化"的一个瞬间：**屏幕上两面旗换色，一支军队消失。**

**伤亡与后果**

- 双方伤亡《史记》未载。
- 后果：赵亡。韩信「令军中毋杀广武君，有能生得者购千金」，活捉李左车后「解其缚，东乡坐，西乡对，师事之」——**战胜者把战败者的谋士当老师供起来**。随后采李左车之策，按甲休兵、抚赵孤、遣使说燕，燕「从风而靡」。
- 政治后果：韩信请立张耳为赵王，刘邦许之。

**【小兵视角细节】**

- **「今日破赵会食」**（《史记·淮阴侯列传》）。这四个字是全部古代战史里最好的一句台词。将军说今天打完赵再吃饭，然后「诸将皆莫信，详应曰：诺」——**所有基层军官心里都觉得这人在吹牛，但嘴上都说"好"**。这是士兵对上级的典型态度，两千年没变。
- **「臣等不服」**：战后诸将直接问韩信「今者将军令臣等反背水陈，曰破赵会食，臣等不服。然竟以胜，此何术也？」——**下级当面承认自己不服，而且是在打赢之后**。这种关系在正史里极其罕见。
- **「驱市人而战之」**（韩信自述）。这四个字说明汉军士兵是什么人：不是精锐，是市井平民，没受过训练，一给活路就会跑。韩信自己说：「今予之生地，皆走，宁尚可得而用之乎！」——**给他们生路，他们全跑；所以只能放死地。** 这是主帅对士兵心理的冷酷评估，也是这支军队的真实处境。
- **「军皆殊死战，不可败」**。背水阵的士兵不是勇敢，是**没有别的选项**。
- **「赵将虽斩之，不能禁也」**。赵军的军官在砍自己人，砍了也止不住。写溃败时这是关键：**溃败不是士兵的失败，是命令系统的失效**。
- **一个被"买"下来的谋士**：李左车被捆着送到韩信面前，韩信「解其缚，东乡坐，西乡对，师事之」。他后来对韩信说了一句名言「智者千虑，必有一失；愚者千虑，必有一得」。这个人是这场仗里唯一看穿全局的人，而他的计策没被采用。
- **一面旗的重量**：二千面红旗，是这场仗唯一的"武器"。士兵整夜的任务不是杀人，是**抱着旗子在山里等**。

**【可玩性评估】**

**最适合：本素材库中与现有设计匹配度最高的一场，建议作为主推战役。**

- 五个兵种天然齐全，且每一个都直接对应已有机制：
  | 兵种 | 史实依据 | 对应机制 |
  |---|---|---|
  | 轻骑（二千人之一） | 「人持一赤帜，从间道萆山而望赵军」 | 隐蔽行军 + 拔旗 |
  | 背水步卒（万人之一） | 「背水陈」「军皆殊死战」 | 阵位（背后是水，不能退） |
  | 鼓手/旗手 | 「信建大将之旗鼓，鼓行出井陉口」 | 鼓点辨令 + 旗号观测（M1/M2 直接落地） |
  | 传令兵 | 「夜半传发」「令其裨将传飧」 | 传令（夜间、口令、跑位） |
  | 文书 | 「诸将效首虏，毕贺」 | **记功/验首**（见下） |
- **现成的"文书/记功"环节**：战后原文是「**诸将效首虏，（休）毕贺**」——"效首虏"就是呈验首级与俘虏，然后集体道贺。这是中国军功制度在战场上的标准动作，可以直接做成一个结算界面：一队人排队把首级放在木台上，文书登记，将军点数。**不需要任何虚构。**
- **天然的反转点**：赵军回望，营垒尽赤。这个反转是**视觉的、瞬时的、不需要台词的**，正好适合 15 分钟 demo 的高潮。
- 核心张力：**"我知道这不可能赢，但命令已经下了。"** 玩家扮演的每一个兵，都知道"今日破赵会食"是句疯话。

**史料出处**

- 〔正史〕《史记·淮阴侯列传》：<https://zh.wikisource.org/wiki/史記/卷092>

### 4. 垓下之战（前202年，汉五年十二月）

**交战方与兵力**

| 方 | 数字 | 出处 | 存疑说明 |
|---|---|---|---|
| 汉（韩信本部） | **三十万** | 〔正史〕《史记·高祖本纪》：「淮阴侯将三十万自当之，孔将军居左，费将军居右，皇帝在后，绛侯、柴将军在皇帝后」 | 高。这是全篇唯一给出完整战斗序列的一战 |
| 楚（项羽） | 「可十万」 | 同上：「项羽之卒可十万」 | 「可」＝大约，是估算 |
| 汉（追击骑兵） | **五千骑** | 《史记·项羽本纪》：「令骑将灌婴以五千骑追之」 | 高 |
| 项羽突围 | **八百余骑** | 同上：「麾下壮士骑从者八百余人，直夜溃围南出」 | 高 |
| 渡淮后 | **百余人** | 同上：「项王渡淮，骑能属者百余人耳」 | 高 |
| 东城 | **二十八骑** | 同上 | 高 |
| 汉军阵亡 | **八万**（斩首） | 《史记·高祖本纪》：「使骑将灌婴追杀项羽东城，斩首八万」 | 「斩首八万」含追击阶段全部战果，非单日 |

**地形与天气**

- 垓下在今安徽灵璧东南，沱河北岸。汉军「围之数重」。
- 决定性"天时"不是天气，是**声音**：「夜闻汉军四面皆楚歌」。项羽大惊，说「汉皆已得楚乎？是何楚人之多也！」
- 后续地形致命处：阴陵（今安徽定远西北）一带多沼泽，「左，乃陷大泽中」。
- 乌江亭有船。**整场追击的胜负手是"路"，不是"战"。**

**战前双方状态**

- 楚：「兵少食尽」，壁垓下，被围数重。此前刚在固陵大破汉军，但韩信、彭越不来会师——刘邦是靠**许地**（「自陈以东傅海与韩信，睢阳以北至穀城与彭越」）才把他们换来的。
- 汉：诸侯联军，成分复杂（韩信齐军、彭越梁军、刘贾、周殷九江兵），指挥链条靠利益绑着。

**战术过程（分阶段）**

1. **合围**：韩信三十万自当正面，孔将军左、费将军右，刘邦在后，绛侯、柴将军再后——**刘邦被放在第三线**，这是韩信的安排。
2. **正面接战**：「淮阴先合，不利，却」——韩信本部先打，退了。孔、费两翼纵兵，楚军不利，韩信回身再乘之，「大败垓下」。
3. **心理瓦解**：夜间四面楚歌。项羽夜起帐中饮酒，作歌，虞姬和之，「项王泣数行下，左右皆泣，莫能仰视」。
4. **溃围**：项羽率八百余骑夜遁。平明汉军才发觉，灌婴以五千骑追。
5. **迷路**：渡淮剩百余人。至阴陵迷失道，问一田父，田父说"左"，向左就陷进大泽，因此被追上。
6. **东城三胜**：只剩二十八骑，汉骑数千。项羽分队四向，说「吾为公取彼一将」，大呼驰下，斩汉一将、一都尉，杀数十百人，自己只损失两骑。问骑兵「何如？」骑皆伏曰「如大王言」。
7. **乌江**：亭长舣船以待，劝他渡江。项羽不肯，「籍与江东子弟八千人渡江而西，今无一人还」。赠马于亭长，令骑皆下马步行持短兵接战，独杀汉军数百人，身被十余创。看见汉骑司马吕马童，说「若非吾故人乎」，然后「吾闻汉购我头千金，邑万户，吾为若德」，自刎。

**关键转折点**

**田父那一句"左"。**

一个没有名字的农夫，在阴陵的路口，把中国历史上最强的武将指向了一片沼泽。司马迁只用九个字记这件事：「问一田父，田父绐曰『左』。」——**"绐"是欺骗，司马迁明确写了这是故意的。**

这是全篇最值得做成剧情的一个点：**决定历史的那个人，连名字都没有，而且他是故意的。** 他为什么骗？史书不说。这个空白是剧本最好的入口。

**伤亡与后果**

- 楚军主力溃散，项羽自刎，汉军「斩首八万」（《史记·高祖本纪》）。
- **争尸**：「王翳取其头，余骑相蹂践争项王，相杀者数十人。」——为抢尸体，汉军骑兵自相残杀数十人。
- 五人分尸封侯：王翳（杜衍侯）、杨喜（赤泉侯）、吕马童（中水侯）、杨武（吴防侯）、吕胜（涅阳侯）。「五人共会其体，皆是。故分其地为五」。
- 后果：汉五年二月刘邦称帝。

**【小兵视角细节】**

- **「左右皆泣，莫能仰视」**。帐中所有人都在哭，没有一个人敢抬头看他。这是《史记》写项羽之死的第一个镜头，写的是**旁人的脸**，不是他的。
- **「骑能属者百余人耳」**。八百人渡淮，剩一百多。**六百多人是在夜里掉队、走散、或者死在路上的，没有一场战斗。**
- **「亡其两骑耳」**。东城之战，二十八骑只损失两人。项羽问"何如"，「骑皆伏曰：如大王言」——**这二十八个兵趴在地上说"跟您说的一样"**。这是项羽最后一次被服从。
- **「余骑相蹂践争项王，相杀者数十人」**。这是全篇最黑的一句。项羽刚死，汉军骑兵为了抢一块尸体，互相踩踏、互相砍杀，死了几十个。**他们的将军在用"封侯"买他们的命，而他们杀的是自己人。**
- **吕马童**：「顾见汉骑司马吕马童，曰：『若非吾故人乎？』马童面之，指王翳曰：『此项王也。』」——项羽认出了一个熟人，那个熟人**把脸转过去，指着项羽对旁边人说"这就是项王"**。他没有回答"是我"，他指了指。司马迁写"面之"两个字，写尽了一个小人物在此刻的选择。他后来封了中水侯。
- **乌江亭长**：「檥船待」，一个管渡口的小吏，把船靠好等着。他说「江东虽小，地方千里，众数十万人，亦足王也。愿大王急渡。**今独臣有船**，汉军至，无以渡。」——全江只有他一条船。他准备了一条船，等一个不会上船的人。
- **「令骑皆下马步行，持短兵接战」**。最后二十八个人被命令下马。马是最后的机动能力，放弃马就是宣布不走了。

**【可玩性评估】**

**最适合：溃逃 + 追击 + 抢尸（三段式，且第三段是道德关）。**

- 核心张力：**"跑"这件事的技术难度**。八百人夜里突围、渡河、迷路、越跑越少——这是一场纯粹的资源递减关卡，玩家每过一个节点，队伍人数掉一截。**这是本素材库里唯一一场"以逃跑为主玩法"的战役。**
- 天然的反转点：田父指路。玩家扮演传令/前锋去问路，得到一个"左"，然后**必须决定信不信**。信了进沼泽，不信则偏离史实——这里可以设计成"两条路都通向失败"，只是失败的方式不同。
- 强反转点：抢尸。玩家在项羽死后，面对一具尸体和一群同袍。任务目标写着"取首级，封侯"。**这是"记功"制度最赤裸的一次显影。**
- 弱点：项羽的个体光芒太强，容易变成"霸王叙事"，压掉小兵。**必须把镜头永远放在他周围的人身上。**

- 〔正史〕《史记·项羽本纪》：<https://zh.wikisource.org/wiki/史記/卷007>
- 〔正史〕《史记·高祖本纪》：<https://zh.wikisource.org/wiki/史記/卷008>

### 5. 赤壁之战（208年，建安十三年十二月）

**交战方与兵力**

| 方 | 数字 | 出处 | 存疑说明 |
|---|---|---|---|
| 曹（自称） | 「水步**八十万**」 | 〔正史〕《江表传》引曹操与孙权书，见《三国志·吴书·周瑜传》裴注：「诸人徒见操书，言水步八十万，而各恐慑，不复料其虚实」 | **这是曹操自己发的宣传数字**，周瑜当场指出是虚数 |
| 曹（周瑜实数） | 中原兵「**不过十五六万**」，刘表降军「**极七八万**」 | 同上，周瑜语：「今以实校之，彼所将中国人，不过十五六万，且军已久疲；所得表众，亦极七八万耳，尚怀狐疑」 | 战时估算，学界多认为大体可信 |
| 孙吴 | 周瑜请「精兵**三万**」，孙权「已选三万人」 | 《三国志·吴书·周瑜传》 | 高 |
| 刘备部 | 未载 | — | 刘备当时兵力无确数 |
| 曹军病亡 | 「大疫，吏士多死者」 | 《三国志·魏书·武帝纪》 | 无数字，但**这是曹操自己给的解释** |

**学界讨论**：八十万是宣传，十五六万＋七八万是周瑜的估算，实际参战兵力可能更低（降军未全部投入、疫病减员）。**"曹操以八十万败于五万"是演义建构，不是史实。** 但反过来说，"曹操兵力约为孙刘联军的三到四倍"这个量级是站得住的。写剧本时不要用八十万。

**地形与天气**

- 战场在长江赤壁（今湖北赤壁市西北）江面及南岸。曹军「引次江北」，周瑜「在南岸」——**两军隔江**。
- 天气（三项，全部有原文）：
  1. 「时风盛猛」（《三国志·周瑜传》）
  2. 「时东南风急」（《江表传》）
  3. 「又今盛寒，马无蒿草」（周瑜语，《三国志·周瑜传》）——**冬天，战马没有草料**
- 另有华容道撤退时的天气：「天又大风」，道「遇泥泞」（《山阳公载记》）。

**战前双方状态**

- 曹：新收荆州，降军「尚怀狐疑」；北方兵不习水土，「必生疾病」；马无草料；内部有主降派（张昭等）与主战派（周瑜、鲁肃）之争，但这是东吴的内部矛盾。
- 孙刘：鲁肃、周瑜主战，孙权「拔刀斫前奏案曰：诸将吏敢复有言当迎操者，与此案同！」
- 疫病：这是被严重低估的变量。曹操战后给孙权的信里自己说：「**赤壁之役，值有疾病，孤烧船自退，横使周瑜虚获此名。**」（《江表传》）——他把失败归因于疫病，还顺手否认了火攻的决定性。

**战术过程（分阶段）**

1. **初战**：「时曹公军众已有疾病，初一交战，公军败退，引次江北。」——曹军初战就退了，原因写在前面：军中已有病。
2. **诈降**：黄盖献火攻计，先「书报曹公，欺以欲降」。曹操收到信后还密问送信人：「但恐汝诈耳。」——**曹操知道可能是诈降，但还是选择观望**。
3. **火船接近**：黄盖取蒙冲斗舰数十艘，装薪草、灌膏油、裹帷幕、建牙旗，后面各系走舸。曹军「吏士皆延颈观望，指言盖降」——**全军伸长脖子看敌人来投降**。这是整场战役最生动的一个集体动作。
4. **发火**：距北军二里余，「同时发火」。「时风盛猛，悉延烧岸上营落。顷之，烟炎张天，人马烧溺死者甚众。」
5. **追击**：周瑜率轻锐继其后，「雷鼓大进」，北军大坏。曹操退保南郡，留曹仁守江陵，自北归。
6. **华容道撤退**（《山阳公载记》）：遇泥泞道不通，天又大风，**「悉使羸兵负草填之，骑乃得过。羸兵为人马所蹈藉，陷泥中，死者甚众」**。出来后曹操大喜，说「刘备，吾俦也。但得计少晚；向使早放火，吾徒无类矣」。

**关键转折点**

**火船距北军二里，风起的那一刻。**

但更"小兵"的转折点是**「曹公军吏士皆延颈观望，指言盖降」**——十万人的注意力全部朝一个方向，全部放松。这一刻没有战斗，只有观看。火就是从这里烧进去的。

**伤亡与后果**

- 「人马烧溺死者甚众」（《三国志·周瑜传》）；「大疫，吏士多死者」（《武帝纪》）。**两个数字都没有。**
- 华容道：「羸兵为人马所蹈藉，陷泥中，死者甚众」（《山阳公载记》）。
- 后果：曹操北归，刘备取荆南四郡，孙权据江东，三分之势成型。

**【小兵视角细节】**

- **「羸兵负草填之」**（《山阳公载记》）。这是全篇最好的一段小兵戏：撤退路上泥泞，曹操命令**最弱的士兵**背草去填路，让骑兵过去。结果这些背草的弱兵被人和马踩进泥里，「死者甚众」。**他们是路的一部分，不是军队的一部分。**
- **「吏士皆延颈观望，指言盖降」**。十万人伸着脖子看，还互相指点"那是黄盖来投降了"。这是胜利前一刻的全军松弛，也是死亡前一刻。
- **「军中惊乱，贼争趣辎重」**——这是香积寺之战的句子（见第 8 条），但赤壁同样有"争趣辎重"的机制：一旦阵形松动，士兵的第一反应是抢东西。
- **一封诈降信**：黄盖信里写「盖受孙氏厚恩，常为将帅，见遇不薄。然顾天下事有大势……以当中国百万之众，众寡不敌，海内所共见也」。**这是一封写给所有人看的信——包括曹军的普通士兵。** 他们信了。
- **一个被烧掉的承诺**：曹操战前给孙权写信说"今治水军八十万众，方与将军会猎于吴"。八十万这个数字，最终成了他败退时最响的一个笑话。
- **疾疫**：赤壁真正的头号杀手是病，不是火。战后曹操「诸士卒不返者皆复其家终世」这类抚恤记载在别的战役里有，赤壁没有——**因为死的大多是病死的，不算战死，可能连抚恤都没有。**

**【可玩性评估】**

**最适合：疫病 + 火攻 + 溃退泥泞。**

- 核心张力：**"我们不是在打仗，我们在生病。"** 前半段做疫病管理（营中不断有人倒下、医者不够、尸体处理），后半段做火攻瞬间的混乱，最后做华容道填路。三段情绪完全不同，很适合做关卡节奏变化。
- 强反转点：**延颈观望**。玩家所在的部队在等敌人投降，所有人都在放松，然后火来了。这是"信息误判"的完美教学关。
- 弱点：赤壁的个体记载少，且被《三国演义》严重污染。**任何"草船借箭""借东风""苦肉计"都不能用**——那是〔演义小说〕，与《三国志》无关。
- 一个可以做的细节：**填路的羸兵**。玩家扮演一个被派去背草的弱兵，任务是"让骑兵过去"。这个关卡的失败条件不是他死，是**路没填好，骑兵过不去**。

**史料出处**

- 〔正史〕《三国志·吴书·周瑜传》（含裴注引《江表传》）：<https://zh.wikisource.org/wiki/三國志/卷54>
- 〔正史〕《三国志·魏书·武帝纪》（含裴注引《山阳公载记》）：<https://zh.wikisource.org/wiki/三國志/卷01>

### 6. 淝水之战（383年，太元八年十一月）

**交战方与兵力**

| 方 | 数字 | 出处 | 存疑说明 |
|---|---|---|---|
| 前秦（发长安） | 「戎卒**六十余万**，骑**二十七万**」 | 〔正史〕《晋书·苻坚载记下》：「坚发长安，戎卒六十余万，骑二十七万，前后千里，旗鼓相望」 | 合计约八十七万，是**征发总数**，不是战场到达数 |
| 前秦（前锋） | 「步骑**二十五万**」 | 同上：「遣征南苻融……率步骑二十五万为前锋」 | 高 |
| 前秦（苻坚随身） | 「轻骑**八千**」 | 同上：「舍大军于项城，以轻骑八千兼道赴之」 | 高 |
| 前秦（洛涧） | 梁成部「**五万**」 | 同上 | 高 |
| 东晋 | 「水陆**七万**」 | 同上：「晋遣都督谢石……等水陆七万，相继距融」 | 高 |
| 东晋（夜袭） | 刘牢之「劲卒**五千**」 | 同上 | 高 |
| 东晋（渡水挑战） | 「勇士**八千人**」 | 《晋书·朱序传》：「于是石遣谢琰选勇士八千人涉肥水挑战」 | 高 |

**学界讨论**：「投鞭断流」「百万大军」是文学化的说法。《晋书》自己给的是六十余万＋二十七万的**征发总额**，且明确写「凉州之兵始达咸阳，蜀汉之军顺流而下，幽、冀之众至于彭城」——**大部分军队根本没到战场**。真正在淝水前线的是苻融二十五万前锋中的一部分。所以"八十七万被八万打败"是错的，实际参战比大致在一比二到一比三之间。**这一条对剧本很重要：不要让玩家以为对面是人海。**

**地形与天气**

- 战场在寿春（今安徽寿县）城下、淝水（肥水）两岸。晋军在西/南，秦军在东/北，「列阵逼肥水」，晋军「不得渡」。
- 季节：十一月，深秋初冬。
- 决定性"天时"是一句视觉记载：「又北望八公山上草木，皆类人形」——苻坚登城望晋军，把山上的草木看成了人。这是**恐惧造成的视觉错误**，不是天文现象。

**战前双方状态**

- 前秦：内部严重分裂。苻融、权翼、石越、道安、太子宏、少子诜全部反对南征，理由是「我数战，兵疲将倦，有惮敌之意」「鲜卑、羌、羯攒聚如林，此皆国之贼也」。苻坚一概不听，说「今有众百万，资仗如山」「吾当内断于心矣」。
- 征发方式：「**人十丁遣一兵**」（《晋书·苻坚载记下》）——每十丁抽一。这意味着**这支军队里绝大多数人是被抽来的农民**，不是职业兵。
- 东晋：内部团结（「晋主休明，朝臣用命」），北府兵精锐，但兵力处于绝对劣势，且朝廷一度只能靠「会稽王道子以威仪鼓吹求助於钟山之神」来稳定人心。
- 一个关键人物：**朱序**。原东晋襄阳守将，城破被俘，苻坚「嘉而不问，以为尚书」。他人在秦营，心在晋。

**战术过程（分阶段）**

1. **洛涧前哨**：秦梁成率五万屯洛涧，栅淮遏晋军。刘牢之率五千夜袭，「克之，斩成及王显、王咏等十将，士卒死者万五千」。**五千人夜袭，斩敌主将，杀一万五。**
2. **苻坚轻骑赴前线**：留大军于项城，以八千轻骑兼道赴寿春，下令「敢言吾至寿春者拔舌」——**连自己人都不许知道主帅到了**。
3. **登城观望**：见晋军「部阵齐整，将士精锐」，又望八公山草木「皆类人形」，对苻融说「此亦勍敌也，何谓少乎！」始有惧色。
4. **朱序告密**：苻坚派朱序去晋营劝降。朱序反而对谢石说：「若秦百万之众皆至，则莫可敌也。**及其众军未集，宜在速战。** 若挫其前锋，可以得志。」
5. **渡水请战**：晋军遣使对苻融说：「君悬军深入，置阵逼水，此持久之计，岂欲战者乎？若小退师，令将士周旋，仆与君公缓辔而观之，不亦美乎！」
6. **后撤失控**：苻融「麾军却阵，欲因其济水，覆而取之。**军遂奔退，制之不可止。**」
7. **朱序一喝**：「坚众小却，序时在其军后，唱云：『坚败！』众遂大奔。」（《晋书·朱序传》）
8. **主帅落马**：苻融「驰骑略阵，马倒被杀」。秦军大败。
9. **追击**：「王师乘胜追击，至于青冈，死者相枕。」

**关键转折点**

**朱序在后阵喊的那两个字：「坚败！」**

不是战败，是**"被告知战败"**。一个前东晋将领、现任前秦尚书，站在自己军队的后方，喊了一句假消息，八十七万人（名义上）开始跑。

《晋书·苻坚载记》和《晋书·朱序传》两处记载互相印证：一处说他在阵后「唱云坚败」，一处说他「时在其军后」。**这是中国战史上最著名的一次"信息战"，实施者是单个中层文官。**

**伤亡与后果**

- 秦军：「死者相枕」（《晋书》），无数字。苻坚「为流矢所中，单骑遁还于淮北」。
- 晋军伤亡未载。
- 后果：前秦崩溃。慕容垂、姚苌相继叛，苻坚两年后被杀。**一场战役解散了一个帝国。**
- 抚恤：苻坚回到长安后「诸士卒不返者皆复其家终世」——**战死者的家属终身免赋役**。这是《晋书》里很少见的一条士兵善后记载。

**【小兵视角细节】**

- **「人十丁遣一兵」**。每十户抽一人。这意味着秦军士兵**彼此都认识**——同村、同里、同宗。这也解释了为什么一崩就全崩：跑的那个人是他邻居。
- **「闻风声鹤唳，皆谓晋师之至」**。八个字，写的是**听觉幻觉**。追兵已经停了，但耳朵还在追。这是最适合做音量设计的一句史料。
- **「饥甚，人有进壶飧豚髀者」**。苻坚单骑逃到淮北，饿得不行，有个人给他送来一壶饭和一条猪腿。苻坚大为感动，要赏他帛十匹、绵十斤。
- **那个送饭的人拒绝了**：「臣闻白龙厌天池之乐而见困豫且，陛下目所睹也，耳所闻也。今蒙尘之难，岂自天乎！**且妄施不为惠，妄受不为忠。** 陛下，臣之父母也，安有子养而求报哉！」说完「弗顾而退」。
  **这是整个素材库里最好的一段无名者独白。** 一个连名字都没留下的人，给亡国之君送了一顿饭，拒绝赏赐，说了一句"你落到今天不是天意"，然后头也不回地走了。**他不肯被记住。**
- **朱序的母亲韩氏**（《晋书·朱序传》，襄阳围城时）：「序母韩自登城履行，谡西北角当先受弊，遂领百余婢并城中女子于其角斜筑城二十余丈。贼攻西北角，果溃，众便固新筑城。」——**一个老太太带着一百多个婢女和城里的女人，在西北角斜着筑了二十多丈的城墙。** 后来襄阳人称这段为"夫人城"。她判断对了：敌人正是从西北角攻破的。
- **「死者相枕」**。尸体互相枕着。这是追击战的画面，不是战斗的画面。
- **「八公山上草木，皆类人形」**。这是恐惧的视觉化。写关卡时，可以让玩家在远处看到一片"伏兵"，走近发现是树。

**【可玩性评估】**

**最适合：信息误判 + 后退变溃退。**

- 核心张力：**"退"和"溃"之间没有中间态。** 命令是"后退一点，让他们渡河"，执行时变成"全军跑了"。这个转换点可以做成一整关：玩家是后阵的一名士兵，听见前面在退，不知道该退还是该站住。
- 天然反转：**朱序的那句喊**。可以做成玩家的选择——玩家扮演朱序身边的传令兵/随从，看他在阵后张嘴。**玩家可以选择跟着喊，或者不喊。** 这是全素材库里唯一一个"一个人一句话改变一场战役"的可交互瞬间。
- 天然反转二：**送饭的人**。可以做结尾：一个无名农夫给逃兵一碗饭，然后拒绝一切。**不做任何解释。**
- 5 视角可行性：中。秦军步卒 / 秦军传令 / 晋军北府兵 / 朱序随从 / 送饭农夫——**农夫这个视角是虚构的，但"有人进壶飧豚髀"是史实**，可以按史实补白。
- 弱点：秦军士兵的具体名字一个都没有。要靠器物和动作补。

**史料出处**

- 〔正史〕《晋书·朱序传》：<https://zh.wikisource.org/wiki/晉書/卷081>

### 7. 睢阳之战（757年，至德二载正月—十月）

**交战方与兵力**

| 方 | 数字 | 出处 | 存疑说明 |
|---|---|---|---|
| 唐（张巡入睢阳时） | 「马裁**三百**，兵**三千**」 | 〔正史〕《新唐书·张巡传》：「巡外失巨依，拔众保宁陵，马裁三百，兵三千。至睢阳，与太守许远、城父令姚訚等合」 | 高。这是张巡本部，另有许远所部，合计数无载 |
| 唐（守军总数） | 「众**六万**」 | 《新唐书·张巡传》：「时议者或谓：巡始守睢阳，众六万」 | **这是战后批评者的说法**，非官方统计，且与"兵三千"矛盾，存疑 |
| 唐（围城初期城中人口） | 「城中**数万口**」 | 《旧唐书·张巡传》引南霁云语：「初围城之日，城中数万口」 | 城中含百姓 |
| 燕（尹子奇） | 未载 | 两《唐书》均只作「贼将尹子奇攻围经年」 | **任何"十余万"的说法都没有两《唐书》依据**〔存疑推断〕 |
| 唐（城破时幸存） | 「不过**数千**」 | 《旧唐书》引南霁云语：「今见存之数，不过数千」 | 高 |
| 唐（被食人口） | 「**二三万**」 | 《旧唐书·张巡传》：「乃括城中妇人；既尽，以男夫老小继之，所食人口二三万」 | 高（史书明载），但是全篇最黑暗的数字 |
| 唐（城破遇害） | 「**三十六人**」 | 《新唐书·张巡传》：「乃与姚訚、雷万春等三十六人遇害」 | 高 |

**学界/史料本身的争议**：张巡守睢阳是否值得，唐代当时就有争论。《新唐书》原文保存了反方意见：「时议者或谓：巡始守睢阳，众六万，既粮尽，不持满按队出再生之路，与夫食人，宁若全人？」——**当时就有人问：与其吃人，不如带人突围。** 张淡、李纾、董南史、张建封等名士反驳，理由是睢阳「蔽遮江淮，沮贼势，天下不亡，其功也」。**这个争论本身就是最好的剧本材料：它没有答案。**

**地形与天气**

- 睢阳（今河南商丘）是江淮屏障，运河节点。**守睢阳＝守江淮的粮道。**
- 天气：十月癸丑城破，深秋。史料无战场天气记载。
- 有一个天气细节极重要（《新唐书·张巡传》）：南霁云突围回城那夜，「**方大雾**，巡闻战声，曰：『此霁云等声也。』」——**大雾里，张巡是靠听声音认出自己人的。**

**战前双方状态**

- 唐：孤城，外无援。周边贺兰进明（临淮）、许叔冀（彭城）、尚衡「皆观望莫肯救」。**内部还有矛盾**：贺兰进明与房琯不和，许叔冀「恃部下精锐，又名位等于进明，自谓匹敌，不受进明节制」，贺兰进明「惧叔冀见袭」，所以不敢分兵。
- 燕：尹子奇围城经年，屡攻不下。张巡曾「剡蒿为矢」诱使敌军来报"城中箭尽"，从而认出尹子奇，命南霁云一箭射中其左目。
- 补给：从有粮到无粮到「易子而食，析骸而爨」到食人。**这是本素材库里补给曲线最完整的一战。**

**战术过程（分阶段）**

1. **前期（守）**：张巡与许远合兵守城。张巡用兵极活：夜鸣鼓严队，装作要出击，燕军整夜戒备；「俄自鼓，贼觇城上兵休，乃弛备」——**等敌人放松了才真的出兵**。这是空营计的原型。
2. **出击（宁陵北）**：遣雷万春、南霁云领兵战宁陵北，「斩贼将二十，杀万余人，投尸于汴，水为不流」。
3. **斩将拔旗**：「巡使南霁云等开门径抵子琦所，斩将拔旗。」
4. **射目**：剡蒿为矢 → 敌军以为城中箭尽 → 报尹子奇 → 尹子奇亲至 → 南霁云「一发中左目」。
5. **粮尽**：「城中粮尽，易子而食，析骸而爨，人心危恐，虑将有变。」
6. **杀妾飨军**：张巡「乃出其妾，对三军杀之，以飨军士」，说「诸公为国家戮力守城，一心无二，经年乏食，忠义不衰。巡不能自割肌肤，以啖将士，岂可惜此妇，坐视危迫」。将士皆泣下，不忍食，张巡「强令食之」。
7. **括妇人，继以男夫老小**：「所食人口二三万」。
8. **求援**：南霁云夜缒出城，先至许叔冀处，不应；再到临淮见贺兰进明。贺兰「张乐高会，无出师意」，还想把他留下。
9. **断指**：南霁云泣告无用，说「请啮一指，留于大夫，示之以信」，当场拔刀断指，「一座大惊，为出涕」。又「抽矢回射佛寺浮图，矢著砖，曰：『吾破贼还，必灭贺兰，此矢所以志也！』」
10. **回城**：至真源得马百匹，至宁陵得廉坦兵三千，夜冒围入，「且战且引，兵多死，所至才千人」。大雾中张巡回城，将士「相持泣」。
11. **城破**：十月癸丑，「贼攻城，士病不能战」。城陷。张巡、许远、南霁云、姚訚、雷万春等三十六人遇害。张巡死前「西向再拜」，说「臣智勇俱竭，不能式遏强寇，保守孤城。臣虽为鬼，誓与贼为厉，以答明恩」。

**关键转折点**

**南霁云从临淮回来、绳城而入，城中将吏知道援军不会来了的那一天。**

《旧唐书》原文只有一句：「**城中将吏知救不至，恸哭累日。**」

这不是战术转折，是**希望被移除的那一刻**。城又守了几个月，但那几个月里所有人都在知道自己会死的前提下守城。

**伤亡与后果**

- 城内：被食「二三万」；城破时存「数千」；遇害「三十六人」。
- 燕军：无总数。
- 后果：城破后十日，广平王收东京（洛阳）——**睢阳多守的每一天，都在为唐廷争取时间**。唐肃宗下诏赠张巡扬州大都督、许远荆州大都督、南霁云开府仪同三司。睢阳立庙，号「双庙」。

**【小兵视角细节】**

**这一节是全部素材里最富的，建议重点取材。**

- **南霁云**（《新唐书·南霁云传》）：
  > 「南霁云者，魏州顿丘人。**少微贱，为人操舟。**」

  **一个撑船的。** 安禄山反后，巨野尉张沼起兵，把他提拔为将。他先跟尚衡，被派到睢阳出差，回去对人说：「**张公开心待人，真吾所事也。**」尚衡送金帛来接他，他不受，留下不走。

  围城之初，张巡「筑台募万死一生者，**数日无敢应**。俄有**喑鸣而来者**，乃霁云也。巡对泣下。」

  「喑鸣」是哭不出声。**募了几天没人应，最后走出来一个哭得说不出话的人。** 张巡看着他哭了。

  「霁云善骑射，**见贼百步内乃发，无不应弦毙**。」——一百步内才射，这是纪律，也是保命的算术（箭少）。

- **断指**（《新唐书》）：「因拔佩刀断指，一座大惊，为出涕。**卒不食去。**」——断了指，一口饭都没吃就走了。
- **射塔**：「抽矢回射佛寺浮图，矢著砖，曰：『吾破贼还，必灭贺兰，此矢所以志也！』」——**他把誓约射进了一座佛塔的砖里。** 这个动作是全篇最好的一个"物件叙事"：一支箭，钉在砖上，谁都可以去看。
- **「南八！」**（《新唐书·张巡传》）城破后张巡被胁降，敌人转而劝降南霁云，南霁云没应声，张巡喊：「**南八！男儿死尔，不可为不义屈！**」南霁云笑了，说：「欲将有为也，公知我者，敢不死！」——**"南八"是排行称呼。将军在最后关头喊的是他家排行，不是他的官职。**
- **二十一个有名有姓的别将**（《新唐书·张巡传》）：

  > 「巡之遣霁云、万春败贼于宁陵也，别将二十有五：**石承平、李辞、陆元锽、朱珪、宋若虚、杨振威、耿庆礼、马日升、张惟清、廉坦、张重、孙景趋、赵连城、王森、乔绍俊、张恭默、祝忠、李嘉隐、翟良辅、孙廷皎、冯颜**，其后皆死巡难，**四人逸其姓名**。」

  **二十一个名字，全部死于此役；另外四个人连名字都没留下。** 这是全素材库里最珍贵的一串名单——正史极少这样成批地记录低级军官。可以直接做成"阵亡名录"的第一批内容。
- **陆家姑**（《新唐书·张巡传》）：「巡有姊嫁陆氏，遮王劝勿行，不纳，赐百缣，弗受，**为巡补缝行间，军中号「陆家姑」，先巡被害**。」——张巡的姐姐，跟着军队缝补衣服，军中叫她"陆家姑"，死在弟弟之前。
- **雷万春**：「万春将兵，方略不及霁云，而**强毅用命**。每战，巡任之与霁云钧。」——一个不如南霁云聪明但死战不退的人。
- **食人的执行细节**（《旧唐书》）：张巡杀妾时说的是「巡不能自割肌肤，以啖将士，岂可惜此妇，坐视危迫」，然后「**强令食之**」。这四个字是全部材料里最难写的一句：不是士兵抢着吃，是将军强迫他们吃。
- **守城的日常**：缒城（用绳子把人从城墙上放下去）、绳城而入（拉上来）、剡蒿为矢（削蒿杆当箭）、驱贼牛数百入城。这些都是**动作**，都可以做成交互。

**【可玩性评估】**

**情感强度全素材库第一，但有一条内容红线必须处理。**

- 核心张力：**"我们守的这座城，已经不是在救人，是在拖时间。"** 每一个士兵都知道援军不会来，但命令还在。
- 最好的关卡结构（按史实顺序）：
  1. **守城**（缒城、绳城、削蒿为矢、射目）——技巧关
  2. **求援**（南霁云出城、被拒、断指、回城）——这是全素材库最好的"传令/求援"关：**玩家带着使命出去，带着失败回来，而城里的人在等他**
  3. **断粮**（马、鼠、茶纸、妇人、老弱）——资源关
  4. **城破**（三十六人）——结算关
- **红线**：食人不能做成可操作的资源管理，也不能做成"选择吃谁"。建议处理方式：**不做过程，只做后果**——玩家在第三幕开始时看到城中已无炊烟，看到长官在写名单，不需要看见具体发生了什么。史书已经写了，游戏不必画出来。
- 天然反转：**南霁云断指**。玩家可以扮演南霁云身边的随从，看他把手指砍下来。**这个动作不需要任何解释。**
- 天然反转二：**大雾中的辨认**。张巡靠听声音认出南霁云。可以做成一关：大雾，只有声音，玩家要判断来的是敌是友。**这正是 01 文档 M2"盲听关"最完美的史实落点。**
- 5 视角可行性：**最高。** 弓手（南霁云部）/ 守城步卒 / 传令（缒城求援）/ 火头军（断粮后的炊事）/ 文书（记三十六人名）。五个兵种全部有史实支撑。

**史料出处**

- 〔正史〕《旧唐书·忠义下·张巡传》（含姚訚、许远附传）：<https://zh.wikisource.org/wiki/舊唐書/卷187下>
- 〔正史〕《新唐书·忠义中·张巡传》（含南霁云、雷万春附传，二十五个别将名单）：<https://zh.wikisource.org/wiki/新唐書/卷192>

### 8. 香积寺之战（757年，至德二载九月）

**交战方与兵力**

| 方 | 数字 | 出处 | 存疑说明 |
|---|---|---|---|
| 唐（含回纥、西域） | 「**十五万**，号二十万」 | 〔编年〕《资治通鉴》卷220：「元帅广平王俶将朔方等军及回纥、西域之众十五万，号二十万，发凤翔」 | 高。「号二十万」是宣传 |
| 唐（回纥） | 「精兵**四千余**」 | 同上：「怀仁可汗遣其子叶护及将军帝德等将精兵四千余人来至凤翔」 | 高 |
| 燕（安庆绪） | 「贼众**十万**」 | 同上：「贼众十万陈于其北」 | 高 |
| 燕（陕州余部） | 「步骑犹**十五万**」 | 同上 | 高 |
| 唐（单日斩首） | 「**六万**级」 | 同上：「自午及酉，斩首六万级，填沟堑死者甚众」 | 高（史书明载），但是**六小时六万**，密度极高，宜标"史载"而非"实测" |

**学界讨论**：斩首六万在六小时内完成（自午及酉，约午前十一时到午后七时），折算每分钟约一百七十人，这个密度在现代冷兵器研究中被认为偏高，可能包含"填沟堑死者"与伤重而死者。但**它作为"这一战极其血腥"的量级判断是站得住的**，且《通鉴》把"填沟堑死者"另计，说明六万只是斩首数。

**地形与天气**

- 战场在长安城西、香积寺北、沣水（澧水）之东。**唐军背水列阵，燕军在北。**
- 天气无直接记载。新店之战有「**黄埃**」中发矢的记载（见下），可推关中九月多风沙〔存疑推断〕。
- 时间跨度是关键：「**自午及酉**」——从中午打到天黑，六个小时。这是一场**没有间歇的消耗战**。

**战前双方状态**

- 唐：借回纥兵，代价写在条约里——「初，上欲速得京师，与回纥约曰：『克城之日，**土地、士庶归唐，金帛、子女皆归回纥**。』」**这是唐廷自己签的条约：城破之后，人可以归唐，财物和女人归回纥。**
- 燕：安庆绪主力十万，李归仁为前锋，战斗力强（安禄山旧部边军）。
- 唐军内部：广平王俶（代宗）为名义元帅，郭子仪实际指挥，李嗣业前军、郭子仪中军、王思礼后军。

**战术过程（分阶段）**

1. **接战失利**：燕将李归仁出挑战，唐军逐之，被诱至燕军阵前。燕军齐进，唐军却，「军中惊乱，**贼争趣辎重**」——燕军士兵跑去抢唐军的辎重。
2. **李嗣业肉袒立阵**：「嗣业曰：『今日不以身饵贼，军无孑遗矣。』乃**肉袒，执长刀，立于阵前，大呼奋击，当其刀者，人马俱碎，杀数十人，阵乃稍定**。」
3. **陌刀如墙**：「嗣业帅前军**各执长刀，如墙而进**，身先士卒，所向摧靡。」
4. **王难得中箭**：「都知兵马使王难得救其裨将，**贼射之中眉，皮垂鄣目。难得自拔箭，掣去其皮，血流被面，前战不已**。」
5. **伏兵与反伏**：燕军伏精骑于阵东欲袭唐军之后，唐军侦知，仆固怀恩引回纥击之，「翦灭殆尽，贼由是气索」。
6. **前后夹击**：李嗣业与回纥出燕军阵后，与大军交击。
7. **结果**：「自午及酉，斩首六万级，填沟堑死者甚众，贼遂大溃。余众走入城，迨夜，嚣声不止。」

**关键转折点**

**李嗣业脱掉上衣、拿着长刀站到阵前的那一分钟。**

《通鉴》写得很清楚：唐军当时已经在退，军心已乱，是**一个将领走到阵前，用身体当墙**，才把阵稳住。「当其刀者，人马俱碎，杀数十人」——他一个人杀了数十人，然后「阵乃稍定」，然后全军才「如墙而进」。

**这是一个人的动作改变了六小时战局。** 而且他不是在后面指挥，他在最前面，脱了甲。

**伤亡与后果**

- 燕军：「斩首六万级，填沟堑死者甚众」。余众入城，「迨夜，嚣声不止」——**夜里城里一直有哭喊声**。
- 唐军伤亡未载。
- 后果：当日收复长安。三日后（壬戌）入东京洛阳。
- **黑暗的后果**：「回纥意犹未厌，俶患之。父老请率罗锦万匹以赂回纥，回纥乃止。」——**洛阳百姓凑了一万匹锦缎，才把条约里的"子女"赎回来。**
- 另一个细节：「百姓、军士、胡虏见俶拜者，皆泣曰：『广平王真华、夷之主！』」——广平王给回纥叶护下拜，求他先不要抢长安。**士兵和百姓看着自己的王子给外族下拜。**

**【小兵视角细节】**

- **王难得拔箭撕皮**（《资治通鉴》卷220）。这是全素材库最具体的一个伤情描写：箭射中眉心，**眼皮垂下来挡住了眼睛**，他自己把箭拔出来，**把眼皮撕掉**，血流满面，继续往前打。一个"都知兵马使"（中低级军官），救的是自己的裨将。
- **「贼争趣辎重」**。燕军士兵在唐军阵脚松动时，第一反应是去抢辎重。**阵就是这么破的**——不是被打穿的，是被自己的贪欲拆开的。
- **「军中惊乱」**。四个字，是六小时血战的开场状态。
- **「填沟堑死者甚众」**。这句话的意思是：有很多人不是被砍死的，是被挤进沟里、被后面的人踩死的。
- **「迨夜，嚣声不止」**。天黑了，长安城里声音不停。**这是战胜方视角听到的敌城的声音。**
- **「金帛、子女皆归回纥」**。这是唐廷签的条约，唐军士兵全都知道。**他们拼命打下来的城，财物和女人不归他们，归盟友。** 这一条对理解唐军士兵的心理极重要。
- **一支箭的算术**：唐军「人具弓一，矢三十」（《新唐书·兵志》）。三十支箭打完，就得靠刀。六小时的仗，箭早就没了。
- **一个文官的死**：宁远之战里放炮而死的金启倧（见第 10 条），香积寺没有对应记载，但可以推知：**陌刀队后面有大量非战斗人员在搬运、救护、填沟**，他们的死亡率不写在战报里。

**【可玩性评估】**

**最适合：前排消耗战（"墙"的感觉）。**

- 核心张力：**"我们不是要赢，我们是要站住。"** 唐军的任务从头到尾不是击溃，是**不让阵散**。玩家的失败条件不是死，是"阵出现缺口"——和 01 文档 M3 的设计完全一致。
- 天然机制：**陌刀如墙**。玩家是一堵墙里的一块砖，左右都是人，前面是马蹄。**这个视角在游戏史里几乎没有被做过。**
- 天然反转：**阵脚松动 → 争趣辎重 → 李嗣业肉袒**。可以做成一关：玩家所在的队列开始退，然后听见前面有人大吼，抬头看见一个脱了上衣的人站在那。
- 天然反转二：**条约**。战后可以做一幕：长安城门口，回纥骑兵进城，唐军士兵站在路边看着。**不需要台词。**
- 弱点：个体名字少（王难得、李嗣业），5 视角要补白。但"陌刀手/弓手/回纥骑/辎重兵/文书"五个兵种都有史实依据。

**史料出处**

- 〔编年〕《资治通鉴》卷220（至德二载九月）：<https://zh.wikisource.org/wiki/資治通鑑/卷220>

### 9. 土木堡之变（1449年，正统十四年八月）

**交战方与兵力**

| 方 | 数字 | 出处 | 存疑说明 |
|---|---|---|---|
| 明 | **《明史》未载总数** | 〔正史〕《明史·曹鼐传》《明史·邝埜传》均只作「六师」「扈驾出关」，无兵数 | 通行的"二十万""号称五十万"来自后世推算，非《明史》原文〔存疑推断〕 |
| 瓦剌（也先） | 未载 | 《明史》无数字 | 通行"二三万"为推算〔存疑推断〕 |
| 明（死亡官员） | 「将相大臣及从官死者不可胜数」 | 《明史·曹鼐传》 | 有人名可考者三十余人，见下 |
| 明（未至大同已乏粮） | 定性记载 | 《明史·曹鼐传》：「未至大同，**士卒已乏粮**」 | 高 |

**为什么这一战的兵力数字特别不可信**：明代京营在正统年间名义编制庞大，但实际在营人数长期不足；英宗出师仓促，各路兵马并未齐集。**《明史》三处相关列传（曹鼐、邝埜、王佐）全都回避了总数**，这本身就是一个信号。写剧本时建议**完全不给数字**，只给"走了几天、还有几天粮、还剩多少水"。

**地形与天气**

- 土木堡（今河北怀来东）地势高。决定性的一句：**「地高，掘地二丈不及水」**（《明史·曹鼐传》）。**挖了两丈深没有水。**
- 瓦剌军「据南河」——**敌人占着河**。
- 回程天气（袁彬《北征事迹》记十月）：「**连日雨雪，上下艰难。**」
- 另有一处极重要的天气记载在紫荆关方向（《明史·谢泽传》）：「**大风扬沙，不辨人马。**」

**战前双方状态**

- 明：仓促亲征，王振专权，「不与外廷议可否」。行军途中已在缺粮。大同前线败报（宋瑛、朱冕全军覆没）传来后，才想回师。
- 内部：文臣跪求班师而不得。「大将朱勇膝行听命，尚书邝埜、王佐**跪草中**，至暮不得请。」——**两个尚书跪在草里，跪到天黑也没能见到皇帝。**
- 瓦剌：也先主动追击，掌握机动。

**战术过程（分阶段）**

1. **出师与回师**：七月出关，八月到大同，闻败报欲还。原拟从紫荆关入（距四十余里），因王振想邀皇帝到蔚州「幸其第」，改道东行趋居庸关——**多走了几百里**。
2. **次土木**：「八月辛酉次土木。」就地扎营，无水。
3. **被围**：「瓦剌大至，据南河。」
4. **诈和**：「明日佯却，且遣使通和。帝召鼐草诏答之。」
5. **移营**：「振遽令移营就水，**行乱**。」
6. **崩溃**：「寇骑蹂阵入，帝突围不得出，拥以去。」

**关键转折点**

**「振遽令移营就水，行乱。」**

六个字。全军忍着渴，听说可以去河边了，队形在移动的瞬间散掉。**这不是被打败的，是在"去喝水"的路上散掉的。**

袁彬的记载补了一个更小的视角：他被俘是在**八月十五日**，也就是移营前后；他在乱军中被一个叫「赛伏剌」的回回抓住。

**伤亡与后果**

- 「六师覆于土木，将相大臣及从官死者不可胜数」（《明史·曹鼐传》）。
- 可考姓名者：英国公张辅、泰宁侯陈瀛等勋臣；户部尚书王佐、兵部尚书邝埜、内阁学士曹鼐、张益；给事中包良佐、姚铣、鲍辉、张洪、黄裳、魏贞、夏诚、申祐、尹竑、童存德、孙庆、林祥凤；庶寮齐汪、冯学明、王健、程思温、程式、逯端、俞鉴、张瑭、郑瑄、俞拱、潘澄、钱昺、马预、尹昌、罗如墉、刘信、李恭、石玉等（《明史·曹鼐传》附列）。
- 后果：英宗被俘，郕王即位（景泰帝），于谦守北京。**明朝从此转入长期防御。**

**【小兵视角细节】**

**这一战的一手材料质量是全素材库最高的，因为有一个当事人写了第一人称回忆录。**

- **袁彬《北征事迹》（锦衣卫校尉自述，全文存世）**：
  - 开篇即自陈身份与遭遇：「**正统十四年八月十五日，臣在土木，为回回赛伏剌所虏。**」——被一个叫赛伏剌的回回抓住。
  - 第二天在乱军里认出了皇帝：「十六日，皇上在雷家站高岗地上众坐，达子围着。是臣远观，认的是我英宗皇帝。**臣叩头哭**，上问：『你是甚么人？』臣说是校尉。」
  - **皇帝教他撒谎**：「当奉圣旨：『你不要说是校尉，只说是原在家跟随的指挥。』」
  - **决定命运的一问**：「又问『**你会写字不会？**』臣说会写。就令在左右随侍答应。」
  - **他下河牵马**：「星月上时，随上渡宣府河，**臣下水控马**，渡讫。」
  - **他差点被肢解**：「喜宁与也先说，都是校尉袁彬拨置阻住，将臣赚去芦苇地内捆了，**欲开剥**。忠勇伯密令人走报，上令哈铭与也先说饶臣死，方解皮条放了。」
  - **他用腋下给皇帝暖脚**：「时天寒甚，臣得宿寝傍。每至中夜，令臣**伏卧内，以两胁温上足**。」（《明史·袁彬传》亦载：「天寒甚，恒以胁温帝足。」）
  - **皇帝也给他暖过**（《明史·袁彬传》）：「彬尝中寒，帝忧甚，**以身压其背，汗浃而愈**。」
  - **他最后得到的**：景泰元年「蒙升臣试百户」；天顺元年英宗复位，「升臣指挥佥事」「钦赐第一所于澄清坊」「赐银三百两」，还替他主婚娶妻。
  - **这份文本的性质**：它是成化元年袁彬应史馆之请写的题本（「锦锦衣卫掌卫事都指挥佥事臣袁彬谨题，为纂修事」）。**一个当年的小校尉，二十年后被叫去口述历史。**
- **哈铭**（《明史·袁彬传》）：「有哈铭者，蒙古人。幼从其父为通事，至是亦侍帝。」他负责给皇帝和也先之间传话，还陪皇帝说话解闷：「二人时进谐语慰帝，帝亦为解颜。」
- **一个夜不收总旗的营救**（袁彬《北征事迹》，二十二日）：「有**夜不收杨总旗**来与臣说：『今夜有五个夜不收来，密请爷爷石佛寺去，待他寻不见时，便乘间入城去。』臣备奏知，上曰：『**此危事，使不得。先在土木时不曾死，我命在天**，若万一不虞，如何好？』遂不用其计。」
  **五个侦察兵摸到营外，要带皇帝跑。皇帝拒绝了，理由是"我的命在天"。** 这是全素材库里最好的"救援任务"原型，而且是**真实失败过的一次**。
- **邝埜**（《明史·邝埜传》）：「振怒曰：『腐儒安知兵事，**再言者死**！』埜曰：『**我为社稷生灵言，何惧？**』振叱左右扶出。埜与佐**对泣帐中**。明日，师覆，埜死，年六十五。」——两个尚书在帐篷里对着哭，第二天全军覆没。
- **罗如墉**（《明史·曹鼐传》附）：「从北征，濒行，**诀妻子，誓以死报国，属翰林刘俨铭其墓**。俨惊拒之，如墉笑曰：『**行当验耳。**』后数日果死。」——他出发前请人给他写墓志铭，人家吓得不肯写，他笑着说"很快就应验了"。
- **俞鉴**（同上）：「驾北征，郎中胡宁当从，以病求代，鉴慷慨许诺。或曰：『家远子幼奈何？』鉴曰：『**为国，臣子敢计身家！**』」——他是**替一个称病的人去死的**。
- **袁敏**（《明史·袁彬传》附，金齿卫知事，应募从军）上书景帝：「上皇曩居九重，所服者衮绣，所食者珍羞，所居者琼宫瑶室。**今驾陷沙漠，服有衮绣乎？食有珍羞乎？居有宫室乎？**」——一连三个问句，是全篇最沉的一段奏疏。
- **孙祥**（《明史·曹鼐传》附，紫荆关守将）：「祥督兵巷战，兵溃被杀，言官误劾祥弃城遁。寇退，有司修关，**得其尸战地，焚而瘗之，不以闻**。」——尸体在战场上找到，烧了埋了，**没有人上报**。
- **「掘地二丈不及水」**。这是这一战最具体的一个身体感受：全军几万人，在黄土高地上往下挖两丈，没有水。

**【可玩性评估】**

**最适合：断水 + 移营 + 溃散 + 护驾。是全素材库"传令/护驾"类关卡的最佳载体。**

- 核心张力：**"我们不是被包围了，我们是没水喝。"** 这个张力极其具体，可以做成一整关的资源管理：水囊见底、马匹倒毙、士兵开始挖地。玩家不需要看见敌人，只需要看见干土。
- 天然反转：**可以走了，然后全散了**。玩家所在的部队听见"移营就水"的命令，队伍开始动，然后队形散掉，然后骑兵来了。**命令本身就是溃败的原因。**
- 天然反转二：**皇帝就在那里**。一个校尉在乱军里认出了皇帝，跪下哭。这个瞬间可以做成一整关的高潮，而且**史实里真的是一个小人物先认出了他**。
- 5 视角可行性：**最高（与睢阳并列）。**
  | 兵种 | 史实依据 |
  |---|---|
  | 锦衣校尉（袁彬） | 有完整第一人称自述 |
  | 夜不收（杨总旗等五人） | 「今夜有五个夜不收来」 |
  | 京营步卒 | 「士卒已乏粮」「行乱」 |
  | 通事（哈铭） | 「蒙古人，幼从其父为通事」 |
  | 文书 | 袁彬因「会写字」被留下；且《北征事迹》本身就是他写的题本 |
- **现成的"文书/记功"环节**：这是全素材库唯一一个**史料本身就是一份文书**的战役。袁彬《北征事迹》是一份题本，是成化元年应史馆之请写的。**整个游戏可以结束在"一个老校尉在灯下写二十年前的事"这个画面上。** 这比任何虚构的"文书记功"反转都更硬。
- 弱点：土木堡没有旗鼓对阵的场面，01 文档的 M1/M2（旗/鼓）在这一战里用不上。**这一战的机制重心是"传令/护驾/资源"，不是"阵形"。**

**史料出处**

- 〔正史〕《明史》卷167《曹鼐传》《邝埜传》《王佐传》《袁彬传》（附哈铭、袁敏）：<https://zh.wikisource.org/wiki/明史/卷167>
- 〔私记〕袁彬《北征事迹》（全文）：<https://zh.wikisource.org/wiki/北征事跡>

### 10. 宁远之战（1626年，天启六年正月）

**交战方与兵力**

| 方 | 数字 | 出处 | 存疑说明 |
|---|---|---|---|
| 明（守军） | **未载总数** | 〔正史〕《明史·袁崇焕传》只记「集将士誓死守」，无兵数 | 通行"万余人"为推算〔存疑推断〕 |
| 后金 | **未载总数** | 《明史》只作「举大军西渡辽河」 | 明方情报称"十三万"，清方无确数；现代研究多估五至六万，均〔存疑推断〕 |
| 明（官方战果） | 「奴夷首级**二百六十九颗**、活夷一名、降夷十七名」 | 〔典章会典〕《明熹宗实录》卷七十，兵部覆辽东经略高第题宁远捷功 | **高。这是这一战唯一可确证的杀伤数字** |
| 明（犒赏优恤用银） | 「一万八千三百六十六两有奇」 | 《明熹宗实录》卷七十，蓟辽总督王之臣查报 | 高 |
| 后金（觉华岛） | 「杀参将金冠等及**军民数万**」 | 《明史·袁崇焕传》 | 高 |

**一个必须说清的事**：宁远之战被称为"大捷"，但**明方自己报上去的斩首数只有二百六十九颗**，而同期觉华岛被屠军民数万。这两组数字放在一起，比任何评论都清楚。**写剧本时应当用 269 这个真实数字，而不是"大炮轰死数万"。**

**地形与天气**

- 宁远卫城（今辽宁兴城），袁崇焕重修的城：「高三丈二尺，雉高六尺，址广三丈，上二丈四尺」（《明史·袁崇焕传》）——**这是全素材库里唯一给出精确城防尺寸的一战**，可以直接做关卡地图。
- 时间：天启六年正月二十三日至二十六日，**隆冬**。史料未记具体天气。
- 城防关键：「先是督镇以城狭，炮不得展，城垛设一板，前置城径，后接民居，使有余地，得便安置。至是工未毕」——这句出自《扬州十日记》，说的是扬州，但机制相同：**炮位是临时搭的，工程没完工。**

**战前双方状态**

- 明：高第代孙承宗后，「谓关外必不可守」，下令尽撤锦州、右屯、大凌河守具，「尽驱屯兵入关，委弃米粟十余万，而死亡载途，哭声震野，民怨而军益不振」。袁崇焕拒绝撤宁远：「**我宁前道也，官此当死此，我必不去。**」
- 后金：努尔哈赤亲征，此前连下辽阳、沈阳、广宁，明军望风而溃。
- 一个残酷的准备动作：**「乃尽焚城外民居，携守具入城，清野以待。」** 烧掉城外所有民房。**这些房子里住的是明国人。**

**战术过程（分阶段）**

1. **誓师**：「崇焕更**刺血为书**，激以忠义，**为之下拜**，将士咸请效死。」——他给士兵下拜。
2. **清野**：焚城外民居，收守具入城。
3. **肃反与督战**：「令同知程维楧诘奸，通判启倧具守卒食，辟道上行人。檄前屯守将赵率教、山海守将杨麒，**将士逃至者悉斩**，人心始定。」
4. **攻城**：「明日，大军进攻，**载楯穴城，矢石不能退**。」——后金用楯车掩护，挖城墙。**冷兵器攻城的标准作业。**
5. **炮击**：「崇焕令**闽卒罗立**，发西洋巨炮，伤城外军。」
6. **再攻再却**：「明日，再攻，复被却，围遂解。」
7. **代价**：「而启倧亦以**然炮死**。」——通判金启倧在点炮时死了。

**关键转折点**

**第一炮打出去的那一下。**

《明史》写得很克制：「发西洋巨炮，伤城外军」。没有"死者无数"，没有"尸横遍野"。真正的转折是**后金军发现这个城打不下来**——他们此前的经验是明军望风而逃，这一次遇到了不跑的。

而操作那门炮的人，是一个福建兵，叫**罗立**。

**伤亡与后果**

- 后金：官方战果 269 级（《明熹宗实录》卷七十）。
- 明：金启倧死；觉华岛「杀参将金冠等及军民数万」。
- 后果：努尔哈赤退兵，八月死（死因与宁远炮伤的关系〔存疑推断〕，清方记载未提炮伤）。袁崇焕擢右佥都御史。明廷称"宁锦大捷"。

**【小兵视角细节】**

- **罗立**（《明史·袁崇焕传》）：「崇焕令**闽卒罗立**，发西洋巨炮。」——五个字，一个福建兵的名字。他不是将领，是**炮手**。整个宁远大捷的官方叙述里，唯一被点名操作的士兵就是他。
- **金启倧**（同上）：「通判启倧具守卒食」，后来「以然炮死」。**一个管粮草的文官，最后死在炮位上。** 他此前还上书反对撤军：「锦、右、大凌三城皆前锋要地。倘收兵退，既安之民庶复播迁，已得之封疆再沦没，关内外堪几次退守耶！」
- **「尽焚城外民居」**。烧的是自己人的房子。写这一幕时不需要任何台词：士兵拿着火把，站在自己邻居的家门口。
- **「将士逃至者悉斩」**。往后方跑的，杀。这条命令是袁崇焕下的，而且他真的执行了（他此前「尝核虚伍，立斩一校」，孙承宗怒问「监军可专杀耶」）。
- **「刺血为书」「为之下拜」**。主帅给士兵下拜，这是极罕见的动作。士兵的反应是「咸请效死」。
- **觉华岛的数万人**：后金解围后「分兵数万略觉华岛，杀参将金冠等及军民数万」，袁崇焕「方完城，力竭不能救也」。**宁远大捷的同一个月，一个岛上的几万军民被杀光了。**
- **269 颗人头**。这是明廷自己报的数字。士兵们抬着这些头去领赏。**"大捷"在文书上就是这么一个数字。**

**【可玩性评估】**

**中等偏上：适合做"炮手"单关，不适合做完整五幕。**

- 核心张力：**装填**。红夷大炮的装填流程长、步骤多、不能出错，而城墙下面有人在挖。这是天然的"倒计时 + 精细操作"关卡：**你每慢一步，墙就薄一寸。**
- 天然反转：**炮位上的文官**。玩家可以扮演金启倧（通判，管粮的），被临时派去点炮，然后死在那里。**这个反转不需要虚构：史书就是这么写的。**
- 天然反转二：**烧房子**。清野命令下达，玩家要去烧自己家那条街。
- 弱点：**史料个体太少。** 《明史·袁崇焕传》关于宁远的记载不到三百字，除了罗立和金启倧，没有一个士兵的名字。**做 5 次魂穿会严重缺料。**
- 建议：如果要用这一战，只做**一关**（炮手/装填），或把它降级为"图鉴/多战役包"里的一个短篇。

**史料出处**

- 〔正史〕《明史》卷259《袁崇焕传》：<https://zh.wikisource.org/wiki/明史/卷259>
- 〔典章会典〕《明熹宗实录》卷七十（宁远捷功、犒赏数目），转引自维基百科"宁远之战"条目所引原文；**未直读《明实录》原书，置信度中**。

### 11. 萨尔浒之战（1619年，万历四十七年二月—三月）

**交战方与兵力**

| 方 | 数字 | 出处 | 存疑说明 |

| 明（出塞官军） | 「**八万八千五百五十余**员名」 | 〔典章会典〕王在晋《三朝辽事实录》：「各路除丽兵外，主客出塞官军共八万八千五百五十余员名」 | 高。这是明代官方口径的出塞总数 |
| 明（另一说） | 「昨之主客出口者仅**七万余**」 | 杨镐奏疏，转引自王在晋《三朝辽事实录》系统 | 中。指实际出关参战数 |

| 明（损失马骡驼） | 「**二万八千六百余**匹头只」 | 同上 | 高 |

| 后金（巡抚估） | 「骁勇贯战者约有五、六万，掳掠中国民兵亦有二三万，总之不下**八九万**」 | 辽东巡抚周永春奏疏 | 中 |
| 后金（朝鲜使臣估） | 「八部大约**九万六千骑**」 | 朝鲜郑忠信出使建州后报告 | 中 |

| 明（刘綎路） | 「綎兵**四万**」 | 〔正史〕《明史·刘綎传》 | 高 |

**学界讨论（重要）**：萨尔浒长期被当作"以少胜多的典型"，与赤壁、淝水并列。**李广廉、李世愉《萨尔浒战役双方兵力考实》（《北京大学学报（哲学社会科学版）》1980年第4期，第81–83、86页）专门反驳这一点**，指出一般论者"受了清人极力夸大其所谓'开国武功'的影响"。按上表，明军八万八、后金六万至十万，**双方兵力相当，甚至后金在局部占优**。清方记载的"二十万，号称四十七万"（《武皇帝实录》《满文老档》）是宣传数字。

**这一条对剧本的价值**：不要把它写成"少数战胜多数"。它真正的教训是——**兵力相当的一方，因为分兵四路、互不协同、情报失灵，在五天内被各个击破。** 这比"以少胜多"残酷得多，也真实得多。

**地形与天气**

- 战场在辽东山区（今辽宁抚顺、新宾一带），四路明军从四个方向深入，道路「重冈叠岭，马不成列」（《明史·刘綎传》）。
- 天气（两项，均有记载）：
  1. 二月二十五日，朝鲜军至亮马佃，「**雪停了，寒风刺骨，有士卒冻死**」（李民寏《栅中日录》系统）。
  2. 三月初四，刘綎路康应乾部与朝鲜军列阵将战时，「**狂风骤起，扬沙石**。应乾发火器，反击己营，大乱」（《明史·刘綎传》）。
  **第二项是决定性细节：大风把明军自己的火器吹得打回自己营里。**

**战前双方状态**

- 明：四路合击，约定三月初一会师赫图阿拉。但「援兵皆伏地哀号，不愿出关」（万历四十六年江西道御史薛贞奏疏）；杨镐说「援兵皆大减原数」；甘肃路援兵未到。
- **粮道是明军的死穴。** 朝鲜军渡江只带三天粮，右营三千余人「事实上已经断粮三天」；士兵「挖掘到一些被埋藏起来的谷子，还没有去壳，于是用**石头擂碎煮粥吃**」。
- 后金：主场、内线、骑兵机动，且**能读到明军的通信方式**——三月初三黄昏，刘綎军听见北方三声炮响，以为是友军已到赫图阿拉城下，「真实的情况是努尔哈赤此时已经从明军俘虏的口中知道了明军联络的方式，遂以炮响引诱刘綎军速进」。
- 后金的社会动员：八旗兵「各有家奴」，「如军卒家有奴四、五人，皆争偕赴，**专为抢掠财物故也**」——**士兵带家奴上战场，是为了抢东西。**

**战术过程（分阶段）**

1. **西路军杜松**（三月初一）：出抚顺关，被歼于萨尔浒。
2. **北路军马林**（三月初二）：败。
3. **东路军刘綎**（三月初四）：这一路细节最全。
   - 刘綎「已深入三百里，杜松军覆犹不知」——**他不知道自己侧翼已经没了。**
   - 三声炮响诱使他加速前进。
   - 「綎引军登阿布达里冈，将布阵，大清兵亦登冈，出其上，而别以一军趋綎西。冈上军自高驰下，奋击綎军，綎殊死战。趋綎西者复从旁夹击，綎军不能支。」
   - 「大清兵乘势追击，遇綎后二营军。未及陈，复为大军所乘，大溃，綎战死。」
   - 「**士卒脱者无几。**」
4. **朝鲜军**（三月初四—初五）：康应乾部「狂风骤起，扬沙石。应乾发火器，反击己营，大乱」，大败。朝鲜都元帅姜弘立、副元帅金景瑞率众降。明军游击乔一琦投崖死。
5. **南路军李如柏**：未接战，被哨骑二十人吓溃，「奔走相蹴死者千余人」（《明史·李如柏传》）。

**关键转折点**

**三月初三黄昏那三声炮响。**

明军自己约定"以炮响为号"，努尔哈赤从俘虏口中知道了这个约定，然后用它把刘綎骗进了口袋。**这不是战术胜利，是通信系统被敌人接管。**

写剧本时这是极好的关卡：玩家是刘綎军的传令兵/听号兵，听见三声炮响，上级说"友军到了，加速"，而玩家**没有办法证明那是敌人放的**。

**伤亡与后果**

- 「阵亡军丁四万五千八百七十余名，官三百一十余员名」（王在晋《三朝辽事实录》）。**明军出塞八万八，伤亡过半。**
- 「阵失马骡驼共二万八千六百余匹头只」。
- 后果：明朝在辽东转为守势，努尔哈赤政权站稳。**这是明清易代的真正起点。**

**【小兵视角细节】**

- **朝鲜随军文官李民寏的《栅中日录》**（〔私记〕，**未直读原书，以下据研究性转述，置信度中**）：
  - 断粮：「右营三千多人事实上已经断粮三天了，还向乔一琦借了 10 袋粮食。」
  - 吃法：「饿疯了的士卒们挖掘到一些被埋藏起来的是谷子，还没有去壳，于是**用石头擂碎煮粥吃**。」
  - 搜山：「斩 30 级，活捉男女 10 余口，牛马 18 头」，18 头牲畜成了晚餐——**他们杀的是女真的村民，不是士兵。**
  - 他写给户曹官员的信（原信语气极烈）：「三军绝食，今已屡日。**自古安有驱督饥卒，颠仆跋涉，深入虏地，而能善其后者乎？** ……白首老书生不免为沙场之骨，命也，奈何！」
  - 战前鼓动：「当李民寏和诸将到阵前，以言语激励士卒，**百无一应**，甚至有很多士卒直接**抛弃了手中的武器，坐而不动**。」
    **这是全素材库最真实的一次"士兵不打了"的记录。** 不是逃跑，不是投降，是坐下来。
  - 战场画面（李民寏原文语句）：「**夕阳之下，只见射矢如雨，铁马来回进退。**」
  - 火器与骑兵的时间差：朝鲜军「炮铳齐射，后金军有落马者，但**未及更换弹药，后金骑兵已经突入了朝鲜营中**」。转述者估算：骑兵百步之外冲来，二十秒内必到。
  - 溃兵的行为：投降议和消息传开，「当时有明军浙兵七八名来到阵前……**朝鲜士卒一起将其驱出阵中**，将领们虽然呵斥，但依旧不能禁止」；「一些明军士卒直接被朝鲜军捆住，**丢往山下**，而山下就是后金军」。
- **刘招孙**（《明史·刘綎传》）：「养子**刘招孙**者，最骁勇，突围，**手格杀数人，亦死**。」——刘綎的养子，突围时徒手杀了数人，死了。
- **乔一琦的绝命书**（《明史·刘綎传》只说「一琦投崖死」；绝命书原文见《栅中日录》系统转述，置信度中）：
  > 「文臣武将尽以社稷为戏，一味循私贪鄙，致属国丧师万计，存留无几，困围孤崖，粮断水尽，其人马朝夕且不保，吾不忍见，而又奉委监督其军，不敢离，谨于三月初四日，西向叩谢皇恩，自裁于家岭上。」

  写完用弓弦自杀被救，然后**从山上跳下去**，「而乔一琦的家丁也纷纷跟随跳崖」。
- **「士卒脱者无几」**。五个字，是刘綎一路的结局。
- **一个大风**：「狂风骤起，扬沙石。应乾发火器，反击己营，大乱。」——**明军最先进的武器，被一阵风变成了杀自己的东西。**

**【可玩性评估】**

**强，但结构复杂，适合做"多线"而不是"单线"。**

- 核心张力：**"我在等一个不会来的友军。"** 四路明军互相以为对方在推进，实际上三路已经没了。玩家扮演的每一路，都在等炮声、等粮、等命令。
- 天然反转：**三声炮响**。这是全素材库最好的"信息战"关卡：敌方用我方的信号骗我方。
- 天然反转二：**士兵坐下**。可以做成一关：玩家是基层军官，任务是"让士兵站起来"。**怎么喊都没人应。** 这是最难做、也最真实的一关。
- 天然机制：**火器换弹**。二十秒的窗口，骑兵从百步到眼前。这是一个天然的"操作精度 + 时间压力"玩法，且完全史实。
- 5 视角可行性：**高。** 明军火器手 / 朝鲜铳手 / 传令兵 / 运粮兵 / 文书（记功、报伤亡）。**而且这一战有全素材库最精确的伤亡统计（45870 名军丁），正好做"名册"结算。**
- 弱点：四路分兵，叙事容易散。建议**只取刘綎一路 + 朝鲜军**，因为这一路的个体材料最全。

### 12. 小商河（小商桥）之战（1140年，绍兴十年七月）

> **先说结论：这一战的史料不足以支撑一份完整档案。** 《宋史·杨再兴传》全文相关记载不到一百字。下面写出能确证的部分，并在"可玩性"里说明它适合被降级使用。

**交战方与兵力**

| 方 | 数字 | 出处 | 存疑说明 |
|---|---|---|---|
| 宋（杨再兴部） | 「**三百骑**」 | 〔正史〕《宋史·杨再兴传》：「再兴以三百骑遇敌于小商桥」 | 高 |
| 金（兀术全军） | 「顿兵**十二万**于临颍」 | 同上 | **注意：这是兀术全军，不是小商桥当面的敌军**。三百骑遇到的是敌军前队，不是十二万 |
| 宋（击杀） | 「杀**二千余人**，及万户撒八孛堇、千户百人」 | 同上 | 高（史载），但三百人杀两千人，比例存疑 |
| 杨再兴遗骸 | 「焚之，得**箭镞二升**」 | 同上 | 高。这是全素材库最震撼的一个数字 |

**名称说明**：史书作「**小商桥**」（今河南临颍小商桥），民间与通俗叙述多作「小商河」。**建议剧本用"小商桥"，与《宋史》一致。**

**地形与天气**

- 小商桥跨小商河（颍水支流），是临颍南的重要通道。**战役就发生在桥头**——三百骑过桥时遭遇。
- 天气无记载。时间：绍兴十年七月，盛夏。

**战前双方状态**

- 宋：岳飞郾城大捷后，诸部分路追击。杨再兴是岳飞部将，此前在郾城「以单骑入其军，擒兀术不获，手杀数百人而还」。
- 金：兀术在郾城受挫，愤而「并力复来」，顿兵十二万于临颍。
- 杨再兴的出身（重要）：他原是流寇曹成的部将。绍兴二年岳飞破曹成，杨再兴「率众直入其营，官军却，**杀顺夫，又杀飞弟飜**」——他杀过岳飞的弟弟岳翻。后来「再兴走跃入涧，张宪欲杀之，再兴曰：『愿执我见岳公。』遂受缚。飞见再兴，奇其貌，释之，曰：『吾不汝杀，汝当以忠义报国。』」

**战术过程**

只有一句：「再兴以三百骑遇敌于小商桥，**骤与之战**，杀二千余人，及万户撒八孛堇、千户百人。再兴战死。」

**"遇"和"骤"两个字说明这不是一场计划中的战斗，是遭遇战。** 三百骑撞上了金军前队，直接开打，打到全死。

**关键转折点**

**没有转折点。** 这是一场从第一秒就在死的战斗，没有任何战术变化。它的价值不在过程，在结果——**烧尸的时候，从灰里捡出了两升箭头。**

**伤亡与后果**

- 宋：三百骑全没，杨再兴战死。
- 金：「杀二千余人」，另杀万户（撒八孛堇）一人、千户百人。
- 后果：张宪随后赶到，「破其溃兵八千，兀术夜遁」。岳家军继续推进，直到岳飞被召还、下狱死。

**【小兵视角细节】**

- **「箭镞二升」**。《宋史》原文：「再兴战死，后获其尸，焚之，**得箭镞二升**。」
  **二升。** 不是"中了很多箭"，是把尸体烧了之后，从灰烬里筛出来的铁箭头，装了二升。汉代一升约二百毫升，宋代一升约七百毫升——**无论按哪个算，这都是一个装满的量。** 一个人身上的箭，能装两升。
  这是整个素材库里最强的单一意象。**它不需要任何解释、任何台词、任何镜头语言。**
- **三百骑里有名字的只有一个人**：杨再兴。其余二百九十九人，全部无名。
- **「骤与之战」**。没有列阵，没有号令，没有鼓。就是撞上了，然后打。
- **一个杀过主帅弟弟的人，最后为主帅的朝廷死了**。杨再兴杀岳翻，岳飞放了他，说「汝当以忠义报国」。九年后他在小商桥应验了这句话。
- **「手杀数百人而还」**（郾城，单骑入敌阵）。这个数字明显夸大，但它说明一件事：**这个人打仗的方式是单骑冲阵**，所以他最后会死于箭。

**【可玩性评估】**

**不适合做完整关卡，但极适合做一个"结算画面"。**

- 三百人对十二万，没有战术空间、没有决策点、没有资源管理。做成关卡只有一种形态：**不可能赢的坚守**，玩三分钟，然后死。这在 15 分钟 demo 里会占掉太多时间，收益却只是一个情绪点。
- **但它应该被用。** 建议用法：不做成一关，做成**一次魂穿的死亡转场**——玩家在某一场战役里扮演一个无名骑兵，冲锋，中箭，倒下，黑屏，然后屏幕上出一行字：

  > 「获其尸，焚之，得箭镞二升。」

  这可能是整个游戏里最有力量的一行字，而且它一个字都不用编。
- 如果要单独做，唯一的形态是"桥"：一座桥，三百人，对面无限。玩法是**守住桥头多少秒**，而无论守多久，结局一样。

**史料出处**

- 〔正史〕《宋史》卷368《杨再兴传》：<https://zh.wikisource.org/wiki/宋史/卷368>

### 12-补. 替补方案：浚稽山之战（前99年，天汉二年九月）

> **为什么补这一场**：小商河史料不足，但如果用户需要一场"三百骑／五百骑级小部队被围歼、且普通士兵的身体感受有明确记载"的战役，**浚稽山之战是全部中国古代史料里最好的一个**。它是《汉书》里唯一一处按**伤口数量**给士兵分派任务的记载。**建议用它替换小商河，把小商河降级为转场的一行字。**

**交战方与兵力**

| 方 | 数字 | 出处 | 存疑说明 |
|---|---|---|---|
| 汉（李陵） | 步兵**五千** | 〔正史〕《汉书·李广苏建传》：「臣愿以少击众，步兵五千人涉单于庭」 | 高 |
| 匈奴（初围） | 骑**三万** | 同上：「与单于相直，骑可三万围陵军」 | 高 |
| 匈奴（增兵后） | 骑**八万余** | 同上：「单于大惊，召左右地兵八万余骑攻陵」 | 高 |
| 汉（脱归） | **四百余人** | 同上：「军人分散，脱至塞者四百余人」 | 高。**五千出征，回来四百** |
| 匈奴（累计被杀伤） | 数千＋三千余＋数千＋二千余 | 同上，分段记载 | 中。分四次记，合计约万余，均出自汉方战报，可能膨胀 |
| 汉（弹药消耗） | 「一日**五十万矢**皆尽」 | 同上 | 高。这是极罕见的弹药消耗量化记载 |

**地形与天气**

- 战场在今蒙古国境内浚稽山一带，汉军「北行三十日」才到。
- 关键地形：「军居两山间，**以大车为营**」——用辎重车围成营寨。后来又「抵大泽葭苇中」，再「南行至山下」，最后「陵居谷中，虏在山上」。
- 天气与火：「虏**从上风纵火**，陵亦令军中纵火以自救」——敌人放火，汉军也放火，用火烧出一条隔离带。
- **一个决定性的温度细节**：最后突围时「令军士人持二升糒，**一半冰**」——每人二升干粮和一块冰。**有冰，说明夜里极冷**，也说明**没有水，只能带冰**。

**战前双方状态**

- 汉：李陵自请以步兵五千深入，武帝先是不悦（「将恶相属邪！吾发军多，毋骑予女」），后又疑他反悔，强令九月出发。原定接应的路博德「羞为陵后距」，上书推托，被调走。**李陵从一开始就没有援军。**
- 匈奴：单于亲率三万骑，初战失利后「大惊」，召左右地兵八万余骑。**先以六倍、后以十六倍以上的骑兵围攻五千步兵**（以三万骑/五千＝6 倍，以八万余骑/五千≈16 倍计；合计近十一万骑则约二十余倍）。
- 汉军内部：**带着女人**。「始军出时，关东群盗妻子徙边者随军为卒妻妇，大匿车中。」

**战术过程（分阶段）**

1. **车营结阵**：「陵引士出营外为陈，前行持戟盾，后行持弓弩，令曰：『**闻鼓声而纵，闻金声而止。**』」——这句话是《尉缭子》金鼓语义在实战记载里的直接印证（见 02 文档 A1）。
2. **千弩俱发**：匈奴「直前就营」，汉军「千弩俱发，应弦而倒」，追击杀数千人。
3. **且战且引**：匈奴增兵八万，李陵「且战且引，南行数日，抵山谷中」。这一段是全军最惨的阶段。
4. **按伤分诊**（本战最重要的一句）：「连战，**士卒中矢伤，三创者载辇，两创者将车，一创者持兵战**。」
5. **搜车斩妇**：李陵发觉不对劲，说「吾士气少衰而鼓不起者，何也？军中岂有女子乎？」搜车搜出随军妇女，「**皆剑斩之**」。
6. **火战**：至大泽葭苇中，匈奴从上风纵火，李陵令军中纵火自救。
7. **树间步斗**：「陵军步斗树木间，复杀数千人」，并发连弩射单于，单于下走。
8. **叛徒出现**：「会陵军候**管敢**为校尉所辱，亡降匈奴」，把汉军「无后救、射矢且尽、以黄与白为帜」全部告诉单于。
9. **矢尽**：「一日五十万矢皆尽，即弃车去。士尚三千余人，**徒斩车辐而持之**，军吏持尺刀。」——**把车辐条砍下来当棍子。**
10. **垒石**：匈奴「乘隅下垒石，士卒多死，不得行」。
11. **散**：李陵尽斩旌旗、埋珍宝，说「复得数十矢，足以脱矣。今无兵复战，天明坐受缚矣！**各鸟兽散**，犹有得脱归报天子者」。分给每人二升干粮一块冰，约定到遮虏鄣集合。
12. **鼓不鸣**：「夜半时，**击鼓起士，鼓不鸣**。」李陵与韩延年上马，壮士从者十余人，匈奴数千骑追之，韩延年战死，李陵降。「军人分散，脱至塞者四百余人。」

**关键转折点**

**军候管敢叛降。**

一个低级军官（军候）被自己的校尉侮辱，跑到匈奴那边，把三件事全说了：没有援军、箭快用完、旗帜是黄白色（便于识别射击）。**这一个人，结束了五千人的命运。**

第二转折点是**「鼓不鸣」**三个字。夜半要突围，击鼓集合，鼓没有响。**可能是冻了、湿了、或者鼓手已经死了。**《汉书》没有解释，只写了这三个字。

**伤亡与后果**

- 汉：五千人出征，脱归四百余人；李陵、韩延年（战死）以下或死或降。
- 匈奴：分段累计约万余人（汉方战报口径）。
- 后果：武帝族李陵家，「母弟妻子皆伏诛」；司马迁为李陵说话，受宫刑；「陇西士大夫以李氏为愧」。

**【小兵视角细节】**

- **「三创者载辇，两创者将车，一创者持兵战」**——**这是全部史料里唯一一条按伤口数量分配任务的军规记载。** 三处伤：坐车；两处伤：赶车；一处伤：继续打。**它把"人"变成了一张分级表。**
- **「徒斩车辐而持之」**——箭射完了，士兵把大车的辐条砍下来当武器。**这是全素材库最具体的一次"没有武器了"。**
- **「人持二升糒，一半冰」**——每人二升干粮、半块冰。**没有水，冰就是水。**
- **「鼓不鸣」**——三个字。要集合了，鼓没响。
- **藏在车里的女人**：「关东群盗妻子徙边者随军为卒妻妇，大匿车中。陵搜得，皆剑斩之。」——**士兵把妻子藏在大车里跟着军队走，被主帅搜出来全部砍了。** 这是全素材库里最不愿写、但最真实的一条：这支军队的士兵是罪犯的家属，他们带上了老婆，然后老婆被自己人杀了。
- **「军人分散，脱至塞者四百余人」**——五千人出去，四百人回来。**这四百人就是"被记住"的全部。**
- **「士张空拳，冒白刃，北首争死敌」**（司马迁语）——空着手，迎着刀，朝北死战。这是同时代人对此战的描述。

**【可玩性评估】**

**极强。如果不用井陉，这一场是"身体感"最锋利的选择。**

- 天然机制一：**伤口分级**。「三创载辇／两创将车／一创持兵战」可以直接做成状态系统——玩家身上每多一处伤，可执行的动作就少一档。**不需要虚构任何数值。**
- 天然机制二：**箭数管理**。「一日五十万矢皆尽」是史实，玩家所在的队分到的箭是有限的，射完就得砍车辐。
- 天然机制三：**金鼓**。「闻鼓声而纵，闻金声而止」是原文，直接就是 02 文档 A1 的战阵版。
- 天然反转：**管敢叛降**。玩家可以是管敢身边的人，看着他被校尉侮辱，看着他夜里走掉。**玩家不能阻止他，因为史书里也没人阻止。**
- 天然结尾：**「鼓不鸣」**。所有关卡结束后，玩家要击鼓集合，鼓没有声音。**这是全素材库最好的结束画面。**
- 5 视角：材官（持戟盾的前行）/ 弩手（后行）/ 车夫（两创将车）/ 军候（管敢）/ 文书（记功与报伤亡）。

**史料出处**

- 〔正史〕《汉书》卷54《李广苏建传》附《李陵传》：<https://zh.wikisource.org/wiki/漢書/卷054>

# 一、史书里的小人物

> 选取标准：**有名字、是普通人或低级军官、有具体行为或台词**。将帅不算，名士不算，虚构不算。
> 排序大致按时代。每人给"他做了什么、说了什么、怎么死的、有没有被记住"。

## 1. 喜（秦，前262—前217？）

**身份**：秦国基层法官（令史），睡虎地十一号秦墓墓主。
**出处**：〔出土文献〕《睡虎地秦墓竹简·叶书（编年记）》。
**他做了什么**：他把自己的**一生**按年记在竹简上，随葬墓中。他记自己出生：「四十五年，攻大野王。**十二月甲午鸡鸣时，喜产。**」——精确到"鸡鸣时"。他记弟弟出生：「四十七年，攻长平。十一月，敢产。」——**长平之战那年，他十二岁，弟弟出生。** 他记自己的仕途：「六年，四月，为安陆令史」「七年，正月甲寅，鄢令史」「十二年，四月癸丑，喜治狱鄢」。他记自己从军：「十三年，从军」「十五年，从平阳军」「十七年，攻韩」「十八年，攻赵」「廿三年，兴，攻荆」。他也记父母之死：「十六年，七月丁巳，公终」「廿年，七月甲寅，妪终」。
**有没有被记住**：**被记住了，而且是他自己记的。** 这是中国考古史上最完整的"一个普通人自己写的一生"。他不知道长平会进教科书，他只是把它当成"那年发生了什么事"记下来，和弟弟出生记在同一行。
**剧本价值**：**这是"名册"主题的史实原点。** 一个人把年、月、日、时辰、家人的生与死，一行一行写在竹片上，埋进土里。两千年后我们读到了。

## 2. 黑夫（秦，约前223年）

**身份**：秦军士兵，安陆人，正在参加攻淮阳的战役。
**出处**：〔出土文献〕睡虎地四号秦墓十一号木牍。
**他说了什么**（原文）：
> 「二月辛巳，黑夫、惊敢再拜问衷，母毋恙也？……遗黑夫钱，母操夏衣来。今书节到，母视安陆丝布贱，可以为禅裙襦者，母必为之，令与钱偕来。**黑夫等直佐淮阳，攻反城久，伤未可智（知）也**，愿母遗黑夫用勿少。书到皆为报，**报必言相家爵来未来**。」

**怎么读**：妈，寄钱来，再给我做身夏衣；如果安陆的丝布便宜就做，贵就直接寄钱。我们正在打淮阳，打了很久了，**伤成什么样还不知道**。信到了都给我回，回信一定要说——**爵位批下来没有**。
**有没有被记住**：记住了。这封信两千两百年后还在，字迹清楚。
**剧本价值**：「伤未可智也」——**一个士兵在攻城间隙说"不知道自己伤成什么样"**。这一句比任何战争描写都冷。

## 3. 惊（秦，同上）

**身份**：黑夫的弟弟，同在一支军队。
**出处**：同上（同一木牍背面）。
**他说了什么**：「惊多问新负（妇）、妴（婉）得毋恙也？**新负勉力视瞻丈人**，毋与……勉力也。」——问新婚妻子好不好，让新妇好好照顾老人。
**剧本价值**：兄弟两人在同一封家书里各问各的家事。**战争把一家人拆成三个地址：前线、家里、和另一个前线。**

## 4. 袁彬（明，生卒不详）

**身份**：锦衣卫校尉（后升至指挥佥事）。
**出处**：〔私记〕袁彬《北征事迹》；〔正史〕《明史》卷167《袁彬传》。
**他做了什么**：土木堡之变时随驾，乱军中被一个叫赛伏剌的回回俘虏；第二天在乱军中认出英宗，跪下哭；因为「会写字」被留在皇帝身边；下河替皇帝牵马；夜里「以两胁温上足」；差点被喜宁害死（「将臣赚去芦苇地内捆了，欲开剥」），靠哈铭求情才解了皮条。
**他说了什么**：英宗教他别说自己是校尉，他照做了。他在大同城下跪着对城上喊：「**我是写字的校尉，见有驾牌为照。我原籍是江西人。**」他还扯住通事李让的腰带说：「**皇帝在门外，你如何不去？**」
**结局**：活着回来了。景泰元年升试百户；天顺元年英宗复位，升指挥佥事，赐宅澄清坊，还替他主婚。成化元年，他应史馆之请写下《北征事迹》。
**有没有被记住**：**被记住了，而且是他自己写的。** 《明史》有传，他的题本全文存世。
**剧本价值**：**这是整个素材库里最重要的小人物。** 一个校尉，因为识字，在皇帝最狼狈的一年里成了他唯一的人。而"识字"这件事，正是《纪效新书》「每队一个识字之人」的制度在极端情境下的兑现。

## 5. 哈铭（明，生卒不详）

**身份**：蒙古人，幼年随父做通事（翻译），锦衣卫系统。
**出处**：《明史》卷167《袁彬传》附。
**他做了什么**：也先与英宗之间的传话全靠他；「二人时进谐语慰帝，帝亦为解颜」——他和袁彬轮流说笑话让皇帝开心；英宗要密擒喜宁时，是他去跟也先说情饶袁彬一命；最后是他先去京城奏报也先要送还英宗。
**有没有被记住**：《明史》附在袁彬传后，**没有独立传记，也没有生卒年**。
**剧本价值**：一个蒙古人在明朝皇帝和蒙古太师之间当翻译。**他的位置本身就是这场战争最荒诞的注脚。**

## 6. 夜不收杨总旗（明，1449）

**身份**：明军侦察兵头目（总旗，管五十人）。
**出处**：〔私记〕袁彬《北征事迹》：「有夜不收杨总旗来与臣说：『今夜有五个夜不收来，密请爷爷石佛寺去，待他寻不见时，便乘间入城去。』」
**他做了什么**：带着五个侦察兵摸到也先营外，计划把英宗偷出去，送到石佛寺，等敌人搜不到再乘隙入城。
**结局**：英宗拒绝：「此危事，使不得。先在土木时不曾死，我命在天，若万一不虞，如何好？」计策作废。**这个人的下场史书没写。**
**有没有被记住**：只有"杨总旗"三个字，连名字都没有。
**剧本价值**：**这是全素材库最好的"救援任务"原型，而且结局是"被救的人拒绝了"。** 玩家做完了所有准备，最后皇帝说"不去"。

## 7. 袁敏（明，1449）

**身份**：金齿卫知事（从八品，西南边地小官）。
**出处**：《明史》卷167《袁彬传》附。
**他做了什么**：英宗北征时「应募从至大同」；见敌骑逼近，建议「留精兵三四万人扼其冲，而车驾疾驱入关」，王振不听，六师遂覆；他跳脱逃回，然后给景帝上了一道奏疏。
**他说了什么**（这段是全篇最动人的奏疏之一）：
> 「上皇曩居九重，所服者衮绣，所食者珍羞，所居者琼宫瑶室。**今驾陷沙漠，服有衮绣乎？食有珍羞乎？居有宫室乎？** 臣闻之，主辱臣死。上皇辱至此，臣子何以为心，臣不惜碎首刳心。乞遣官一人，或就令臣赍书及服御物问安塞外，以尽臣子之义。臣虽万死，心实甘之。」

**结局**：「命礼部议，竟报寝。」——交礼部讨论，然后没有下文。**他想去塞外送衣服，没人批准。**
**剧本价值**：一个小官，想给被俘的皇帝送几件衣服，被官僚系统按程序驳回了。

## 8. 罗如墉（明，1449）

**身份**：行人司行人（正八品，管礼仪外交的闲职）。
**出处**：《明史》卷167《曹鼐传》附。
**他做了什么**：随军北征。出发前「诀妻子，誓以死报国，**属翰林刘俨铭其墓**」。
**他说了什么**：刘俨吓了一跳，拒绝写。罗如墉笑着说：「**行当验耳。**」（很快就应验了。）
**结局**：「后数日果死。」
**剧本价值**：**一个提前给自己写好墓志铭的人。** 而且是别人不肯写，他还笑。这个人物的完成度比任何虚构角色都高。

## 9. 俞鉴（明，1449）

**身份**：兵部职方司主事（正六品）。
**出处**：《明史》卷167《曹鼐传》附。
**他做了什么**：北征时，郎中胡宁本来该随驾，称病求人替代。俞鉴「慷慨许诺」。
**别人问他**：「家远子幼奈何？」
**他说**：「**为国，臣子敢计身家！**」
**结局**：「师覆」时死。他此前跟兵部尚书邝埜说过自己唯一的建议：「惟力劝班师耳。」——他能做的只有劝人撤兵。
**剧本价值**：**他是替一个装病的人去死的。** 而这个细节是正史顺手记下来的，不是谁编的。

## 10. 南霁云（唐，？—757）

**身份**：张巡帐下之士，善骑射。
**出处**：《新唐书》卷192《南霁云传》；《旧唐书》卷187下《张巡传》。
**出身**：「**少微贱，为人操舟**」——一个撑船的。
**他怎么进的睢阳**：被尚衡派去和张巡议事，回去对人说：「**张公开心待人，真吾所事也。**」尚衡送金帛来接，他不受，留下不走。
**他说了什么**：
- 求援时对贺兰进明：「本州强寇凌逼，重围半年，食尽兵穷……**今见存之数，不过数千，城中之人，分当饵贼**……」
- 断指时：「今主将之命不达，霁云请置一指以示信，归报中丞也。」然后「拔佩刀断指，一座大惊，为出涕。**卒不食去。**」
- 射塔时：「吾破贼还，必灭贺兰，**此矢所以志也**！」
- 城破时张巡喊他「南八！男儿死尔，不可为不义屈！」他笑了，说：「欲将有为也，公知我者，敢不死！」
**结局**：与张巡等三十六人同时遇害。
**有没有被记住**：被记住了，而且很彻底——唐代宗赠他开府仪同三司、再赠扬州大都督；大中年间图像入凌烟阁；睢阳"双庙"至今祭祀。
**剧本价值**：**一个船夫，靠"善骑射"和"见贼百步内乃发"成为守城战里最重要的一支箭。** 他的全部戏都在"出去求救—被拒—断指—回来"这四步里，而这一步是天然的一整关。

## 11. 雷万春（唐，？—757）

**身份**：张巡部将。
**出处**：《新唐书》卷192。
**评价**（《新唐书》原文）：「万春将兵，方略不及霁云，而**强毅用命**。每战，巡任之与霁云钧。」
**结局**：与张巡同遇害。
**剧本价值**：一个"不如南霁云聪明，但每次都死战"的人。**游戏里的"老兵"角色可以直接照这个写。**

## 12. 石承平等二十一人（唐，？—757）

**身份**：张巡部别将（低级军官）。
**出处**：《新唐书》卷192《张巡传》。
**名单**：石承平、李辞、陆元锽、朱珪、宋若虚、杨振威、耿庆礼、马日升、张惟清、廉坦、张重、孙景趋、赵连城、王森、乔绍俊、张恭默、祝忠、李嘉隐、翟良辅、孙廷皎、冯颜。
**结局**：「其后皆死巡难，**四人逸其姓名**。」
**剧本价值**：**这是全素材库最珍贵的一串名单。** 二十一个名字，全部死在同一座城里；另外四个人连名字都没留下。**"四人逸其姓名"这六个字，就是整个游戏的主题句。**

## 13. 陆家姑（唐，？—757）

**身份**：张巡的姐姐，嫁陆氏。
**出处**：《新唐书》卷192。
**她做了什么**：「遮王劝勿行，不纳，赐百缣，弗受，**为巡补缝行间**，军中号『陆家姑』。」
**结局**：「先巡被害。」——死在弟弟之前。
**剧本价值**：**一个在军营里给士兵缝衣服的女人。** 她有姓（陆），有称呼（陆家姑），没有名字。她是这支军队的后勤系统，也是这场围城里唯一一个不属于任何编制的死者。

## 14. 罗立（明，1626）

**身份**：福建籍士兵，炮手。
**出处**：《明史》卷259《袁崇焕传》：「崇焕令**闽卒罗立**，发西洋巨炮，伤城外军。」
**他做了什么**：操作宁远城头的西洋巨炮，打退了后金攻城部队。
**有没有被记住**：**只有五个字**：「闽卒罗立，发西洋巨炮。」
**剧本价值**：整个宁远大捷的官方叙述里，唯一被点名的士兵。**他不算英雄，他算"操作员"。** 这恰好是小兵视角的核心：**战争需要的是技能，不是勇气。**

## 15. 金启倧（明，？—1626）

**身份**：督屯通判（文官，管粮草）。
**出处**：《明史》卷259。
**他做了什么**：反对高第撤关外，「锦、右、大凌三城皆前锋要地。倘收兵退，既安之民庶复播迁，已得之封疆再沦没，关内外堪几次退守耶！」；宁远之战负责「具守卒食」（管士兵吃饭）。
**结局**：「**启倧亦以然炮死。**」——点炮时死了。
**剧本价值**：**一个管粮食的文官，最后死在炮位上。** 史书只用六个字写他的死。

## 16. 王难得（唐，757）

**身份**：都知兵马使（中低级军官）。
**出处**：《资治通鉴》卷220。
**他做了什么**：「救其裨将，贼射之**中眉，皮垂鄣目**。难得**自拔箭，掣去其皮，血流被面，前战不已**。」
**剧本价值**：**全素材库最具体的一次伤情描写。** 箭射中眉心，眼皮垂下来挡住眼睛，他自己把箭拔了，把眼皮撕掉，血流满脸，继续打。这不是英雄主义，这是**"眼睛被挡住了，得先弄开"**。

## 17. 刘招孙（明，1619）

**身份**：刘綎的养子。
**出处**：《明史》卷247《刘綎传》：「养子刘招孙者，最骁勇，突围，**手格杀数人，亦死**。」
**结局**：死。
**剧本价值**：萨尔浒东路军最后时刻，一个养子在突围时徒手杀了几个人，然后死了。**"手格杀"意味着兵器已经没了或者来不及用。**

## 18. 乔一琦（明，？—1619）

**身份**：游击将军，被派去监督朝鲜军。
**出处**：《明史》卷247《刘綎传》：「一琦投崖死。」
**他的绝命书**（据《栅中日录》系统转述，置信度中）：
> 「文臣武将尽以社稷为戏，一味循私贪鄙，致属国丧师万计，存留无几，困围孤崖，粮断水尽，其人马朝夕且不保，吾不忍见，而又奉委监督其军，不敢离，谨于三月初四日，西向叩谢皇恩，自裁于家岭上。儿可传于相知，并亲以意奏知圣明。」

**结局**：用弓弦自杀被救，然后跳崖。「而乔一琦的家丁也纷纷跟随跳崖。」
**剧本价值**：**他是明军派去"看着"朝鲜军的人，最后朝鲜军投降了，他跳崖了，他的家丁跟着跳了。** 侍从的选择在这份材料里第一次被写出来。

## 19. 吕马童 / 杨喜 / 王翳 / 吕胜 / 杨武（汉，前202）

**身份**：汉军骑兵军官（骑司马、郎中骑、郎中）。
**出处**：《史记·项羽本纪》。
**他们做了什么**：项羽自刎后争抢其尸，「**余骑相蹂践争项王，相杀者数十人**」。最后「王翳取其头，……郎中骑杨喜、骑司马吕马童、郎中吕胜、杨武各得其一体。五人共会其体，皆是。」
**结局**：五人皆封侯——吕马童中水侯、王翳杜衍侯、杨喜赤泉侯、杨武吴防侯、吕胜涅阳侯。
**特别记一个人**：吕马童是项羽的旧识。项羽死前对他说：「若非吾故人乎？」吕马童「**面之**」（把脸转过去），指着王翳说：「此项王也。」
**剧本价值**：**这是"军功制度"最赤裸的一次演示。** 五个人分了一具尸体，各得一块，全部封侯。而为了抢这具尸体，汉军自己人互相砍死了几十个。**"面之"两个字，是一个小人物一生中最重要的一次选择，而司马迁只用了两个字。**

## 20. 田父（汉，前202）

**身份**：阴陵一带的农夫。
**出处**：《史记·项羽本纪》：「项王至阴陵，迷失道，问一田父，田父**绐**曰『左』。左，乃陷大泽中。以故汉追及之。」
**他做了什么**：给项羽指了一条错路。「绐」是欺骗，司马迁明确写了这是故意的。
**有没有被记住**：没有名字。
**剧本价值**：**一个连名字都没有的农民，用一个字改变了中国历史。** 而这个字是故意的——史书没有解释为什么。**这个空白是剧本最好的入口。**

## 21. 淝水进饭者（前秦，383）

**身份**：淮北一个百姓。
**出处**：《晋书·苻坚载记下》：「坚为流矢所中，单骑遁还于淮北，饥甚，**人有进壶飧豚髀者**，坚食之，大悦。」
**他说了什么**：苻坚要赏他帛十匹、绵十斤，他拒绝了：
> 「臣闻白龙厌天池之乐而见困豫且，陛下目所睹也，耳所闻也。今蒙尘之难，岂自天乎！**且妄施不为惠，妄受不为忠。** 陛下，臣之父母也，安有子养而求报哉！」

说完「弗顾而退」。
**有没有被记住**：没有名字。
**剧本价值**：**他不肯被记住。** 给一个亡国之君送了一壶饭，说了一句"你落到今天不是天意"，然后头也不回地走了。这是整个素材库里最好的一段无名者独白。

# 二、士兵视角的战争描写

> 选录标准：**写"体感"而不是"战略"**。每段给原文、出处、可提取的感官细节（声音/气味/颜色/动作/温度）。
> 凡引自维基文库者均已逐字比对。

## 1. 李华《吊古战场文》——最完整的一份"战场感官清单"

**原文**（节选）：
> 「浩浩乎平沙无垠，夐不见人。河水萦带，群山纠纷。黯兮惨悴，风悲日曛。蓬断草枯，凛若霜晨。鸟飞不下，兽铤亡群。亭长告予曰：『此古战场也。尝覆三军，往往鬼哭，天阴则闻。』」
>
> 「吾想夫北风振漠，胡兵伺便。主将骄敌，期门受战。野竖旄旗，川回组练。法重心骇，威尊命贱。**利镞穿骨，惊沙入面。** 主客相搏，山川震眩。**声析江河，势崩雷电。**」
>
> 「至若穷阴凝闭，凛冽海隅；**积雪没胫，坚冰在须**。鸷鸟休巢，征马踟蹰，**缯纩无温，堕指裂肤**。」
>
> 「径截辎重，横攻士卒；都尉新降，将军覆没。**尸填巨港之岸，血满长城之窟。无贵无贱，同为枯骨**，可胜言哉！鼓衰兮力竭，矢尽兮弦绝。白刃交兮宝刀折，两军蹙兮生死决。」
>
> 「**鸟无声兮山寂寂，夜正长兮风淅淅。** 魂魄结兮天沉沉，鬼神聚兮云幂幂。**日光寒兮草短，月色苦兮霜白。**」
>
> 「苍苍蒸民，谁无父母？提携捧负，畏其不寿。谁无兄弟？如足如手。谁无夫妇？如宾如友。生也何恩？杀之何咎？**其存其殁，家莫闻知。** 人或有言，将信将疑。」

**出处**：〔文学〕李华《吊古战场文》，《古文观止》本：<https://zh.wikisource.org/wiki/弔古戰場文_(古文觀止)>

**可提取的细节**：
- **触觉/温度**：「积雪没胫，坚冰在须」——雪没到小腿，胡须上结了冰；「堕指裂肤」——手指冻掉，皮肤裂开。
- **听觉**：「声析江河，势崩雷电」——声音像江河被劈开；「鸟无声兮山寂寂，夜正长兮风淅淅」——**战后最恐怖的是安静**。
- **视觉/颜色**：「日光寒兮草短，月色苦兮霜白」——太阳是"寒"的，月光是"苦"的。用感官形容词写光，这是中国文学里最高级的一手。
- **痛觉**：「利镞穿骨，惊沙入面」——箭头穿骨，风沙打脸。
- **制度感**：「法重心骇，威尊命贱」——八个字写尽军法的心理效果；「无贵无贱，同为枯骨」——**死亡是唯一一次平等**。
- **游戏可直接用的一句**：「其存其殁，家莫闻知。」——**家里人根本不知道他是死是活。** 这就是"阵亡名录"为什么重要的答案。

## 2. 汉乐府《战城南》——最冷的一首

**原文**：
> 「战城南，死郭北，**野死不葬乌可食**。
> 为我谓乌：『且为客豪，野死谅不葬，腐肉安能去子逃？』
> 水深激激，蒲苇冥冥。**枭骑战斗死，驽马裴徊鸣。**
> 梁筑室，何以南？何以北？
> 禾黍不获君何食？愿为忠臣安可得？
> 思子良臣，良臣诚可思。
> **朝行出攻，暮不夜归。**」

**出处**：〔文学〕汉乐府《战城南》（佚名）：<https://zh.wikisource.org/wiki/戰城南_(佚名)>

**可提取的细节**：
- **对尸体说话**：整首诗是**对着乌鸦说话**——"你替我叼着吧，反正没人埋，肉也跑不了"。这是中国文学里最冷的一次拟人。
- **声音**：「枭骑战斗死，**驽马裴徊鸣**」——勇士死了，劣马在旁边来回叫着。**战场上最后的声音是畜生发出的。**
- **时间**：「朝行出攻，暮不夜归。」——早上出去打，晚上没回来。**一句诗写完了"阵亡"这件事。**
- **游戏用法**：这句可以直接做结算文案的模板：**"朝行出攻，暮不夜归"——下面跟一行名字。**

## 3. 曹操《蒿里行》——"白骨露于野"的原始出处

**原文**：
> 「关东有义士，兴兵讨群凶。初期会盟津，乃心在咸阳。
> **军合力不齐，踌躇而雁行。势利使人争，嗣还自相戕。**
> 淮南弟称号，刻玺于北方。
> **铠甲生虮虱，万姓以死亡。白骨露于野，千里无鸡鸣。**
> 生民百遗一，念之断人肠！」

**出处**：〔文学〕曹操《蒿里行》，《乐府诗集》卷二十七：<https://zh.wikisource.org/wiki/蒿里行>

**可提取的细节**：
- **寄生虫**：「**铠甲生虮虱**」——**这是全部材料里唯一写到"虱子"的句子**，而它比任何"血流成河"都更接近士兵的真实。铠甲长期不离身，里面长虱子。
- **声音的消失**：「千里无鸡鸣」——不是"没有声音"，是**连鸡叫都没有了**。用一个农业社会的日常声音来判断死亡。
- **动作**：「踌躇而雁行」——诸侯军像雁一样排着不敢进。这是**观望**的身体姿态。
- **游戏用法**：「铠甲生虮虱」可以直接做成一个可交互的细节：玩家在行军途中脱下铠甲，看见里面。**不需要台词。**

## 4. 王粲《七哀诗》其一——路上看见的那一幕

**原文**：
> 「西京乱无象，豺虎方遘患。复弃中国去，远身适荆蛮。
> 亲戚对我悲，朋友相追攀。**出门无所见，白骨蔽平原。**
> **路有饥妇人，抱子弃草间。顾闻号泣声，挥涕独不还。**
> 『未知身死处，何能两相完？』驱马弃之去，不忍听此言。
> 南登霸陵岸，回首望长安。悟彼下泉人，喟然伤心肝。」

**出处**：〔文学〕王粲《七哀诗》其一，《文选》卷二十三：<https://zh.wikisource.org/wiki/七哀詩_(西京亂無象)>

**可提取的细节**：
- **视觉的绝对化**：「出门无所见，白骨蔽平原」——**"什么也看不见，只看见骨头"**。这是最高的视觉压缩。
- **台词**：那个母亲说的是「未知身死处，何能两相完？」——我自己都不知道会死在哪，怎么能保住我们两个。**这是中国诗歌里最冷静的一句母亲的话。**
- **声音**：「顾闻号泣声」——她走了还回头听。**声音追着她。**
- **游戏用法**：可以做成一关的过场：玩家策马经过，看见一个妇人把孩子放在草丛里，走了，回头听，然后走了。**玩家什么都不能做。** 这个"不能做"就是主题。

## 5. 蔡琰《悲愤诗》——被掳者看到的路边

**原文**（节选）：
> 「马边**悬男头**，马后**载妇女**。长驱西入关，迥路险且阻。」
>
> 「所略有万计，不得令屯聚。或有骨肉俱，**欲言不敢语**。失意机微间，辄言毙降虏：『要当以亭刃，我曹不活汝！』岂复惜性命？不堪其詈骂。**或便加棓杖，毒痛参并下。**」
>
> 「旦则号泣行，夜则悲吟坐。**欲死不能得，欲生无一可。**」
>
> 「城郭为山林，庭宇生荆艾。**白骨不知谁，从横莫覆盖。**」

**出处**：〔文学〕蔡琰《悲愤诗》，《后汉书》卷八十四《列女传·董祀妻》：<https://zh.wikisource.org/wiki/悲憤詩_(蔡琰)>

**可提取的细节**：
- **一个画面就是全部**：「马边悬男头，马后载妇女。」——**十个字，战场的全部构图**：马的一边挂着男人的头，另一边载着女人。
- **不敢说话**：「欲言不敢语」——骨肉都在，但不敢交谈。这是被掳者的第一反应。
- **威胁的原话**：「要当以亭刃，我曹不活汝！」——"拿刀架着，我们不让你活"。**这是史书里少见的、被记录下来的加害者原话。**
- **时间感**：「旦则号泣行，夜则悲吟坐。」——白天哭着走，晚上坐着呻吟。**一天只有两个动作。**
- **最狠的一句**：「欲死不能得，欲生无一可。」——想死做不到，想活没一条路。
- **游戏用法**：「白骨不知谁」——可以做成一关的结尾：玩家走过一片骨头，**没有任何标记能告诉他这是谁**。

## 6. 杜甫《兵车行》——征兵现场

**原文**（节选）：
> 「车辚辚，马萧萧，行人弓箭各在腰。
> 耶娘妻子走相送，**尘埃不见咸阳桥**。
> **牵衣顿足拦道哭，哭声直上干云霄。**」
>
> 「道傍过者问行人，行人但云点行频。
> 或从十五北防河，便至四十西营田。
> **去时里正与裹头，归来头白还戍边。**」
>
> 「**边庭流血成海水，武皇开边意未已。**」
>
> 「信知生男恶，反是生女好。生女犹得嫁比邻，**生男埋没随百草**。」
>
> 「君不见青海头，古来白骨无人收。
> **新鬼烦冤旧鬼哭，天阴雨湿声啾啾。**」

**出处**：〔文学〕杜甫《兵车行》，《乐府诗集》卷九十一：<https://zh.wikisource.org/wiki/兵車行>

**可提取的细节**：
- **声音层次**：「车辚辚，马萧萧」是背景，「牵衣顿足拦道哭，哭声直上干云霄」是前景。**哭声盖过了车马声。**
- **尘土**：「尘埃不见咸阳桥」——人太多，扬起的土把桥遮住了。
- **一个制度细节**：「去时里正与裹头」——出发时里正给他裹头巾。**裹头是成年的仪式**，一个十五岁的男孩在出发那天被裹上头巾，就算是兵了。
- **时间跨度**：「或从十五北防河，便至四十西营田」——十五岁到四十岁，一辈子。
- **反转的民间智慧**：「信知生男恶，反是生女好」——**因为男孩会被拉走。** 这是唐代民间的真实心态，不是诗人煽情。
- **游戏用法**：「去时里正与裹头」可以直接做一个开场动作：一个里正给玩家裹头巾。**不用一句台词，玩家就知道自己是谁了。**

## 7. 杜甫《石壕吏》——夜里敲门

**原文**：
> 「暮投石壕村，**有吏夜捉人**。
> 老翁逾墙走，老妇出门看。
> **吏呼一何怒，妇啼一何苦。**
> 听妇前致词：三男邺城戍。
> 一男附书至，**二男新战死**。
> 存者且偷生，死者长已矣。
> 室中更无人，惟有乳下孙。
> 有孙母未去，**出入无完裙**。
> 老妪力虽衰，请从吏夜归。
> 急应河阳役，犹得备晨炊。
> **夜久语声绝，如闻泣幽咽。**
> 天明登前途，独与老翁别。」

**出处**：〔文学〕杜甫《石壕吏》：<https://zh.wikisource.org/wiki/石壕吏>

**可提取的细节**：
- **"夜捉人"**——不是征兵，是**抓人**。时间是夜里，动作是"捉"。
- **声音的对比**：「吏呼一何怒，妇啼一何苦」。一怒一苦，两个声音。
- **一个具体的穷**：「有孙母未去，出入无完裙」——**儿媳妇没有一条完整的裙子，所以不能出门。**
- **结局的声音**：「夜久语声绝，如闻泣幽咽。」——说话声没了，只剩极轻的哭。**这是全诗唯一一次"听不清"。**
- **游戏用法**：这首诗的结构就是一次完整的交互：**敲门—躲—开门—问答—带走一个人—天亮**。可以原样做成一关。

## 8. 《史记·项羽本纪》——垓下之夜

**原文**：
> 「夜闻汉军四面皆楚歌，项王乃大惊曰：『汉皆已得楚乎？是何楚人之多也！』项王则夜起，饮帐中。……于是项王乃悲歌忼慨，自为诗曰：『力拔山兮气盖世，时不利兮骓不逝。骓不逝兮可奈何，虞兮虞兮奈若何！』歌数阕，美人和之。**项王泣数行下，左右皆泣，莫能仰视。**」

**出处**：〔正史〕《史记·项羽本纪》：<https://zh.wikisource.org/wiki/史記/卷007>

**可提取的细节**：
- **声音先于画面**：整段从"听见"开始。**四面都是楚歌**——不是战鼓，是家乡的歌。
- **一个集体动作**：「左右皆泣，莫能仰视」。**所有人都在哭，所有人都不敢抬头。**
- **游戏用法**：这是"声音叙事"的教科书。**玩家不需要看见项羽，只需要听见四面楚歌，然后看见身边的人开始哭。**

## 9. 《史记·淮阴侯列传》——战前那顿饭

**原文**：
> 「令其裨将传飧，曰：『**今日破赵会食！**』诸将皆莫信，详应曰：『诺。』」
>
> 「诸将效首虏，毕贺，因问信曰：『兵法右倍山陵，前左水泽，今者将军令臣等反背水陈，曰破赵会食，**臣等不服**。然竟以胜，此何术也？』」

**出处**：〔正史〕《史记·淮阴侯列传》：<https://zh.wikisource.org/wiki/史記/卷092>

**可提取的细节**：
- **一句不可能的话**：「今日破赵会食。」将军说今天打完赵再吃饭。
- **一个集体的假动作**：「诸将皆莫信，**详应曰：诺**。」——所有人都不信，所有人都在假装答应。**这是全部史书里最真实的一次"下级对上级"的反应。**
- **战后的当面顶撞**：「臣等不服。」**打赢了还说"我不服"**，这种关系在正史里极罕见。
- **游戏用法**：「今日破赵会食」可以直接做成一句贯穿全关的台词。玩家第一次听见时不信，打完回来吃那顿饭。

## 10. 《史记·白起王翦列传》——围城第四十六天

**原文**：
> 「至九月，赵卒不得食四十六日，**皆内阴相杀食**。来攻秦垒，欲出。为四队，四五复之，不能出。其将军赵括出锐卒自搏战，秦军射杀赵括。」

**出处**：〔正史〕《史记·白起王翦列传》：<https://zh.wikisource.org/wiki/史記/卷073>

**可提取的细节**：
- **「内阴相杀食」**——五个字，全部材料里最冷的一句。不是"易子而食"（那还有伦理结构），是**暗中互相杀着吃**。
- **一个重复动作**：「为四队，四五复之，不能出。」——四次、五次，反复冲，出不去。**这是一个循环，不是一次事件。**
- **游戏用法**：这一句可以做成关卡的"循环结构"：突围—失败—再突围—再失败，每次人数更少。

## 11. 《三国志》裴注引《山阳公载记》——华容道上的羸兵

**原文**：
> 「公船舰为备所烧，引军从华容道步归，遇泥泞，道不通，天又大风，**悉使羸兵负草填之，骑乃得过。羸兵为人马所蹈藉，陷泥中，死者甚众**。军既得出，公大喜，诸将问之，公曰：『刘备，吾俦也。但得计少晚；向使早放火，吾徒无类矣。』」

**出处**：〔正史〕《三国志·魏书·武帝纪》裴松之注引：<https://zh.wikisource.org/wiki/三國志/卷01>

**可提取的细节**：
- **"羸兵"这个词**——最弱的兵。他们不是战死的，是被派去**填路**的。
- **「为人马所蹈藉，陷泥中」**——被自己人的马踩进泥里。**死因是自己人。**
- **对比的残酷**：弱兵死完后，曹操「大喜」。**同一个段落里，一边是陷在泥里的人，一边是高兴的统帅。**
- **游戏用法**：这是最好的"被当作材料"的关卡。玩家的任务不是活下来，是**把路填好**。

## 12. 《资治通鉴》——香积寺：一个人站到阵前

**原文**：
> 「贼军齐进，官军却，为贼所乘，军中惊乱，**贼争趣辎重**。李嗣业曰：『今日不以身饵贼，军无孑遗矣。』乃**肉袒，执长刀，立于阵前，大呼奋击，当其刀者，人马俱碎，杀数十人，阵乃稍定**。于是嗣业帅前军各执长刀，**如墙而进**，身先士卒，所向摧靡。都知兵马使王难得救其裨将，贼射之**中眉，皮垂鄣目。难得自拔箭，掣去其皮，血流被面，前战不已**。」

**出处**：〔编年〕《资治通鉴》卷二百二十：<https://zh.wikisource.org/wiki/資治通鑑/卷220>

**可提取的细节**：
- **阵是怎么破的**：「贼争趣辎重」——**敌人去抢东西，阵就散了**。
- **一个人怎么稳住的**：脱掉上衣，拿长刀，站到阵前。**"肉袒"是姿态，不是战术。**
- **"如墙而进"**——四个字定义了陌刀队的全部。**不是冲，是推。**
- **王难得的伤**：「皮垂鄣目」——眼皮垂下来挡住眼睛；「自拔箭，掣去其皮」——自己拔箭，撕掉眼皮。**这是一个纯粹的技术动作，没有一句豪言。**
- **游戏用法**：「如墙而进」可以直接做成玩法：玩家是墙里的一块砖，任务是不让墙出现缺口。

## 13. 袁彬《北征事迹》——一个校尉的日常

**原文**（节选）：
> 「星月上时，随上渡宣府河，**臣下水控马**，渡讫。」
>
> 「时天寒甚，臣得宿寝傍。每至中夜，令臣**伏卧内，以两胁温上足**。」
>
> 「有夜不收杨总旗来与臣说：『今夜有五个夜不收来，密请爷爷石佛寺去，待他寻不见时，便乘间入城去。』臣备奏知，上曰：『此危事，使不得。**先在土木时不曾死，我命在天**，若万一不虞，如何好？』遂不用其计。」
>
> 「喜宁与也先说，都是校尉袁彬拨置阻住，将臣赚去芦苇地内捆了，欲开剥。忠勇伯密令人走报，上令哈铭与也先说饶臣死，**方解皮条放了**。」
>
> 「连日雨雪，上下艰难。」

**出处**：〔私记〕袁彬《北征事迹》：<https://zh.wikisource.org/wiki/北征事跡>

**可提取的细节**：
- **一个身体动作**：「臣下水控马」——他下到河里，牵着马。**夜里，星月都出来了，水很冷。**
- **另一个身体动作**：「以两胁温上足」——用两边腋下给皇帝暖脚。**这是全素材库最私密的一个动作。**
- **「方解皮条放了」**——他被皮条捆着，差点被开剥，解开之后呢？史书没写他怕不怕。
- **一句皇帝的宿命论**：「我命在天。」——**被围的时候，皇帝说的是这四个字。**
- **游戏用法**：这份文本本身就是"第一人称小兵叙事"的范本。**它没有一句抒情，全是动作、时间、地点、谁说了什么。**

## 14. 王秀楚《扬州十日记》——气味、颜色、声音

**原文**（节选）：
> 「天渐暮，大兵杀人声已彻门外，因乘屋暂避。**雨尤甚，数数人共拥一毡，丝发皆湿透。** 门外哀痛之声，悚耳慑魄。」
>
> 「城中四周火起，近者十余处，远者不计其数。**赤光相映如霞电，𤐙烞声轰耳不绝**，又隐隐闻击楚声，哀风凄切，惨不可状。」
>
> 「**满地皆婴儿，或衬马蹄，或籍人足，肝脑涂地，泣声盈野。** 行过一沟一池，堆尸贮积，手足相枕，**血入水碧赭，化为五色，塘为之平**。」
>
> 「天晴。**烈日蒸熏，尸气薰人。** 前后左右，处处焚烧，**烟结如雾，腥闻数十里**。是日，予烧棉及**人骨成灰，以疗兄疮**。」

**出处**：〔私记〕王秀楚《扬州十日记》，《明季稗史汇编》本：<https://zh.wikisource.org/wiki/揚州十日記>
**存疑**：该书为清初禁书，清末革命宣传中广泛流通，其成书与部分细节学界有争议；「查焚尸簿载数，其八十万余」明显夸大。〔私记〕部分（亲历感官描写）可信度较高，数字部分置信度低。

**可提取的细节**：
- **触觉**：「数数人共拥一毡，丝发皆湿透」——几个人挤在一张毡子里，头发全湿。
- **颜色**：「赤光相映如霞电」；「**血入水碧赭，化为五色，塘为之平**」——**血让水变成青红混合的五色，池塘被尸体填平了。** 这是全部材料里最骇人的颜色描写。
- **气味**：「尸气薰人」「烟结如雾，**腥闻数十里**」。
- **声音**：「𤐙烞声轰耳不绝」——火烧东西的爆裂声；「泣声盈野」。
- **一个动作**：「予烧棉及**人骨成灰，以疗兄疮**」——把人骨烧成灰，敷哥哥的伤口。
- **游戏用法**：这一段的感官信息密度极高，可以直接做成一整关的"环境叙事"素材库。**但要注意：这是屠杀平民的记录，不是战场记录，用在"战役"里会跑题。**

## 15. 《宋史·杨再兴传》——两升箭头

**原文**：
> 「再兴以三百骑遇敌于小商桥，骤与之战，杀二千余人，及万户撒八孛堇、千户百人。再兴战死，**后获其尸，焚之，得箭镞二升**。」

**出处**：〔正史〕《宋史》卷368：<https://zh.wikisource.org/wiki/宋史/卷368>

**可提取的细节**：
- **一个物件**：二升箭头。不是"身中数十箭"，是**把尸体烧了，从灰里筛出来的铁，装了两升**。
- **一个被省略的过程**：史书没有写他中箭的过程，只写了结果。**中间那段空白，就是剧本要填的地方。**
- **游戏用法**：这是全部材料里最适合做"结算画面"的一句。**一行字，一个容器，一个数字。**

## 第一名：井陉之战（背水）

**为什么适合**

这场比赛简直是照着 01 文档的机制表长的。逐条对：

| 01 文档机制 | 井陉的史实落点 |
|---|---|
| M1 旗号观测 | 「**拔赵帜，立汉赤帜二千**」——整场胜负就是一次旗色变更 |
| M2 鼓点辨令 | 「信建大将之**旗鼓**，**鼓行**出井陉口」；「夜半**传发**」 |
| M3 阵位（八阵） | 「**背水陈**」——一个不能后退的阵位，天然的教学关 |
| M4 传令 | 「夜半传发」「令其裨将传飧」——**两次传令，一次在半夜，一次在饭前** |
| M5 救援 | 「赵将虽斩之，不能禁也」——溃败时救不救同伍 |
| M6 登先/记功 | 「**诸将效首虏，毕贺**」——呈验首级与俘虏 |
| M7 魂穿 | 五个兵种天然齐备（见下） |

**能不能撑 5 次魂穿（5 个兵种）**

能，而且是**唯一一个五个兵种全部有原文依据**的战役：

| # | 兵种 | 史实依据 | 死法（都符合"命，不是错"） |
|---|---|---|---|
| 1 | 轻骑（二千人之一） | 「人持一赤帜，从间道萆山而望赵军」 | 抱旗在山里等一夜，天亮时被赵军发现 |
| 2 | 背水步卒（万人之一） | 「背水陈」「军皆殊死战」 | 被水挡住退路，战死 |
| 3 | 鼓手/旗手 | 「建大将之旗鼓，鼓行出井陉口」 | 中箭仍击鼓（与 01 文档第 2 关完全一致） |
| 4 | 传令兵 | 「夜半传发」 | 夜里传令走错路，被自己人当奸细 |
| 5 | 文书 | 「诸将效首虏」 | 不死，是记名的人 |

**有没有天然反转点**

有两个，而且都是视觉级的：

1. **赵军回望，营垒尽赤。** 一支还有战斗力的军队，因为看见自己营里换了旗，当场解散。**这个反转不需要一句台词，也不需要玩家做任何操作**——它应该发生在玩家扮演的角色回头的那一秒。
2. **「今日破赵会食」。** 反转在情绪层：开场所有人都不信这句话（「诸将皆莫信，详应曰：诺」），结尾所有人坐在一起吃饭。**同一句话，前后两个意思。**

**有没有现成的"文书/记功"环节**

有，而且是原文：「**诸将效首虏，毕贺。**」

"效"是呈验，"首虏"是首级和俘虏。这是秦汉军功制度的现场动作：**排队、放下人头、登记、然后集体道贺。** 可以直接做成结算界面，一行一行写名字。

再往后还有一层：韩信战后「令军中毋杀广武君，有能生得者购千金」——**功劳簿上还有一笔是"活捉敌国谋士，赏千金"**。这一笔是给谁的？给那个真正捆住李左车的人。**史书没写他是谁。**

**核心张力**

**"我知道这不可能赢，但命令已经下了。"**

这句张力在井陉是双层的：对士兵是"背水，退不了"；对军官是"将军说今天破赵再吃饭，我不信，但我得说好"。

**推荐关卡序列（15 分钟）**

| 分钟 | 关 | 兵种 | 教什么 | 死亡 |
|---|---|---|---|---|
| 0–3 | 夜半传发 | 传令兵 | 听令、跑位、黑暗中辨方向 | 走错路，被己方哨兵射死 |
| 3–6 | 背水列阵 | 步卒 | 阵位（背后是水，退一步就是死） | 补阵缺，被冲散 |
| 6–9 | 鼓行出隘 | 鼓手 | 鼓点辨令（重鼓＝接敌） | 中箭不停手 |
| 9–12 | 二千骑拔帜 | 轻骑 | 隐蔽、等待、时机 | 提前暴露，被围杀 |
| 12–15 | 效首虏 | 文书 | 记功、验首、名字 | 不死，执笔 |

**这个序列的好处**：五个兵种全部有原文，五次死亡全部是"命"不是"错"，最后落在"记名"上，与 01 文档的 R3 反转完全同构。

**风险**：井陉的史料虽然精，但**人物只有韩信、张耳、陈馀、李左车四个**，没有南霁云、袁彬那样的个体故事。共情要靠"器物"和"动作"补，不能靠人名。

## 第二名：土木堡之变

**为什么适合**

因为它是**唯一一个有当事人第一人称文本的战役**。袁彬《北征事迹》是一份完整存世的题本，一个锦衣卫校尉用"臣"的口吻，一天一天记下他跟着皇帝被俘的一年。这份文本解决了叙事游戏最难的问题：**小兵怎么说话。**

其他优势：

- **有"皇帝"这个极端变量**。一个小人物的一生里突然出现一个皇帝，这本身就是最好的戏剧结构。
- **有清晰的空间**：土木堡（无水的高地）→ 宣府（城下答话）→ 大同（城下答话）→ 漠北（苏武庙四十日）→ 回京。**五个场景，一条线。**
- **有明确的机制**：断水（资源）、移营（命令导致溃败）、护驾（跟随目标）、传话（在敌我之间跑）。

**能不能撑 5 次魂穿（5 个兵种）**

能，五个视角全部有原文：

| # | 兵种 | 史实依据 | 死法/结局 |
|---|---|---|---|
| 1 | 京营步卒 | 「士卒已乏粮」「掘地二丈不及水」「行乱」 | 移营时被踩死 |
| 2 | 夜不收（侦察兵） | 「有夜不收杨总旗来……今夜有五个夜不收来」 | 摸营被发觉，被杀 |
| 3 | 通事（哈铭） | 「蒙古人，幼从其父为通事」 | 不死，是活着回来的人 |
| 4 | 锦衣校尉（袁彬） | 全文自述 | 差点被开剥，活下来了 |
| 5 | 文书 | 袁彬因「会写字」被留在皇帝身边 | 不死，是写这份题本的人 |

**注意这里的结构**：第 4 和第 5 其实是同一个人（袁彬）。这反而是优势——**玩家最后一次魂穿，落到一个"已经在前面出现过"的人身上**，这是天然的闭环。而且第 5 关的动作不是打仗，是**写字**。

**有没有天然反转点**

有三个，全是原文：

1. **乱军之中认出皇帝。** 「是臣远观，认的是我英宗皇帝。臣叩头哭。」一个校尉在几万人里看见了一个人，跪下哭了。
2. **皇帝教他撒谎。** 「你不要说是校尉，只说是原在家跟随的指挥。」——**最高权力者在向最低身份者求助时，第一反应是改他的身份。**
3. **五个夜不收来救，皇帝说不去。** 「此危事，使不得……我命在天。」——**玩家做完了全部准备，被救的人拒绝了。**

**有没有现成的"文书/记功"环节**

**有，而且是全素材库最强的一个：袁彬《北征事迹》本身就是一份文书。**

它的开头是：「锦衣卫掌卫事都指挥佥事臣袁彬谨题，为纂修事。成化元年七月二十一日，该太保会昌侯孙继宗等题，英宗皇帝车驾北征往还事迹，有锦衣卫都指挥佥事袁彬一向随侍，必能详知，合无令其开写具题。」

**这是成化元年（1465），朝廷要修实录，把当年那个校尉叫来，让他把亲身经历写下来。**

所以整个游戏的结尾可以是：**一间屋子，一盏灯，一个老人在写二十年前的事。** 他写的每一行，就是玩家刚才玩过的每一关。**这不是虚构的反转，这是史实给的反转。**

**核心张力**

**"我不是在打仗，我是在跟着一个人。"**

土木堡之变对士兵来说最恐怖的不是敌人，是**没有水**、**命令反复**、**队伍散了**。而袁彬这个角色的特殊之处是：他在所有人都跑散的时候没有跑，**因为他识字**。

**推荐关卡序列（15 分钟）**

| 分钟 | 关 | 兵种 | 教什么 | 结果 |
|---|---|---|---|---|
| 0–3 | 掘地二丈 | 步卒 | 资源耗尽（水） | 渴死/被踩死 |
| 3–6 | 移营 | 步卒 | 命令即溃败（"行乱"） | 被骑兵冲散 |
| 6–9 | 夜不收摸营 | 侦察兵 | 潜行 + 传令 | 被发觉，死 |
| 9–12 | 乱军认主 | 校尉 | 在人群中找一个特定的人 | 差点被开剥 |
| 12–15 | 写题本 | 文书（袁彬） | 记名 | 不死 |

**风险**：土木堡没有旗鼓对阵的场面，M1/M2（旗/鼓）在这一战里用不上。如果 demo 必须展示"旗鼓辨令"，土木堡做不到。

## 第三名：睢阳之战

**为什么适合**

因为它的**情感强度是全部素材里最高的**，而且它的结构天然是"五幕递减"：有粮 → 缺粮 → 无粮 → 食人 → 城破。这是一条不需要设计的曲线，史书已经写好了。

更重要的：**它有小人物最完整的一条线——南霁云。**

一个撑船的（「少微贱，为人操舟」）→ 因为"张公开心待人"留下来 → 围城时从募兵台上哭着走出来（「俄有喑鸣而来者」）→ 突围求援 → 被拒 → 断指 → 射箭入塔立誓 → 带一千人回城 → 城破 → 张巡喊他"南八" → 他笑着说"敢不死"。

**这是一条完整的、真实的、有名字的小人物弧线。** 整个素材库里只有这一条。

**能不能撑 5 次魂穿（5 个兵种）**

能，且五个兵种全部有史实支撑：

| # | 兵种 | 史实依据 | 死法 |
|---|---|---|---|
| 1 | 弓手 | 「霁云善骑射，见贼百步内乃发」 | 箭尽，被擒 |
| 2 | 守城步卒 | 缒城、绳城、剡蒿为矢、驱牛入城 | 城破战死 |
| 3 | 传令/求援 | 南霁云夜缒出城 | 断指而归 |
| 4 | 火头军 | 「易子而食，析骸而爨」——炊事的人最先知道没粮 | 饿死 |
| 5 | 文书 | 「等三十六人遇害」——名单是有人记的 | 不死 |

**有没有天然反转点**

有三个：

1. **援军不来的那一天。** 「城中将吏知救不至，恸哭累日。」——**希望被移除比城破更狠。**
2. **断指。** 「请置一指以示信。」拔刀，砍下手指，一桌人惊哭，他一口饭没吃就走了。**这是一个不需要解释的动作。**
3. **大雾中的辨认。** 「方大雾，巡闻战声，曰：『此霁云等声也。』」——**张巡在大雾里靠听声音认出了自己的人。** 这正是 01 文档 M2"盲听关"最完美的史实落点：**大雾、只有声音、要判断来的是敌是友。**

**有没有现成的"文书/记功"环节**

有，但比前两名弱。

- 强的部分：**「与姚訚、雷万春等三十六人遇害」**——一个明确的死亡名单数字。加上二十一个有名有姓的别将（石承平等）。**这是全素材库最现成的"阵亡名录"。**
- 弱的部分：睢阳是守城战，没有"效首虏"那种现场记功动作。军功在这座城里意义不大，因为**没有人能活着去领赏**。

**核心张力**

**"我们知道不会有人来。"**

这句话在前面几关都不成立，在睢阳成立。士兵不是在为胜利守城，是在为"多守一天"守城。

**推荐关卡序列（15 分钟）**

| 分钟 | 关 | 兵种 | 教什么 | 结果 |
|---|---|---|---|---|
| 0–3 | 缒城 | 步卒 | 上下的技术（绳、钩、陌刀、强弩） | 被射死 |
| 3–6 | 剡蒿为矢 | 弓手 | 伪装（让敌人以为没箭了） | 射目成功，但被反扑 |
| 6–9 | 夜缒求援 | 传令 | 穿越敌营 + 被拒绝 | 断指而归 |
| 9–12 | 大雾辨声 | 弓手/哨兵 | 盲听（M2 王牌关） | 误判，射死自己人 |
| 12–15 | 三十六人 | 文书 | 记名 | 不死 |

**风险（必须处理）**

**食人是这一战不可回避的核心史实，也是最大的内容风险。**

「巡乃出其妾，对三军杀之，以飨军士」；「乃括城中妇人；既尽，以男夫老小继之，所食人口二三万」。

处理建议（三选一，推荐第三种）：

1. **完全不碰**——只做前四关，第五关跳到城破。缺点：抽掉了这一战最核心的道德重量。
2. **只做后果**——玩家进入第三幕时，城中已无炊烟，长官在写名单，不需要看见过程。
3. **做成"不知道"**——玩家扮演的士兵在第四关被派去领"肉"，他不知道那是什么，也不需要知道。**玩家会知道。** 这个信息差就是全部的力量，而且完全符合史实（《旧唐书》原文就是"强令食之"）。

## 为什么不是其余战役

| 战役 | 不推荐做 demo 的原因 |
|---|---|
| **淝水** | 反转极强（朱序一句"坚败"），但**士兵个体材料为零**。5 视角要大量虚构，且秦军士兵连一个名字都没有。适合做"第二战役包"。 |
| **香积寺** | "陌刀如墙"是极好的单关，但**只有六小时一场战斗，没有阶段变化**。15 分钟做一场没有节奏起伏的消耗战，会闷。 |
| **萨尔浒** | 材料极好（尤其朝鲜军），但**四路分兵，叙事结构散**。而且伤亡数字太精确（45870），容易让玩家以为在玩统计游戏。适合做"多线叙事"的完整版，不适合 15 分钟 demo。 |
| **长平** | 主题最重（断粮、坑杀），但**没有可交互的高潮**。坑杀不能做，突围必败，玩家四十六天里能做的只有等。 |
| **垓下** | 抢尸那一段极强，但**整场是追击战**，主角光环全在项羽身上，小兵视角会被压掉。 |
| **巨鹿** | "三日粮倒计时"很好，但**个体记载几乎为零**，且"破釜沉舟"太有名，玩家的预期会盖过设计。 |
| **赤壁** | 被《三国演义》污染最严重，**任何设计都会被玩家用演义知识校正**。而且赤壁的个体材料（除了羸兵填路）很薄。 |
| **宁远** | **史料个体太少**。《明史·袁崇焕传》关于宁远不到三百字，除罗立、金启倧外无一名士兵。只能做单关。 |
| **小商河** | **史料不足以支撑档案**（全文相关记载不到一百字）。但它有全素材库最强的单一意象（箭镞二升），**建议降级为死亡转场的一行字，而不是一关**；空出的位置用**浚稽山之战**顶上（见第 12-补 条）。 |

## 一个额外的建议

如果 demo 只用一场战役，选**井陉**。

如果 demo 想展示"多战役包"的野心（01 文档 P3 的扩展方向），用**井陉开场 + 小商河的"箭镞二升"做一次死亡转场 + 土木堡收尾**。三场戏各有各的功能：井陉给机制，小商河给重量，土木堡给人物。而三场之间不需要任何过渡——**魂穿本身就是过渡。**
