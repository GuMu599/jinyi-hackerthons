## 2. 世界构成

坐标沿用原场景：城墙在 `z = 34`、城门在 `x = 0`、攻方从南侧（`z < 34`）接近，地面高度约 `y = 6.2 ~ 7.6`。

| 层 | 做法 | 参数 |
|---|---|---|
| 台地 | 原 `BattlefieldGround` 网格（240×240 顶点，200×200m） | 保留原起伏，直接在其上刻河槽 |
| 河 | 在原网格里下压 3.1m 的槽，槽上铺水面网格 | 河心 `z ≈ -62 + 22·sin(x/55) + 10·sin(x/23)`，槽宽 52m，水面宽 38m，水面 `y = 6.05` |
| 谷地 | `FarField`：4000×4000 平板，靠近河处压平 | `y = 4.40 + Perlin×9`（河岸 90m 内归零） |
| 山脊 | 三层环形锯齿带，每层 520 段顶点、5 个八度的脊状噪声 | 半径 620 / 1080 / 1750m，基准高 55 / 130 / 240m，振幅 95 / 170 / 250m；近层深灰、中层蓝灰、远层浅蓝 |
| 大气 | 线性雾 | 起点 220m、终点 2100m，颜色 `(0.70, 0.76, 0.84)` |

**为什么山要做三层**：一层山只有一个剪影；三层会互相咬边，视觉上才有纵深。远层靠雾变浅，不需要额外的空气透视 shader。

**为什么河要刻进地面而不是铺一张平板**：铺平板会得到一条高出地面的蓝色水带，从任何角度都不对；刻槽之后河岸自然形成，水面低于地表 1.3m，站着看就是一条沟里的河。

## 4. 魂穿第一人称

脚本（`Assets/Scripts/`）：

| 文件 | 作用 |
|---|---|
| `PossessionTarget.cs` | 挂在每个假人上的标记：`unitId` / `role` / `possessable`，`EyePoint = 脚底 + 1.66m` |
| `PossessionController.cs` | 挂在 Main Camera 上：**F 附身最近的可附身假人**、鼠标转头（水平 360° / 俯仰 ±80°）、WASD 小步移动、**Esc 抽身** |
| `SightlineAudit.cs` | 视线审计：判定哪些假人配得上"可附身" |

附身时的三条硬约束（代码里落在 `ApplyCameraConstraints` 与 `Possess`）：

1. **自己的模型必须消失**：附身瞬间把该假人身上所有 `Renderer` 关掉，否则镜头就在后脑勺里；
2. **相机参数固定**：`near = 0.05`、`far = 2600`、`FOV = 72`、`shadowDistance ≥ 160`——远山、河面、城墙必须同时在裁剪范围内；
3. **眼高固定 1.66m**：贴地、不悬空，站着的人看世界的高度。

## 5. 视线审计：什么限制能保证"代入后看得到四周"

这是这一版唯一的"规则"，也是被问到的那个问题的答案。审计定义（`SightlineAudit.cs`）：

| 维度 | 判据 | 当前结果 |
|---|---|---|
| 渲染 | 远裁剪 ≥ 2000m、雾终点 ≥ 1800m、FOV ≥ 70°、阴影距离 ≥ 120m | 全部 OK（2600 / 2100 / 72 / 160） |
| 站位 | 眼点向 8 个水平方向各打一条 600m 射线，**至少 4 个方向**不被近处地形/人墙挡住 | 84 个假人达标 |
| 地标 | 城门、河面、北山脊、南山脊四个地标，**至少看到 2 个** | 同上 |

执行方式：`SightlineAudit.ApplyGate()` 把不达标的 `PossessionTarget.possessable` 置 false，控制器不会选中它们。

当前结果：**113 个假人里 84 个可附身，29 个被排除**（集中在阵列中段和左翼洼地），可附身集合内部 0 个不达标，审计结论 `PASS`。

被排除的 29 人不是"坏了"，他们仍然在场上、仍然计数——只是玩家不能从他们眼睛里看世界。这就是"限制"的实现方式：**不是把地图做大，而是只允许从看得见风景的位置代入。**

## 6. 与既有文档的口径冲突（需要拍板）

`资料库/10-游戏与影像参考.md` 第 502 行、`16-实机画面规格.md` 第 347 行、`18-玩家看到的画面.md` 都明确写了「放弃 3D 低多边形」「不做第一人称走读」，`06-完全体玩法.md` §14 也列了「不做 3D、不做第一人称走读」。

本次按你的要求转成了三维 + 第一人称。**这两套口径不能同时成立**，建议二选一：

- A. 承认转向：改 `06` §14 第 1 条与 `资料库/10` 第 502 行，把三维原型当作"实机验证载体"，二维版画作为最终美术方向；
- B. 三维只做内部工具：不对外，最终交付仍是二维版画。

在拍板前，我不会去改那些文档的结论。

## 8. 下一步（按性价比排）

1. **美术解耦**：现在的假人是灰模 + 布纹材质，和城墙的青砖不在一个写实度上；先定"假人要不要做旧、要不要上甲片"。
2. **守军动画**：墙顶 13 人现在是静止假人，加一个循环的"张望/放箭"能让城活起来。
3. **器械升级**：要么把现有 primitive 器械按 WallBrick/WoodMat 的写实度做细节（推荐），要么换 Kenney 的低模但统一全局美术口径。
4. **附身镜头**：现在是纯第一人称；如果要做"魂穿"的抽离感，可以在附身瞬间加 0.4s 的上升 + 视线拉远，再落到眼高。
5. **名册联动**：`PossessionTarget.unitId` 已经预留，接册子时直接用。
