**五个反直觉点，全部可直接做玩法：**

1. **同样的鼓敲第二遍，意思从"进"变成"接敌"**（重鼓则击）。玩家只记"鼓=冲"就会在第二通鼓送命。
2. **金鼓同时响＝全体坐下**，不是"又进又退"。
3. **低旗＝加速**。旗不只有方向，还有速度。
4. **金二声＝后退，但金连二声＝转身向前立定**（假装退却的战术动作）。有组织的退和被击溃是两回事。
5. **"鸣金＝撤退"是流行误解**。金有五义：缓/止/退/背/急背（《武经总要》）。

## A1.5 三条必须补进设计的细节

**1. 新兵的第一课是一块瓦。**

《尉缭子·兵教上》：「伍长教其四人，**以板为鼓，以瓦为金，以竿为旂**……麾而左之，麾而右之，金鼓俱击而坐。」

新兵最初听的"鼓"是木板，听的"金"是瓦片，看的"旗"是竹竿。**这是现成的开场教学关，而且是史实**：玩家第一次学会的信号全是假的替代品，等真打起来，才发现真正的鼓声大得能让胸口发麻。

**2. "敌人从哪来"是靠磨旗，不是靠角声。**

敌情方向由五方旗与望旗承担（五方旗「举旗者，令诸军知贼所从来也」）。望旗的语义（《武经总要》）：

| 动作 | 含义 |
|---|---|
| 旗头向上磨 | 贼远 |
| 平低磨 | 贼近 |
| 低垂向下磨 | 贼近百步 |
| 绕竿头转递 | 四面来 |

塘报旗：**摇旗＝有贼至，摩旗＝贼多**。

"磨"是一个动作，不是一种颜色——这正是"观察"玩法需要的东西：玩家看的不是旗语词典，是那只手在怎么动。

**3. 旗是三维编码，不是纯色块。**

《武备志》卷一〇一：**心色表方位、边色表司属、号带表营属**。尺寸随级别递增：队长认旗方 1 尺（竿 1 丈 5 尺、悬高 9 尺）→ 旗总 1 尺 5 寸 → 哨官 2 尺 → 把总 3 尺 → 营将 5 尺 → 主将长 3 尺阔 1 尺 5 寸、十尾、五色带 25 条。

士兵侧唯一的身份标记：「军士盔有缨而无旗。**队总盔旗长三寸，上书队哨分数字样**」。

夜营灯具精确到寸，且**每盏配黑油罩，"使寸明不露"**——遮光就是断令。

> 版本提醒：「鼓之则进，重鼓则击；金之则止，重金则退」出自《尉缭子·勒卒令》，但维基文库底本自标"未完成"、该篇残缺，未能直读，另有来源称已读。游戏引用时注"见《尉缭子·勒卒令》"，**不要把它当成铁板钉钉的原文**。

## A2 旗语：五方旗用身体方位，不用东南西北

《纪效新书》卷二：

- 面所向谓之前 → **红旗**
- 面所背谓之后 → **黑旗**
- 左手所指谓之左 → **青旗**
- 右手所指谓之右 → **白旗**
- 脚下所立谓之中央 → **黄旗**

戚继光的原话：「以东南西北为名，则愚民一时迷失方向……惟左右前后属人之一身。」

**这是"小兵视角"的钥匙。** 旗语不是地理知识，是身体感。玩家不需要地图，他只需要知道自己的脸朝哪、左手在哪。这条规则比任何"左上角小地图"都更有代入感。

同一套编码在先秦就有：《吴子·治兵》「必左青龙，右白虎，前朱雀，后玄武，招摇在上」。

另注：士兵认的是**本总哨自己的颜色**（各营自定认旗），不是全国统一旗色。所以"我不认识将军，我只认识那面旗"是史实台词。

## A3 阵型映射：鼓数 + 旗色 = 阵形（最好用的玩法表）

《武经总要·前集》卷八引裴子法：

| 鼓数 | 旗色 | 阵形 |
|---|---|---|
| 一鼓 | 黑旗 | 曲阵 |
| 二鼓 | 朱旗 | 锐阵 |
| 三鼓 | 青旗 | 直阵 |
| 四鼓 | 白旗 | 方阵 |
| 五鼓 | 黄旗 | 圆阵 |

**注意逻辑：玩家必须同时看鼓数和旗色，任何一个错都会变错阵。** 这是天然的"双通道校验"机制——只听鼓会错，只看旗也会错。这正是"观察与辨听"两个玩法要素拧在一起的地方。

地形决定阵型（同卷）：

- 高平利方 · 四方高利圆（圆利守）· 左右高利牝 · 后高前下利牡 · 前高后下利冲方 · 平易利车轮 · 斥泽利罘罳 · 城丘利雁行（雁行利绕）

## A4 八阵图的真相（关键：八卦阵是后人的臆说）

**史料原点只有一句话**（《三国志·诸葛亮传》）：

> 「亮性长于巧思，损益连弩，木牛流马，皆出其意；推演兵法，作八阵图，咸得其要云。」

**八阵的八个名字是编制番号，不是卦象**（《武经总要·前集》卷八）：

> 天阵、地阵、风阵、云阵、虎翼阵、蛇盘阵、飞龙阵、鸟翔阵

正确的阵名：**天、地、风、云、龙、虎、鸟、蛇**。没有任何一个对应乾坤震巽。

**核心结构**（《握奇经》，转引）：

> 「四为正，四为奇，馀奇为握奇」「阵数有九，中心奇零者，大将握之，以应副八阵之急处。」

即：**八个可调度单元 + 一个主帅亲掌的第九单元（预备队）**。这是真能做成玩法的结构。

**把八阵配八卦，宋人就骂过**（《武经总要》评唐李筌）：

> 「配四正四奇之位于八卦……则筌尽出臆度，殊乖本文。」「阵图所存者，惟唐人李筌有八阵图，而其说难以依据。」

**鱼腹浦石阵的真相**（同卷）：

> 「今夔州之南北岸，沙中累石，为八阵形势。凡八行，行相去二丈。」

就是沙滩上八行石头、行距二丈的**阵列示意**（训练/纪念用），不是会困人的迷宫。

**演义版**（《三国演义》第八十四回）：黄承彦说「反复八门，按遁甲休、生、伤、杜、景、死、惊、开」——纯属小说家言，无任何兵书依据。

**结论与用法建议：**

| 用途 | 能不能用 | 怎么标注 |
|---|---|---|
| 八阵＝天地风云龙虎鸟蛇 + 四正四奇 + 大将握奇 | ✅ 用，这是史实 | 图鉴可直引《握奇经》 |
| 生门/死门/遁甲八门 | ⚠️ 只能标为"民间传说版" | 用一个角色说"听人说书这么讲"，另一个角色说"兵书里没有" |
| 唐李筌的八卦配位图 | ⚠️ 可标为"唐代某家的臆说" | 礼学评委看到这个注，会认为我们做了功课 |

**这个落差本身就是好戏**：让文人谈八卦，让士兵只认颜色。戚继光自己就说八卦是"读书有位者"的学问，「然不可以之责行伍之人」。

## A5 先登之功的真相（比想象的更冷）

**"先登"专指攻城首先登城**，与野战破阵的"陷阵"是两条赛道（《尉缭子·制谈》「先登者未尝非多力国士也，先死者亦未尝非多力国士也」）。

**明代赏格：六次先登才升一级**（《明会典》卷一百六）：

> 「（成化）七年，令六次先登、杀败敌兵者，升一级加赏。三次及阵亡者，升一级给赏。齐力策应者，给赏不升。」
> 「无伤而当先数多者，止给赏。」

单次先登通常只有赏银，**不升级**。这比"先登封侯"的通俗想象残酷得多，也真实得多。

**秦制记名方式：木台上三方共同监看**（《商君书·境内》）：

> 「将军为木台，与国正监，与王御史，参望之。其先入者，举为最启；其后入者，举为最殿。」
> 「以战故，暴首三，乃校三日，将军以不疑致士大夫劳爵。」

先入者记"最启"、后入者记"最殿"，人头要陈列三天验首才定功。**制度预设了冒功的可能，所以设计了三方监看——但"三个人同时看见"也意味着只有极少数先登者会被看见。**

**"功归他人"的史料**（郑若曾一系，明代现场证词）：

> 「两军相敌，当先格斗者，手眼瞬息不得差池，何暇割首？使其取首，则再不能战，而为敌所乘……故杀贼者不能取首，而得首者又为势家所夺；又或因争首级，自相蹂践，而为敌所败，此边人之大恨，兵战之大患也。」

> ⚠️ **版本存疑，引用须留神**：上述文字转引自《筹海重编》卷十（邓钟重编本）。另一次独立核查在《筹海图编》卷十一**未检得此句**，故不能确定它出自郑若曾原书还是重编者之手。**可确证的等价表述**是胡世宁原话：「斩获首级者，又被势豪夺去」，以及「势豪夺功买功之弊，尤宜痛革」。送审文稿请用胡世宁这两句，或写"郑若曾一系记载"，不要写成确定的书名卷次。

**功劳归谁：制度在一百二十年内翻转过一次**（这是第 5 关反转的直接地基）

| 时代 | 规定 | 一个战死的先登者会得到什么 |
|---|---|---|
| 秦《军爵律》 | 「未拜而死……皆不得受其爵及赐」 | **死在核功与拜爵之间，爵位直接消失** |
| 秦《军爵律》 | 「其已拜，赐未受而死，予赐」 | 已拜爵的，赐物可给 |
| 《商君书·境内》 | 「死则一人后」 | 由一人承袭 |
| 明景泰五年 | 「许并其功于见存之人」 | **功可以并给还活着的人**（等于让人代领） |
| 明万历五年 | 「追赠阵亡之人，不许同籍并功」 | **改为必须追赠死者本人，不许并给别人** |

**这就是玩家扮演的文书翻开功次册时，手里那支笔的分量**：同一本册子，早一百二十年，他可以不写那个死人的名字而是写别人的；晚一百二十年，他必须写死者。制度本身在变，而每一次变，都有人因此被记住或被抹掉。

**戚继光设了专岗来替人割头**（说明这事普遍到必须编制化）

- 长兵**不许带解首刀**（因为长兵要顶住，不能腾手）
- 每哨设两名膊缝"取功"白布的**割级亲兵**
- 收兵后，首级**尽数派给冲锋兵均分报功**

→ 游戏里这是现成的角色位：一个专门替别人割头、自己不领功的人。

**明代计功让"大战不值钱"**

- 成化十四年：「一日一处之数，止拟一级」——同一天同一处砍十颗，只算一级。
- 天顺七年：「六次先登、杀败敌兵者，升一级加赏。**三次及阵亡者，升一级给赏**。」

→ **先登三次 ＝ 阵亡一次 ＝ 一级。** 这个等式不用加工，可以直接做图鉴卡。

**真正拼命的人腾不出手割头，割头的往往不是拼命的人，而首级又被"势家"夺走。** 这是本设计"文书记账"反转的硬史料支撑。

**抢登是违纪，而且会被斩**（《尉缭子·武议》）：

> 「吴起与秦战未合，一夫不胜其勇，前获双首而还。吴起立命斩之。军吏谏曰：'此材士也，不可斩！'起曰：'材士则是也，非吾令也。'斩之。」

以及《尉缭子·兵教下》：「其后者不得争先登不次。」

**先登者的实际生还率：没有任何量化史料。** 可用间接证据（《孙子·谋攻》"杀士三分之一"；《商君书》为陷队之士预设"死则一人后"；《明会典》以六次为门槛），但**游戏里不要给出具体百分比，也不要写"先登必死"为定论**。

## A6 小兵制度（每一��都能变成机制）

| 制度 | 原文 | 玩法转化 |
|---|---|---|
| 什伍连坐 | 「五人为伍，伍相保也……伍有干令犯禁者，揭之免于罪，知而弗揭，全伍有诛」《尉缭子·伍制令》 | 告发免罪 / 隐瞒连坐 |
| 同伍战死，四人受刑 | 「一人死，而刭其四人。能人得一首，则复」《商君书·境内》 | **四个人的命要用一颗人头赎回**——抢首级行为的制度根源 |
| 夺功 | 「战亡伍人，及伍人战死不得其死，同伍尽夺其功。**得其尸，罪皆赦**」《尉缭子·兵令下》 | **抢回尸体可以免罪**——"救援任务"的硬机制依据 |
| 牌手阵亡，全伍皆斩 | 「牌手阵亡，伍下兵通斩」《纪效新书》卷二 | 保护最前排＝保护自己 |
| 分级连坐 | 「管五名以上者，一名有犯必连坐之……管一万名者，五百名有犯必连坐之」《练兵实纪》卷二 | 连坐是按比例算的 KPI，不是一人犯错全斩 |
| 兵看各营把总的，把总看中军的 | 「如旗不起，脚下即是信地，虽天神来叫移动，也不许依从擅动」《纪效新书》卷二 | 层级传递；"天神来也不许动" |
| 每队一个识字的人 | 「识字者自读，不识字者就听本队识字之人教诵解说」《纪效新书》卷二 | **"文书"角色的史实依据**：队里唯一识字的人＝朗读员＝书记 |
| 传令靠口授＋抽查 | 「队总口授军兵而止，须要传说明白……差巡视旗于街上或歇家唤二三个军来问之，照不知条内查治」《练兵实纪》卷二 | 传令丢了词要挨罚，天然的紧张感 |
| 通行靠符节 | 「非将吏之符节，不得通行」《尉缭子·分塞令》 | 白昼关卡用符节；夜间另有"夜号"制度，见本表下方 |
| 兵器上写番号 | 「虽一弓一箭，须书各行伍在上」《练兵实纪》卷二 | 身份道具 |

## A7 真实的随身之物（比编的更动人）

**唐兵个人装备**（《新唐书·兵志》）：

> 「人具弓一，矢三十，胡禄、横刀、砺石、大觿、毡帽、毡装、行縢皆一，麦饭九斗，米二斗，皆自备。」

弓一张、箭三十支、箭袋、横刀、磨刀石、解绳锥、毡帽、毡衣、绑腿、炒麦九斗、米二斗。**主粮是炒麦，米是稀缺品。**

**一火十人公用**：乌布幕、铁马盂、布槽、锸、䦆、凿、碓、筐、斧、钳、锯。

**黑夫家书**（睡虎地 **4 号墓**出土 11 号木牍，攻城的间隙写的；墓主是收信人、他们的兄长"衷"）：

> 「遗黑夫钱，母操夏衣来……黑夫等直佐淮阳，攻反城久，伤未可智（知）也，愿母遗黑夫用勿少。书到皆为报，报必言相家爵来未来。」

**"妈，寄钱和夏衣来，顺便告诉我爵位批了没有。"** 这是中国最早的家书之一，写于攻城期间。可直接做游戏内可读文献，全文用原文，不用改写。

**收尸**：匈奴「战而扶舆死者，尽得死者家财」（《史记·匈奴列传》）；戚继光连战马都要求「全体掩埋，不许开剥食用」。

**庆功宴座次就是排行榜**（《吴子·励士》）：「上功坐前行……次功坐中行……无功坐后行」，赏赐还发到家属手里。

## A8 必须避开的十个错误（内容红线）

1. **"鼓声一响就全军冲锋"** → 错。鼓有步鼓/趋鼓/鹜鼓的速度分级，五鼓是整天的日程，冲锋只是其中一种。
2. **"三通鼓＝冲锋"** → 错。唐代三通是**角**（一收取、二偃旗、三举旗），之后才击鼓。"三通鼓"是小说语汇。
3. **"鸣金＝撤退/逃跑"** → 错。金有五义，明代细到一声/二声/连二声。
4. **"八卦阵是诸葛亮的实战阵法"** → 错。八阵是天地风云龙虎鸟蛇八个编制单元；配八卦是唐李筌臆说，宋《武经总要》已斥"尽出臆度"。
5. **"鱼腹浦石阵是困住陆逊的迷宫"** → 演义虚构。真实是沙中八行石、行距二丈。
6. **"先登一定重赏封侯"** → 错。明代需六次先登才升一级。
7. **"不听令抢先登也能记功"** → 错。吴起斩过抢先斩首的勇士。
8. **"士兵能读军令布告"** → 错。不识字者靠队里识字的人念。
9. **"主将一喊就能指挥"** → 错。旗鼓不动时「就是天神来也不许依从」。
10. **"督战队在后排射杀逃兵"** → 未找到史料，不要用。真实的是"尽斩"军法与分级连坐。

**另四条容易踩的：**
- "号角是冲锋号" → 错。角用于警众、收众、集合、定方向；戚家军冲锋是擂鼓。
- "古代的军饷必然层层克扣" → 不准确。明代有唱名发放、包封秤兑、允许告发克减的制度；真正的日常贪法是"折干"（交钱免役）。
- **"失期，法皆斩"** → 这是《史记·陈涉世家》里**汉代人的叙述**，与出土《秦律十八种·徭律》直接冲突。秦律对失期的处罚是**斥责、罚盾、罚甲**：「失期三日到五日，谇；六日到旬，赀一盾；过旬，赀一甲」，而且「**水雨，除兴**」——下雨可以免征。**旁白绝对不能当制度陈述。** 让角色在台词里说"失期当斩"，再让懂律的军官当场纠正他——这才是好戏，而且是真的。
- **睡虎地两个墓别搞混**：黑夫、惊的家书出自 **4 号墓**（收信人是兄长"衷"）；**11 号墓**主是县吏"喜"，《编年记》（一作《叶书》）的作者。写的时候分清。

## B 技术实现参考（1-2 人 / 34 小时）

**音频——真的不需要素材，全部现场合成：**

| 音色 | 合成方式 |
|---|---|
| 鼓 | OscillatorNode 正弦 150→45Hz 快速下滑 + 短噪声层（即 Tone.js MembraneSynth 原理） |
| 钲/金 | 非谐波 FM / MetalSynth，长衰减 |
| 号角 | sawtooth + vibrato（LFO） |

- **必须用 `ctx.currentTime` 提前调度，不能用 `setTimeout`**（后者在音频上有可闻抖动）。
- **首次发声必须由用户手势触发**（浏览器 autoplay 策略）。把"击鼓开战"做成开场按钮，既符合规则又贴合题材。
- Tone.js（MIT）现成有 MembraneSynth / MetalSynth / NoiseSynth / FMSynth。

**叙事引擎**：手写 JSON 状态机 + 一个 30 行对话渲染器。分支浅（2-3 个判定点），真正的复杂度在音频时机和战场状态。不引 ink（会多一层"玩法↔叙事"互调成本）。第 3 天有余力再迁。

**战场视图**：≤60 个符号建议直接用 DOM/SVG + CSS transition，省掉渲染循环，随时可调试。要粒子和上百单位才上 Canvas。

**中文竖排**：`writing-mode: vertical-rl` 可用（Baseline，caniuse 98.3%），**只用在文字面板，不要用在 body**；数字/拉丁字母用 `text-combine-upright: all`。

**字体**：思源宋体 / Noto Serif SC / 霞鹜文楷，均 OFL。demo 只有几百字，子集到 30-80KB。

## C 评审视角：实际会看什么

> ⚠️ **来源降级**：以下几条最初标为"Devpost 对多位黑客松评委的访谈"，但后续独立核查时该原文被反爬拦截、**未能核实**。**不要在答辩里当作数据引用**，只能作为经验判断。

- （可核实）Shipaton / Devpost 一类参赛指南的说法：评委被要求观看的时长很短，钩子要在 15–20 秒内出现，60–90 秒内要给完实证。
- （可核实）联谱日程：12-18 10:00 开赛 → 12-19 20:00 提交，约 34 小时；答辩 10:30–14:30 共 4 小时，6 位评委。
- （推断）初筛主要看能不能跑起来、基本设定成不成立。
- （推断）评审会先玩，先看视觉、再看代码。
- （推断）视频是投入程度的第一指标，只优化单一维度会拉低总分。

**推论：打开即玩 → 30 秒内出现第一个"我懂了" → 3 分钟录屏必备。**

**必砍**：考据级美术、自由战斗、>3 个结局、后端/账号、程序化战役、音频素材库、配音、独立教程关、兵种数值成长、移动端适配。

**必留**：
- 45-90 秒可重复的"旗-鼓-钲"判断闭环（错了有可见后果）
- 3 分钟内第一次魂穿，且新角色立刻有不同能力 + 一句生平
- ≤60 符号的可读战场
- 一条贯穿的人线索
- 结算知识卡（先登 / 八阵 / 金鼓，3 行内，放情绪之后）

**一个容易被忽略的点**：魂穿规则必须在开场 60 秒内用一句老兵旁白说清——「我们这队人，死了就换个人接着喊」。否则玩家会当成 bug。
