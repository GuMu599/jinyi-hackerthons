# 《壕口》：沉浸式战场冒险可玩案例

> 讨论稿。以下是一场虚构战役的关卡构想，不对应某一场真实战役。参考素材：《08-战例与小兵视角.md》中的家书、军营生活、旗号和士兵身体经验。

ps提示词：我觉得方向看上去可以，玩法还是有点模糊，你可以给我一个具体的case吗，我希望这个游戏是沉浸且震撼的，或者你可以帮我拆解一下一个普通的小兵他在战场上的心路历程，越细越好。你可以参考下这个资料，影响心境的可能是多方面的东西，小兵或许也很年轻，还没怎么训练就被征兵，军营条件恶劣，他或许想家，想爹娘，或许被同伍欺负看不起，但他们同吃同睡也积攒了深厚的情谊，大家都在猜测这场仗应该打不起来，但很平常的一个半夜或者清晨，懵懂地就被推上战场，在跟着队伍出城门的那一刻，才有实感，前一晚预想的害怕似乎并没有，更多的是悲壮凄凉，他或许不懂这次出兵意味着什么。他或许是最不被看好的那个，真正打起来，他左砍一刀右挡一剑竟然也杀了几个人，第一次杀人他甚至很平静，可手抖的生理反应克制不住。他受了伤，但感觉不到疼，只能边流泪边机械的挥刀，慢慢的他发现身边熟悉的面孔一个一个都不见了，他来不及找他们，巨大的力量把他抡飞出去，他躺在地上，眼前是血色和泪水，世界是颠倒的模糊的，后知后觉的疲惫涌上来，手都抬不起来了，他觉得就这样死掉也挺好，家里会收到一笔抚恤金，爹娘留给阿妹照顾。想着想着看到了挥舞的军旗，身边的战场渐渐空开，大家都在向侧翼撤退，他知道这是他们要向侧翼进攻的信号。他咬咬牙爬起来，这是他必须遵循的命令，。。。他死了，但战壕守住了，闭眼前他看到战友们疲惫但庆幸的面孔。再睁眼，他成了另一兵种，他们要去攻城，原来他之前做的事情就是为这只攻城的队伍扫清障碍。大概如此吧，你发散吧


这段约 40 分钟的体验，核心是：**玩家起初只知道自己要穿过一条壕沟；换人后，才亲手走过自己打开的那条路。**

两座城之间有一座被敌军占据的小城。玩家所在的军队要攻城，但盾车和云梯被城外的壕沟、木栅挡住。清晨，一队步卒先出城，任务很小：**找到壕沟里能让器械通过的位置，拆开木栅，留下己方能认出的标记。**

玩家扮演十七岁的新征兵阿砚。他不知道攻城队伍何时来，也不知道这个缺口对整场进攻有多重要。眼前只有伍长交给他的一截绳、一把短刀，以及一句“跟住人，别走丢”。

## 1. 前一夜：还没有战争，只有难堪和日常

开场不播放身世独白。玩家在拥挤的营舍醒来，要摸黑找到自己的鞋、给水囊灌水、把湿透的绑腿重新缠紧。有人嫌他动作慢，拿走他的鞋垫垫桌脚；另一个同伍阿六没替他说话，等人散了，才把鞋垫扔回来，说：“脚磨破了，明天我可不背你。”

玩家可以读一封没写完的家书。阿砚前半页问母亲家里的布价，后半页写“这里吃得还行”，桌边却放着半块发硬的饼。他可以继续写，也可以把信折起来。**这不是决定结局的选项**；它让玩家用自己的手碰到这个人的生活。

夜里大家猜明天仍不会打。有人已经猜了十几次。阿六边说边帮他把磨损的水囊绳结重新打好。玩家若参与这段互动，后来在战场上会一眼认出那个结；若没参与，水囊仍是水囊，游戏照常推进。

阿砚此刻最强烈的感受未必是怕死。他更在意自己又做错事、明天会不会拖累一伍的人。他想家，但想的是母亲发现他把新衣穿坏会骂什么，而不是一段悲壮的告别词。

## 2. 清晨出城：害怕暂时没有来

玩家跟着队伍穿过城门。这里可以自由走、回头看、听人说话，但不能离开自己的队伍太远。城内有人挑水、有人清扫昨夜的灰；他们没有停下来送行。阿砚原本以为出城会让自己腿软，实际却只顾着看前面人的鞋跟，怕又跟丢。

直到城门在身后关上，玩家听见门轴拖过石槽的声音。回头仍看得见城墙，但门里的人已经看不见了。

这里的心境变化不是“忽然勇敢”。更像是：**昨夜想象的恐惧没有出现，取而代之的是一种说不清的凄凉。**他第一次觉得，城里的早饭照样会做，而自己正在走向一件并不由自己决定的事。

玩家此时学会本关最重要的操作：停下、抬头辨认本队旗帜；借山坡和烟尘判断位置；在看不清旗的时候听鼓。游戏不在地面画通往目标的光线。伍长会教他认旗，但真正走到岔路口时，仍得由玩家看现场。

## 3. 到达壕边：目标明确，办法没有写好

伍长指给众人看壕沟另一侧的木栅，随后带两个人从正面摸过去。玩家与阿六沿沟寻找能过人的位置。这里开始是真正的冒险关卡：

- 玩家可以爬到坡上看栅后的守兵，但会暴露在视线里。
- 可以顺着沟底走，比较隐蔽，却会遇到积水和塌土。
- 可以询问一名退回来的兵，他知道旧车辙通往哪里，但没看到木栅后面。

玩家要用观察、移动、攀爬、拉拽和使用绳索，给后来的队伍弄出一条路。障碍不会只有一个预设解法：木栅可以从旁边拆，可以借倒下的车越过，也可以先找到沟里较浅的一段。战斗是其中一种危险，**不是这段的主要工作**。

阿砚此时还会等伍长替他判断。伍长一离开他的视线，他才发现自己记住的命令只有半句。第一次主动做决定，可能只是“从哪边下沟”。

## 4. 第一次交手：心里平静，手却不听话

在木栅附近，敌人发现他们。玩家可以躲、退，也可能被迫用短刀和盾应付两三个守兵。操作很简单：看准距离，挡开眼前的一击，推人让出路，再刺或砍。这里没有连招奖励，也不鼓励追着人杀。

阿砚第一次杀人，可以发生得很不体面：他后退时踩空，对方扑过来；玩家按下格挡、再刺出去。等他意识到发生了什么，那人已经滑进沟里。他没有立刻崩溃。他先去捡掉在泥里的绳，甚至觉得自己刚才做得很利落。

**变化在下一件小事上出现。**玩家要把绳穿过木栅，阿砚的手一直在抖，绳头几次对不准孔。镜头没有血红滤镜，也不弹“你第一次杀人了”。阿六过来按住木头，让玩家把绳穿过去，嘴上只说：“快点。”

随后战斗越来越近。玩家也许又伤了人，但已经分不清每一刀的结果。阿砚不再想着“我能不能打”，只在处理一个接一个贴到眼前的问题。

## 5. 受伤与失散：他还在做事，世界却越来越窄

阿砚的侧腹受了伤。起初他只发现衣服湿、握绳时力气不够；疼痛是在他停下来后才追上来的。受伤会改变操作：攀爬要找更低的落脚处，拉重物需要阿六帮忙，跑一段后必须扶住东西喘气。它不会突然夺走玩家控制权。

伍长不见了。阿六刚才还在左边扶栅，下一次玩家回头，那个位置已经是陌生人。游戏不立刻确认他们死了，也不给熟人名单划红线。玩家可以喊，可以短暂地沿沟找，但敌军正在逼近，手里的绳还没固定好。

这一刻最难受的不是一段哭戏，而是**玩家也没有时间弄清发生了什么**。阿砚会先把绳拉紧，再想起自己还没问阿六去了哪里。他的伤、手抖、喘息与寻找熟人的冲动同时存在，没有一个整齐的“悲伤阶段”。

## 6. 倒下：最后的操作仍属于玩家

一股冲击把阿砚掀进壕沟。镜头贴近地面，天与旗帜在视野里颠倒；声音变钝了。玩家仍能转头、抓住沟壁、缓慢爬行，但站起来已经很难。

他看见侧翼的己方旗动了，知道后队开始推进。此时壕边已经有一道缺口，**还差一个能让推车的人从远处认出来的标记**。先前玩家把绳拴在哪里、拆掉了多少木栅，都决定现在还够不够得着。玩家可能用尽力气把一块布系到露出的木桩上；也可能只来得及把木桩扶起一半。

阿砚想起有人说阵亡者家里会领到钱。他不知道这话是真是假，甚至记不清自己有没有把家里的地址写对。疲惫盖过了害怕；他有一瞬间真的不想再动。然后他看见后队正向自己找出的壕口移动，又伸手去够那根绳。

玩家完成的最后一个动作可以很小：**拉住、系紧、松手。**敌人反扑时，阿砚死在沟边。闭眼前他看见几个人从缺口过去，其中没有阿六。他不知道他们有没有看见自己的标记。

## 7. 再睁眼：玩家必须亲手经过那里

没有“任务完成”画面。下一声是木轮碾过石子的声音。玩家睁眼，已经是一名推盾车的攻城兵，双手正抵着车梁。新角色有自己的同伴和任务：把盾车送到城墙下。**他不知道阿砚是谁；记得阿砚经历的是玩家。**

玩家从更高、更远的位置看向刚才那条沟。第一段里，那不过是几个人挤在一起的一小块泥地；现在它是整列器械必须经过的入口。

接下来仍是操作，而不是观看成果：

- 如果阿砚拆开了足够宽的缺口，玩家可以和队友直接把车推下去，但要控制木轮别陷进沟底。
- 如果缺口太窄，玩家得停下车，亲手继续拆栅；箭雨和赶来的队伍会让这件事更难。
- 如果标记没立好，**玩家仍记得浅沟在哪里**，可以离开队伍去确认路线，再回来引车。
- 玩家可能在车轮旁看到阿砚的水囊，认出那根重打过的绳结。新角色不会说“这是我”，队友也只会催他推车。

震撼放在这里：**玩家费尽力气打开的地方，换一个身体看，才知道它究竟有多窄，又有多少人要从这里经过。**攻城能否成功仍由这场战役决定；但这辆车能否到墙下、哪些人能跟上，是玩家两条命接力打出来的。

## 阿砚的心路，不是一条“胆小变勇敢”的直线

| 时刻 | 他心里更可能发生的事 | 游戏怎样让玩家感到 |
|---|---|---|
| 营中受轻视 | 怕丢脸比怕死具体 | 找鞋、系错绑腿，被熟人催促 |
| 与同伍相处 | 讨厌他们，也开始依赖他们 | 阿六嘴上刻薄，手却帮他固定绳结 |
| 战前一夜 | 用“仗打不起来”维持日常 | 大家谈吃食、鞋、家书，没人能确认军令 |
| 出城 | 没有想象中的惊恐，只有退路忽然变远 | 玩家能回头看关闭的城门 |
| 接近战场 | 只看得到眼前几十步，不理解全局 | 靠旗、鼓、烟和他人只言片语找方向 |
| 第一次杀人 | 意识跟不上动作，事后身体先有反应 | 交手时输入清楚，系绳时手抖 |
| 受伤 | 先忙着完成事，停下才感到疼 | 可做的动作改变，仍能寻找办法 |
| 熟人消失 | 悲伤被任务挤到后面 | 可以回头找，却不能让战场停下来 |
| 倒在沟里 | 不再想证明自己，只想休息 | 玩家行动范围缩小，仍握有最后一个动作 |
| 看见旗号 | 命令成了他此刻唯一确定的东西 | 玩家凭先前学会的旗号，自己认出后队将至 |
| 临死 | 他未必觉得自己成了英雄 | 只看见有人从缺口过去，不知道后来怎样 |

这段不能靠旁白告诉玩家“他很悲壮”。前半段要让玩家熟悉一个人怎样穿鞋、吃饭、被取笑、依赖同伴；后半段再让这些熟悉的动作逐个变得困难。死亡后也不替他立刻写结论，而让玩家**继续推车，亲自检验他留下的路**。

最值得先验证的是从“倒在沟里系上标记”到“换人推车经过壕口”这十分钟。它同时检验沉浸感、实际操作，以及魂穿是否真的成为玩法。
