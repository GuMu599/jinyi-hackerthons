### 0.3 一句话说清 C1 为什么必须存在

用户要的是"手笨不该被卡住"。这件事本身是对的。
但"死了重来"和"死了换人"是同一位置的两套规则，**不能共存**。
解法不是二选一，是**承认这世上本来就有两种死**：

> **因为不会而死的，书可以重讲。**
> **因为该他死而死的，书讲完就完了。**

前者是玩家的错，后者是他的命。玩家分得清这两件事，主题就立得住；分不清，这个游戏就只是一个能赢的游戏。

## 1. 核心体验

| 项 | 是什么 |
|---|---|
| **你是谁** | 一个说书人在茶楼里讲的、没有名字的小兵。你会附在书里某个人的身上 |
| **你唯一的能力** | 读得懂战场的信号。而这份能力换不来活命 |
| **你唯一的资产** | **一本册子**。每死一个人，多一行。你会看着它变厚 |
| **你唯一的失败** | 不是死。是**没能把他记住** |
| **你必须做的事** | 在听不清、看不见、不敢问的情况下，做一个动作 |

玩家的位置是三层：**听者 → 兵 → 记账的人。**

一句话：**从"我在听书"，到"我在当兵"，最后到"我在记账"。**

## 2. 地基：两类死亡

### 2.1 「错」——操作死

| 项 | 规则 |
|---|---|
| 怎么触发 | 玩家判令判错、动作变形、阵位失守、体力见底、看错旗 |
| 屏幕上发生什么 | 画面不会停在"失败"。声音先抽掉，然后**说书人的声音回来**，他停在一句话中间 |
| 回到哪里 | 茶楼。说书人放下书，看着你 |
| 他说什么 | 「这一回，我再说一遍。」——然后**只重讲那一条军令**，不重讲整段 |
| 你能不能不听 | 能。不打断他，他继续；打断他（乱点），他停下，直到你停手 |
| 结果 | 同一个人，同一天，从头再来。**不换人** |
| 留痕 | 名册上多一行，**用朱笔划掉**。这一行永远留在册子上 |

**关键设计：重讲不等于复述。** 第二次讲时，说书人的措辞会变——不是记忆完美的人。玩家会注意到"他说的和刚才不太一样"。这不是 bug，是全书的地基（见 3.4）。

### 2.2 「命」——脚本死

| 项 | 规则 |
|---|---|
| 怎么触发 | 流矢、职责（鼓手不停手）、补阵缺、送达之后被杀、先登 |
| 屏幕上发生什么 | 死亡八秒：声音抽空 → 耳鸣心跳 → 远处的鼓 → 一个新的人的呼吸 |
| 回到哪里 | **不回来**。魂穿进下一个人 |
| 能不能重来 | **不能**。这一行永远留着，不可改 |
| 留痕 | 名册上留一行，不划 |

### 2.3 为什么必须分开

| 只用"死了换人" | 只用"死了重来" | 分开 |
|---|---|---|
| 玩家手笨就被卡住，读成"我失败" | 魂穿设定作废，主题滑成"练技术" | 两种都保住 |
| 死亡不能教东西 | 死亡不值钱 | 错可以教，命不能改 |

**这条分开之后，长出来一个原本没有的东西**：

> 你可以重来，但他不能。
> 你每重来一次，册子上就多一道朱笔划痕。
> 最后你会看见：你为了让这个人活下来，把他"死"了十一次。

这是类魂的"死亡记账"在本题材里唯一成立的形态——魂系丢的是卢恩，这里丢的是**他死得干不干净**。

### 2.4 朱笔的规则

| 规则 | 内容 |
|---|---|
| 颜色 | 朱（`#A8322A`），全屏只用三处之一，不许用朱写别的字 |
| 出现时机 | 只在玩家操作死、且说书人重讲之后 |
| 划法 | 一道横线，从右往左（明人改字是从右往左划的书写习惯，本书统一从右往左） |
| 上限 | 一个人最多十一道。第十一道时，说书人会停一下，说：「这一回，我不讲了。你听着。」 |
| 不可撤销 | 不能洗、不能隐藏、不能导出时抹掉 |
| 会说话 | 结算时，册子上划得最乱的那个人，名字反而最清楚——因为写得最多 |

**朱笔不惩罚。** 它只记录。玩家自己会算出代价。

## 3. 元循环：书场 ↔ 沙场

### 3.1 茶楼四拍 = 四个系统动作

开场四拍全部有原文（张岱《陶庵梦忆》卷五：「每至丙夜，拭桌剪灯，素瓷静递，款款言之」）。完全体把这四拍直接做成系统动作——**叙事即 UI，不另造菜单**：

| 四拍 | 原文依据 | 系统功能 |
|---|---|---|
| **静场** | 张岱：「主人必屏息静坐，倾耳听之，彼方掉舌」 | **开始**。玩家不动，书开始；玩家乱点，书停 |
| **拭桌** | 「拭桌」 | **开新的一回**。抹布过桌，桌上摊开一页新纸 |
| **剪灯** | 「剪灯」 | **存档点**。灯芯一剪，这一回记下了 |
| **递茶** | 「素瓷静递」 | **重来**（对应 2.1 的「错」）。茶递到你手里，就是允许你重听一次 |

这四件事本来是他开场的仪式，现在每一件都对应玩家能做的一件事。**玩家不需要理解这四个动作，只需要发现它们有用。**

### 3.2 一轮完整会话

```
茶楼：静场（开始）
      ↓
    拭桌（新回）→ 说书人讲三条军令（逐条，允许打断）
      ↓
    入梦（身份卡：名、齿、由、一件东西）
      ↓
沙场：一日（行军 → 号令 → 接阵 → 某一刻他死）
      ↓
    ┌─「错」→ 回茶楼 → 递茶 → 重讲那一条 → 再入梦（同日）
    └─「命」→ 死亡八秒 → 魂穿（下一个兵，同日继续）
      ↓
    剪灯（存档）→ 合书 → 册子展开
```

### 3.3 时间尺度：茶楼是"现在"，战场是"过去"

| 尺度 | 茶楼 | 沙场 |
|---|---|---|
| 玩家真实时间 | 一段话几分钟 | 一日几十分钟 |
| 剧中时间 | 一个晚上 | 一天 |
| 说话人 | 说书人（现在） | 老兵、同伍、原主记忆（过去） |

**这一层不能让玩家觉得是"读档界面"。** 茶楼永远是那个茶楼，茶永远是新倒的，说书人的嗓子永远是坏的。玩家每次回来，会越来越熟悉这张桌子——**而他讲的那些人已经死完了。**

### 3.4 说书人会讲错（全书的地基）

D12 待定项③，本篇的建议定案：

| 项 | 规则 |
|---|---|
| 错什么 | **只错细节，不错大事**。他会把"金二声"和"金连二声"说反，会把某个兵说成"第三排"而其实在第一排，会记错一个人的籍贯 |
| 错多少 | 每一回**一处**。全书五回，共五处 |
| 错的方向 | 永远是"让故事更好听"的方向。他把一个小兵讲成了有点像英雄 |
| 谁来纠正 | **没有人当面纠正他。** 只有老兵的耳语、物件、册子上的事实，反过来打他的话 |
| 后果 | 玩家照错的做，会死人。但**死的是"命"，不是"错"**——因为玩家信错了人，不是手笨 |
| 最后一处 | 第五回，他讲错了自己的事 |

**为什么必须有这一条**：如果他说什么对什么，玩家就只是在学知识；如果他会错，玩家就必须**判断说话的人**——这是"文脉"这个主题唯一的玩法形态。

## 4. 局内循环

### 4.1 三层

```
【解读层】只给原始情报，不给结论
    鼓点节奏 / 旗色旗位 / 金声数 / 角声数 / 烟尘 / 阵形缺口
        ↓
【决断层】时间窗口内做一个动作，选了不能退
    进 / 止 / 退 / 顶住 / 低头 / 抬头 / 挪一格 / 举旗 / 传令
        ↓
【执行层】小游戏承担"我做到了 / 我搞砸了"的身体感
    辨令 / 跑位 / 承重 / 拉弓 / 击鼓
```

三层缺一不可：只有解读＝电子书；只有决断＝选择题；只有执行＝音游。

### 4.2 一轮 5–20 秒

| 拍 | 发生什么 |
|---|---|
| 0 s | 信号出现（听或看，按你的兵种，你可能**只有一个通道**） |
| 0–1 s | 你落后半拍才意识到它什么意思 |
| 1–3 s | 时间只够做一个动作，而你的身体不一定听你的 |
| 3 s | 你做了，或没做 |
| 3–4 s | 屏幕**不告诉你对不对**（见 4.3） |
| 5–20 s | 你从别人身上看出后果：有人没跟上来、有人被挤出去了、前面塌了一块 |

### 4.3 判定：判"判断对不对"，不判"拍子准不准"

这是全书最重要的一条判定规则。

| 判什么 | 为什么 |
|---|---|
| **命令的语义你读对了吗**（进／止／退／接敌／坐） | 读错＝死的是别人，主题成立 |
| **不判**你的手指落在节拍线上的毫秒数 | 音游式判定会让玩家把死归因为手笨，主题当场崩塌 |

工程上：判定单位是**整句**（4 拍构成一个命令），不是单拍。4/4 完美、3/4 命令生效但队形降级、≤2/4 阵缺。

## 5. 按键表

> 这一节是"玩家到底能掌控什么"的唯一答案。**任何一个新功能，如果在这里找不到位置，就不做。**

### 5.1 三条设计原则

1. **核心键不超过六个。** 玩家在战场上手忙脚乱是设计，但不是因为记不住键位。
2. **军令不新增按键。** 听懂命令和身体执行必须是同一套动作——军令用 `1/2/3` 回答，这个游戏就变成答题了。
3. **换兵种 = 换键盘。** 魂穿换的是"一副耳目和一双的手"，键位跟着变。

### 5.2 第一层：身体（人人都有，六个键）

| 键 | 动作 | 世界怎么回应 | 代价 |
|---|---|---|---|
| **W**（按住） | 前挤 | **挤不动前面的人**，只挤出半个身位；挤到第三个身位，队形破口 | 后面的人被你拉开 |
| **S**（短按） | 立止 | 站定，绷紧；阵位不动 | 别人在动你不动，位就空出来 |
| **S**（按住 ≥0.6 s） | 后退 | **只有"金二声"之后有效**；否则后面的人顶住你，退不动 | 退错＝阵缺 |
| **A / D** | 侧挪一格 | 只挪**一格**；同伍不跟，你就空了半位 | 空位要有人补，慢一拍就是缺口 |
| **空格**（按住） | 顶住 | 阵位在涨，体力在掉；松手，位置后移一格 | 体力见底＝动作变形 |
| **Shift**（按住） | 低头 | 受击面缩小，**视野进一步变窄** | 看不见旗，也看不见前面 |
| **鼠标右键**（按住） | 抬头看 | 最多 **2 秒**；期间不能防 | 部分兵种没有这个键 |

**这张表的核心不是"六个键"，是"方向键被队形拒绝"。** 玩家有意图、有输入，世界不让他动。这比"没有移动"重得多，而且不需要 3D 与寻路——要的是位置力学（谁顶着谁、缺口在哪），可以算，不需要做动画。

**"止"为什么是 S 短按、不是"松开所有键"**：松开是一个"不作为"，玩家很难意识到自己做了什么。必须有一个明确的、可被教会的动作。老兵第一课就是教这个（见 8.1）。

### 5.3 第二层：军令应答（复用上面六个键，零新增）

| 军令（真实语义） | 应答动作 | 判错会怎样 |
|---|---|---|
| **鼓之**（进） | W | 没进＝队形断裂，后面的人撞上来 |
| **重鼓**（接敌，敲第二遍） | W + 空格 | 没顶住＝你这一列被冲开 |
| **金之**（止） | S 短按 | 还往前＝你一个人突出阵外 |
| **重金**（退） | S 按住 | 没退＝你站在原地，队退了 |
| **金连二声**（转身向前立定） | S 按住 → 快速松开 → W | 最难的一个动作。做反＝全队跟着你做反 |
| **金鼓俱击**（全体坐下） | Shift + 空格 | 没坐＝你是整排里唯一站着的人 |
| **低旗**（加速） | 连按 W | 慢＝拖全队后腿 |
| **放铳一声**（变更号令，立定看新旗） | 松开一切，**站着不动** | 动＝军令未定你就动了 |

**注意最后一行**：全书唯一"正确动作是不作为"的一条。它会成为玩家最难学会的一课。

### 5.4 第三层：兵种专属（换兵种 = 换键盘）

| 兵种 | 专属键 | 功能 | 拿走后他剩什么 |
|---|---|---|---|
| **长枪手（兼弓箭）** | 鼠标左键 | 放箭。箭**三十支**（唐制与明制一致） | 只剩枪与顶住 |
| **鼓手** | 空格 | 击鼓。**空格在这里不是"顶住"，是"敲"** | 只剩耳朵 |
| **牌手（盾）** | —（无专属键） | **他没有任何额外键。** 这是设计，不是遗漏 | 只有身体 |
| **传令兵** | E | 递令／答话／验符节 | 剩路线与腿 |
| **火兵** | E | 分饭／看火／递水 | 剩锅与火 |
| **文书** | E | 写／改／念 | 剩笔 |

**牌手没有专属键，是全书最重要的一个"没有"。** 他的全部玩法就是那六个身体键，而且他的视野被军规剥夺（「执牌者专以前进为务，不许出头看贼」）。玩家演他时会觉得"我什么都做不了"——这就是对的。

### 5.5 第四层：元层（茶楼与册子）

| 键 | 功能 | 在哪用 | 备注 |
|---|---|---|---|
| **Tab** | 军令图 | 战场 | **写的是说书人那一版**（可能错）。不许在此处更正 |
| **I** | 随身物 | 任何地方 | 那**一件**东西。全书不换、不传、不落到别人手里 |
| **M** | 名册 | 任何地方 | 只读；每回结束可填死因（见 10.3） |
| **Esc** | 离席 | 任何地方 | 暂停即"合书"。回来时，茶是新的 |
| **滚轮／点击** | 翻页 | 茶楼与册子 | 唯一的"读"动作 |

### 5.6 茶楼：零按键

**茶楼不提供任何控件。** 没有"继续"按钮、没有跳过、没有 Auto。

- 玩家不动，他说下去。
- 玩家乱点，他**停下、看着你、不说话**，直到你停手。

成本近乎零，但它一句话就说清了全篇的规则：**你在这里的身份是听者。**

### 5.7 明确不加的键（和理由）

| 不加 | 为什么 |
|---|---|
| 跳跃 | 穿甲的人不跳。要翻越，用"顶住—撑起—过去"三拍 |
| 攻击键（除长枪手外） | 小兵的动作是"顶"，不是"砍"。砍是长兵的事，且长兵不许带解首刀 |
| 技能／必杀 | 没有。这个游戏里唯一能"变强"的是你的判断 |
| 冲刺 | 行军有步鼓／趋鼓／鹜鼓三档，靠鼓点给，不靠按键 |
| 地图／小地图 | 全书不提供。方向由身体与旗给（五方旗按前后左右） |
| 对话选项 | 战场没有对话。你开口就违纪（「若无令许说话，但开口者着实重处」） |
| 快速存档／读取 | 不提供手动档。存档只在"剪灯"（一回结束），读档只在"递茶"（一次重来） |
| 难度选择 | 用三个旋钮＋一个校准调节（见 11.3），不给"简单/困难"标签 |

## 6. 身体系统：位置力学

### 6.1 六件事

一本书里，玩家对"位置"能做的事只有六件，全部在 5.2 的按键表里：

| 事 | 机制 |
|---|---|
| **挤** | 前面有人，你只能挤出半个身位 |
| **让** | 侧挪一格，后面要跟；他不跟，你空一位 |
| **顶** | 承重：位置在涨，体力在掉 |
| **缩** | 低头，缩小受击面，同时缩小视野 |
| **看** | 抬头两秒，失去防护 |
| **补** | 补上阵缺，代价是自己站到最容易死的位置 |

### 6.2 体力：不给数字，给呼吸

| 项 | 规则 |
|---|---|
| 表现 | 屏幕没有体力条。你听到自己的呼吸 |
| 消耗 | 顶住、抬头看、连续前挤 |
| 见底时 | **动作变形**：W 变成原地踉跄；空格按不住；S 退得比想的远 |
| 恢复 | 只有"止"能恢复，而且很慢 |

**为什么不做体力条**：条是"资源"，会让你算；呼吸是"身体"，只会让你怕。这个游戏的每一处 UI 都应该往"身体"那边靠。

### 6.3 阵缺

| 项 | 规则 |
|---|---|
| 什么算阵缺 | 任何一个该有人的格子空超过一拍 |
| 后果 | 相邻的点被冲散；那一侧的人开始死 |
| 归属 | **阵缺永远算在你头上，不算在系统头上。** 没人会告诉你"你造成了阵缺" |
| 怎么补 | 只有"补"（第 6 件事）。补的人往往死 |

**建议贯彻全书的一条**：玩家的错不让他自己死，让别人死。这条比任何难度曲线都重要。

### 6.4 伤口分级：状态不是血条

史实直接可用（《汉书·李陵传》）：「三创者载辇，两创者将车，一创者持兵战」。

| 你受的伤 | 你还被允许做什么 |
|---|---|
| 一创 | 还能打。但每动一下都有声音 |
| 两创 | 不能打，只能"将车"（搬、推、拉） |
| 三创 | 不能动。载辇，被人抬走——**抬走的人未必回来** |

**这不是血量递减，是"权限递减"。** 你不会"死"，你会"被移出战场"。而离开战场的方式，决定了册子上那一行怎么写。

## 7. 感知系统：五副耳目

### 7.1 表

| 兵种 | 能看 | 能听 | 看不见什么 | 他的关卡 |
|---|---|---|---|---|
| 长枪手（兼弓箭） | 旗号、阵形、敌人远近 | 鼓声（远、混响） | 前排究竟发生了什么 | 看旗 |
| 牌手（前排） | **不许抬头看** | 鼓声（近、震得胸口发麻） | 几乎一切 | 在黑暗里押鼓点 |
| 鼓手 | 只看得见自己的鼓 | **听得最清** | 整条战线 | 敲错一拍就死人 |
| 传令兵 | 跑动中看见全局 | 各处鼓都能听见 | 没有掩护 | 路线与抉择 |
| 火兵 | 看得见锅、火、人 | 听得见近处的骂 | 战斗本身 | 在什么时刻递水 |
| 文书 | 看不见战场 | 听不见 | 一切 | 只能看册子 |

**"魂穿"不只是换故事，是换一副耳目。** 玩家每换一个兵，得到一种感知、失去另一种感知。五个关卡的操作体验天然不同，不需要硬造差异。

### 7.2 核心博弈：信息换安全

> **本书的核心资源不是时间，是注意力。**
> 你不可能同时"知道"和"活着"。

| 你想 | 你要付 |
|---|---|
| 知道前面怎么了 | 抬头两秒，失去防护 |
| 知道我该往哪 | 看旗，低头就看不见 |
| 知道别人在干什么 | 挪一格，破自己的阵 |
| 活着 | 低头，什么都不知道 |

这个交换必须让玩家自己发现，**不教**。

### 7.3 视觉提示模式（硬要求）

不是无障碍的可选项，是必做项。规则：**全程静音能通关。**

理由有三条，前两条是设计与合规，第三条是现实：

1. 当声音是情报时，视觉必须是它的备份；当视觉是情报时，声音必须是它的备份
2. 「不能有纯靠声音的关键信息」是无障碍指南的硬条款
3. **答辩现场评委大概率没戴耳机**

## 8. 军令系统

### 8.1 三层教学（全部有史料，不用编）

《尉缭子·兵教上》：「伍长教其四人，**以板为鼓，以瓦为金，以竿为旂**」。

| 层 | 你听到/看到 | 你以为 | 其实 |
|---|---|---|---|
| **第一层** | 木板、瓦片、竹竿 | 这就是军令 | 这是假的。新兵的第一课从来都是假的 |
| **第二层** | 真鼓、真金、真旗 | 原来刚才那是假的 | 真的鼓声大得让胸口发麻，你会听错 |
| **第三层** | 说书人讲的军令 | 这是标准答案 | **他有一处讲反了** |

三层教学对应三种"我以为我知道"，而每一次都是被打脸。**这是全书的教学设计，不需要一个教程弹窗。**

### 8.2 进游戏的语义表（全部按 `02-考据底本.md` A1，不许添改）

| 信号 | 含义 | 用在哪 |
|---|---|---|
| 鼓之 | 进 | 常规 |
| 重鼓（第二遍） | 接敌 | **杀手机关**：只记"鼓＝冲"的人会在这里送命 |
| 金之 | 止 | 常规 |
| 重金 | 退 | 常规 |
| 金连二声 | 转身向前立定（诈退） | **最难的一课** |
| 金鼓俱击 | 全体坐下 | 最容易读错的（不是"又进又退"） |
| 低旗 | 加速 | 旗也带速度 |
| 一步一鼓 / 十步一鼓 / 音不绝 | 步鼓 / 趋鼓 / 鹜鼓 | 行军三档 |
| 角一通 / 二通 / 三通 | 收拢 / 偃旗 / 举旗（之后才击鼓） | 角是准备，鼓是交战 |
| 放铳一声 | 变更号令：立定看新旗令 | 唯一的"不动才对" |
| 摔钹响 / 打铜锣 / 吹哱啰 | 收队 / 坐地休息 / 起身执械 | 生活段 |
| 塘报摇小黄旗 / 摩旗 | 有贼至 / 贼多 | 警报 |
| 磨旗：上磨 / 平低磨 / 低垂磨 / 绕竿转 | 贼远 / 贼近 / 近百步 / 四面来 | **看的是那只手怎么动，不是颜色** |

**明确不许写进游戏的**：三通鼓＝冲锋（小说语汇）、鸣金＝逃跑（流行误解）、号角＝冲锋号、八卦阵当实战阵法、先登封侯、督战队射杀逃兵。全部见 `02` 号 A8。

### 8.3 双通道校验：鼓数 + 旗色

《武经总要》引裴子法：一鼓黑旗曲阵、二鼓朱旗锐阵、三鼓青旗直阵、四鼓白旗方阵、五鼓黄旗圆阵。

**玩家必须同时看鼓数和旗色，任一错都会变错阵。** 只听会错，只看也会错。这是"观察"与"辨听"拧在一起的唯一一处，也是完全体里最适合做"变阵"考题的地方。

且——**变阵在兵书里是危险动作，不是炫技**（《孙膑兵法·将失》「令数变，众偷，可败也」）。所以变阵关的张力是**"该不该变"**，不是"变得快"。

## 9. 六个人

| 兵种 | 制度身份 | 连坐关系 | 他死了会怎样 | 他的死法（「命」） |
|---|---|---|---|---|
| 长枪手（兼弓箭） | 队里在编 | 同伍相保 | 同伍夺功 | 流矢 |
| 牌手 | 队里在编 | **牌手阵亡，伍下通斩** | 全伍皆斩 | 补阵缺 |
| 鼓手 | **编在中军纛下，不属任何一队** | **无人连坐** | 没人被连坐，但全军听不见鼓 | 中箭不停手 |
| 传令兵 | 队里在编 | 同伍相保 | 同伍夺功 | 送达之后被杀 |
| 火兵 | 队里在编 | 同伍相保 | 同伍夺功 | 送水途中 |
| 文书 | **这队里"认字的那一个"**（不是编制内的"队文书"） | — | 制度上没有痕迹 | **不死。他是记账的人** |

> ⚠️ 考据硬约束：识字兵按**把总**（约 192 人）配一员（茅元仪《武备志》「每一把总下，识字一名」）。**一队十二人未必有识字者**。台词只能说"这队里认字的那一个"，不能说"队文书"。

**鼓手是六个人里唯一的孤独者**：他死了没有人要抵命，所以他也没有人保护。而他一停手，整支部队就散了。这与《汉书》「击鼓起士，**鼓不鸣**」是同一件事。

## 10. 名册：类魂的"魂"

### 10.1 五栏

| 栏 | 内容 | 什么时候写 |
|---|---|---|
| **名** | 姓名 | 入梦时 |
| **齿** | 籍贯、年龄 | 入梦时 |
| **由** | 他怎么当的兵（征兵前那一幕） | 入梦时 |
| **终** | 死因 | 死时（「命」由系统写；「错」由玩家重来，终栏留空） |
| **朱** | 重来的划痕 | 每次「错」 |

**名、齿、由三栏由说书人给，终栏由战场给，朱栏由玩家给。** 三个人各写一部分，这本册子才完整。

### 10.2 朱笔（C2 的全部内容）

| 规则 | 内容 |
|---|---|
| 一道划痕＝一次重来 | 不是"失败次数"，是"你又让他死了一回" |
| 不显示总数 | 没有"已重来 7 次"的计数器。你要自己数那些横线 |
| 名字反而更清楚 | 划得越乱的格子，因为写过太多次，那个名字反而最清楚 |
| 结算时说话 | 册子展开时，划得最多的那一格会被**停留最久**，不配字 |

### 10.3 从"只读"到"可填写"

完全体的册子是可以填的（Obra Dinn 结构，但更窄）：

| 阶段 | 玩家能做什么 |
|---|---|
| 前两回 | **只读**。你只能看着他被写进去 |
| 第三回起 | 死因那一栏是空的，你可以填。填错不惩罚，只是名字不变黑 |
| 第五回 | 你手里有笔。你可以**改一个名字** |

**第五回的那支笔，是全书唯一一次"能改变结果"的操作。** 而它改的不是命，是记录。这一点必须守住：玩家永远不能救人，只能记人。

### 10.4 三个结局（不是分支，是同一条路的不同完成度）

| 结局 | 条件 | 玩家会说什么 |
|---|---|---|
| **记住** | 册子填对、名字变黑 | 「我记得他」 |
| **记错** | 有格子填错、名字仍是灰的 | 「我以为我记得」 |
| **没记** | 有格子空着 | 「我不知道他叫什么」 |

三个结局里，**只有第一个是"赢"**，而它不给任何奖励画面。

## 11. 难度与教学

### 11.1 四个维度，各自有教学曲线

| 维度 | 在学什么 | 失误后果 | 怎么教 |
|---|---|---|---|
| **知识** | 旗、鼓、阵的语义 | 走错位（可挽回） | 老兵带教，不弹教程窗 |
| **感知** | 从噪声里抓信号 | 慢半拍 | 同一信号反复出现 |
| **时间** | 窗口内决断 | 任务失败 | 窗口从宽松收到 2 秒 |
| **道德** | 不可能两全 | 失去战友，不可撤销 | **不教，让玩家自己撞** |

### 11.2 曲线：每一场的死法象征一种战争真相

| 回 | 兵种 | 学什么 | 时间压力 | 他的死（「命」） | 象征 |
|---|---|---|---|---|---|
| 1 | 长枪手（兼弓箭） | 看旗 | 无 | 流矢 | 战场上的运气 |
| 2 | 鼓手 | 听鼓／敲鼓 | 轻 | 中箭不停手 | 职责 |
| 3 | 牌手 | 阵位 | 中 | 补阵缺 | 集体 |
| 4 | 传令兵 | 路线＋夜号＋抉择 | 重 | 送达后被杀 | 牺牲 |
| 5 | 文书 | 综合＋反转 | 极重 | **不死。他是记名的人** | 荣耀的虚妄 |

**第 5 回不让玩家死**：让玩家活下来，成为那个记账的人。这比"也死了"更有余味。

### 11.3 三个旋钮 + 一个校准

| 旋钮 | 调什么 |
|---|---|
| 接令窗 | 信号到必须响应的时长 |
| 噪声量 | 从噪声里抓信号的难度 |
| 阵缺容忍度 | 空位多久算缺口 |

**校准**：开场一次八拍点击，测设备延迟，存下来（照 Patapon 重制版的 Input Timing Adjustment）。现场演示时三个旋钮调到比正式版更宽松——让评委 3 分钟内"读懂"，而不是看你反复死。

## 12. 情绪曲线

| 幕 | 玩家状态 | 手段 |
|---|---|---|
| **失序** | 混乱、看不懂、怕死 | 信息轰炸，强制出错，但**不出人命** |
| **习得** | 能读旗、能听鼓、知道位置。「我懂了。」 | 反复给同一信号，让玩家自己发现规律 |
| **承重** | 开始替别人做决定，开始死人 | 第一次道德抉择，两个选项都疼 |
| **留名** | 反转、册子、沉默 | 关掉一切 HUD，只剩名字和一支笔 |

一句话：**从"我在听书"到"我在当兵"，最后到"我在记账"。**

### 12.1 六种爽感（都是低音量的）

| # | 爽感 | 在哪一刻 |
|---|---|---|
| 1 | **认知爽** | 嘈杂里突然听懂鼓点。你解开的是一套**真实存在过的密码** |
| 2 | **共谋爽** | 你知道得比角色多。你知道他下一秒会死 |
| 3 | **代偿爽** | 我替他活了一次，我替他答了名字 |
| 4 | **审美爽** | 一排人整齐地转身；一页纸上多了一行字 |
| 5 | **道德爽（反向）** | 我选了难的那条 |
| 6 | **存在爽** | 名字落下的那一下 |

**1、2、4、5 别的游戏也能给。3 和 6 只有本书能给**——因为它们需要"魂穿 + 名册"同时在场。

### 12.2 情绪依存的三个锚点

| 锚点 | 是什么 | 什么时候给 |
|---|---|---|
| **名字** | 他叫什么、哪里人、多大 | 入梦一次、结算一次 |
| **一件东西** | 半块干粮、没寄出的家书、磨亮的铜钱 | 入梦时给，死时不解释 |
| **一个承诺** | 你要记住他 | **只在结尾出现一次** |

**不奖励玩家，给玩家欠条。** 奖励是"你赚到了"，欠条是"你还欠着"。
