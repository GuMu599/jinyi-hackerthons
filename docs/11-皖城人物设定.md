| 人物 | 出现在 | 做法 | 预算 |

| 守军 ×54 | 南墙、门楼、狭口 | 通用守军 #2（深色甲、城头伪装色） | 共用 |

| 甘宁 | 远处/史料卡 | **只做剪影级**，不进近景 | 3k 面 |
| 吕蒙 | 只出声 | **不做模型**，只做鼓声 | — |

**为什么甘宁不做近景模型：** 史载他"手持练，身缘城，为吏士先"，是明确的历史锚点。给他做可交互近景会诱导玩家去"救甘宁/跟甘宁"，而我们没有史料支持任何具体互动。远景剪影 + 旗号 + 传令声就够完成"历史在此处"的暗示，也避免把虚构互动伪装成史实。

## 二、逐人设定

> 每人四块：**性格、外观、模型规格、声音**。外观描述可直接交给建模同学。

### 2.1 陈安 —— 一级模型

**身份：** 吴郡吴县治所（今苏州古城一带）附近人。家中长子，父亲是工匠，母亲持家，有一个妹妹。入伍约三个月，训练有限，**第一次上战场**，开场即已在攻城战中负伤倒地。

**性格（四个词 + 一条禁忌）：**
- **问得多、答得短**：不清楚就问"哪儿卡住了"，被问就答"我托后头"。
- **手稳、眼细**：能注意到绳压在哪里、轮子转没转；敌人倒下时他先看车轮。
- **怕给人添麻烦，甚于怕死**：他不敢喊疼，会自己系绑腿。
- **越到后面越主动**：第三章第一次给出能执行的短令（"后头扶住车尾！"）。
- **禁忌：不许让他发表任何战略见解或慷慨陈词。** 他不是"少年英雄"，是一个刚学会干活的年轻人。

**外观描述（给建模）：**
| 项 | 描述 |
|---|---|
| 体型 | 瘦，肩窄，还没长开；肋骨可辨但不脱相 |
| 面部 | 圆脸、颧骨未开、鼻梁低；眼神飘忽（紧张时看别处） |
| 发式 | 草草绾髻，用一根木簪；布帻（软巾）歪了一点 |
| 服装 | 短襦（麻褐，本色偏黄）、行縢（宽幅布帛，缠至膝下，35–45 cm）、草履 |
| 甲 | **无甲**。只有皮护臂（左小臂）与一条皮腰带 |
| 兵器 | 环首直刀（通长约为 1.0 m），插在腰间；不是长兵 |
| 损伤 | 开场左肋/腰部有伤（不露内脏、不血腥）；衣上有土，无大片血 |
| 新衣痕迹 | **衣服折痕还在**——这是他刚发下来的军装 |

**模型规格：** 8,000 三角面（一级），**2048² 贴图（Albedo + Normal + Mask 共 3 张）**，面部骨骼 **12 根**（眉×2、眼×2、颊×2、下颌×1、嘴×2、鼻×1、额×1、舌×1），复用 UAL1 的 65 根身体骨骼以便共用动画。LOD1 3k、LOD2 1.2k。

**声音：** 少年音，音高偏高，气息不稳；战场上说短句时会**吸气**（"……手有点抖"）。家中段落是吴县乡音（苏州话参考），战场保留轻口音。**必须请苏州话母语者核音。**

### 2.2 丁进 —— 一级模型

**身份：** **籍贯属本作设定 `[F]`**——上游六份没有给丁进定籍贯，本作取丹阳。汉代丹阳郡以精兵闻名，这一联想标 `[C]` 时代背景，**不是本役记载**；两者都不能当史实。入伍两年，打过几场小仗，没登过城。第四章起为玩家角色。

**性格：**
- **务实、话少**：只关心自己队列的事（"来了。你抬前头，我托后头"）。
- **不英雄，但可靠**：不会主动冒险，交代的事能办到。
- **对伤者会犹豫**：听到"他还活着"会停下来——这是他唯一一次"不专业"。
- **学习快**：墙上一站稳就开始指挥后继（"这边能站了。叫他们上来"）。

**外观描述：**
| 项 | 描述 |
|---|---|
| 体型 | 结实，肩宽，比陈安壮一圈；腰背有长期负重形成的微弓 |
| 面部 | 方脸、下颌方、短须（三四天没刮）；眉骨突出 |
| 发式 | 髻扎得紧，武弁（皮弁）＋**绛帻**（汉代常见首服；"红抹额"多见于唐以后，不用） |
| 服装 | 短襦＋长裤、行縢、皮靴（比陈安的草履好一档） |
| 甲 | 小片札甲（胸背 + 披膊）；甲片按 12 号 §6「汉末形制核对」的考据区间（5–10 × 2–4 cm、厚 1–2 mm），本作建模取 **5–6 × 2–3 cm**（`[F]` 具体取值），铁色偏暗；**甲上有旧补丁** |
| 兵器 | 环首刀（鞘插腰后）；抬梯时收在背后——**丁进有刀，别和推车兵搞混** |
| 手 | 手掌厚、虎口有裂口（常年握绳） |

**模型规格：** 8,000 面，**2048² 贴图**，同骨架复用。**与陈安的差别必须一眼可辨**：肩宽 + 甲型 + 靴 vs 草履。

**声音：** 成年男中音，语速慢、句子短、尾音下沉。**低音区男声，与陈安段明显区分**——不指认任何具体方言语系（214 年的口音无法由现代方言复原，见 §5.1 口音纪律）。

### 2.3 吴成 —— 一级模型（第三章战死）

**身份：** 陈安同伍的老兵，**吴县人 `[F]`**（与陈安同乡是为共享乡音，上游未定籍贯）。打了六七年仗。**嘴硬心软**是本作"同袍"主题的主要承担者。

**性格：**
- **说狠话、做软事**：嘴上嫌陈安磨蹭（"拖着要绊的"），手上已经蹲下来替他系行縢。
- **不信新兵，但会护着**：他把盾移到陈安身旁，不是因为他相信陈安，是因为"贴这边"能活。
- **只用动作表达关心**：全篇没有一句"你小心"。

**外观描述：**
| 项 | 描述 |
|---|---|
| 体型 | 粗壮、略驼背；脖子短粗 |
| 面部 | **右颊一道旧疤**（愈合、不新鲜）；络腮短须花白 |
| 发式 | 髻被汗打散，用布条随便绑 |
| 服装 | 短襦下摆磨损；行縢缠得极紧极整（与陈安的松垮形成对照） |
| 甲 | **混合甲**：胸前皮甲 + 肩部铁札甲片。这是"打了多年、东拼西凑"的视觉交代 |
| 兵器 | **双弧盾（楯）+ 环首刀**——他的功能和视觉重心都在盾上。汉盾尺寸无载，此处 0.9 × 0.6 m 是推值 `[F]`；**不称"橹"**（橹为大盾，传统训诂，本库未直读原典、置信度低） |
| 盾 | 木胎髹漆，盾面有 3–4 处修过的裂纹（用铁片钉住） |

**模型规格：** 8,000 面；**盾单独一个资产**（3k 面，双面材质），因为他要反复举起/移动，独立骨骼便于动画。

**声音：** 沙哑低音，说话像在赶人。**台词里没有一句抒情。**

### 2.4 赵平 —— 一级模型（第三章战死）

**身份：** 陈安同伍，**吴县人 `[F]`**（同乡设定同吴成），年纪相近。前夜把外衣分给陈安盖的人。

**性格：**
- **有一点轻松气**：会开小玩笑（"挨着睡，冻不着"），是五人伍里唯一的"活气"。
- **遇险后不再开玩笑**：第三章他死前只说了"吴成？"和一声没说完的话。
- **他的死是"绳从手里滑落"**——不是壮烈，是脱手。这是本作对普通兵死亡的处理方式。

**外观描述：**
| 项 | 描述 |
|---|---|
| 体型 | 中等、精瘦，四肢长 |
| 面部 | 长脸、嘴角天生微翘（看起来像在笑）；笑起来有虎牙 |
| 发式 | 髻歪向一侧，常用手拨 |
| 服装 | 外衣**明显偏大**（他后来把这件给了陈安盖）；短襦内衬露出 |
| 甲 | 只有护胸皮甲片，无披膊 |
| 兵器 | 环首刀；主要道具是**牵绳**（一段粗麻绳，1.8 m，末端有结） |

**模型规格：** 8,000 面。**面部表情骨骼要比别人多一组"笑肌"（左右各 1 根，即面部共 14 根）**，因为全篇只有他需要笑；**这 2 根计入骨骼预算，不另加面数**。

**声音：** 年轻男声，音色偏亮，尾音上扬。**同一套吴县乡音**。

---

### 2.5 伍长 —— 二级模型（不具名）

**身份：** 五人伍带队者。全篇只以职务称呼，**不给名字**——这是刻意的：他是"军令"这个功能的化身。

**性格：**
- **军令短**：每句话都是一个动作（"我顶这边。你拉。"）。
- **眼里只有本队当前的事**：他不评价战局，不解释为什么。
- **不抒情**：结尾喊"陈安！陈安！"，喊的是确认，不是哭丧。

**外观描述：**
| 项 | 描述 |
|---|---|
| 体型 | 精干，腰背笔直（与吴成的驼背对照） |
| 面部 | 棱角深、颧骨高；鬓角几根白 |
| 发式 | 髻整齐，武弁戴正 |
| 甲 | **全伍最完整**：鱼鳞甲（小片密编）+ 盆领护颈 + 披膊 |
| 兵器 | 步矛（约 2.6 m，木柲 + 铁矛头） |
| 标志物 | 腰间一条**深色绦带**（队职标识，非史载建制） |

**模型规格：** 6,000 面（二级），2K 贴图。

**声音：** 中年男声，音量不大但咬字极清（在嘈杂里能被听见）。**标准普通话底子，不带明显乡音**——这也是他与四名伍员的口音区分。

### 2.6 推车兵 —— 二级模型（不具名）

**身份：** 同伍第五人，扶车尾。车到位后**留在车边，存活到最后**——他是五人伍唯一"什么都没失去"的人。

**性格：**
- **只报自己能做的事**："车尾我扶住。""扶着。你把绳拿住。"
- **沉默可靠**：全篇没抱怨、没玩笑、没抒情。
- **他的存在感来自"一直在那里"**：玩家回头，他总在车尾。

**外观描述：**
| 项 | 描述 |
|---|---|
| 体型 | 壮，肩膀厚，个子不高 |
| 面部 | 圆脸、厚唇、眉毛淡 |
| 服装 | 短襦+围腰（有车油污） |
| 甲 | 无甲，只有厚布护肩 |
| 手 | 手掌极大（专门给特写：扶车尾的手） |
| 兵器 | **无兵器**——全程扶车尾、不参战；这也是刀 41 把里没有他的原因 |

**模型规格：** 6,000 面。

**声音：** 低沉、含混，像嘴里含着东西说话。**全程不超过四句。**

---

### 2.7 徐直 —— 二级模型

**身份：** 丁进同伴，**籍贯同属本作设定 `[F]`**（与丁进同乡的安排是为让两人有共同的说话方式，不是史实）。**抬梯的梯脚一头**（靠墙、落在 (36,−158) 的就是这一端；梯顶那头由玩家/丁进托——对应台词「你抬前头，我托后头」）。箭雨中说出"收拾调理"的人。

**性格：**
- **嘴快、直接**：不绕弯（"别停！杀退他们，才好收拾调理！"）。
- **不是冷血**：他催人前进，但战后主动叫丁进一起抬伤兵（"这人还有气。来，抬一把。"）。
- **他的逻辑是军人的逻辑**：在箭雨中停下来抬人，两个人都会死——这句话他不需要解释，玩家会懂。

**外观描述：**
| 项 | 描述 |
|---|---|
| 体型 | 瘦高，腿长，走路带冲劲 |
| 面部 | 长脸、眉浓、颧骨突出；**下巴一道旧疤**（做成静态几何 + 贴图，不依赖面部骨——**二级模型不追加面部骨**，只有主角级才加 12 根） |
| 服装 | 短襦扎进腰带，袖子挽到肘 |
| 甲 | 札甲（胸背），无盆领 |
| 兵器 | 环首刀 |
| 手 | 抬梯时手掌压在梯梁上，指节发白 |

**模型规格：** 6,000 面。

**声音：** **嗓子偏哑**（长期喊话），语速快、停顿短。音色比丁进更糙更急，两人同处一个低音区但可区分（口音设定同 §5.1 纪律，不指认方言）。

---

### 2.8 带队兵 —— 三级模型（不具名）

**身份：** 丁进段的局部指挥，负责"底脚放这儿""趁他们分开，把梯立起来"。

**性格：**
- **只给局部命令**：他从不说全局（"四面并攻"是传令兵喊的，不是他）。
- **用动作代替解释**：在墙下空地招手标出终点。
- **不解释，不鼓励**：他的台词全部是祈使句。

**外观描述：**
| 项 | 描述 |
|---|---|
| 体型 | 中等，站姿稳（长期站队列） |
| 面部 | 方脸、法令纹深、几乎不带表情 |
| 甲 | 札甲 + 一条**褪色的红绦**斜挂胸前（队职标识） |
| 兵器 | 环首刀（不拔） |

**模型规格：** 4,000 面（三级，只在中近距离出现）。

**声音：** 中低音，咬字清楚、不带情绪。**他的声音功能是"可辨认的坐标"**，不是角色。

## 三、家庭三人（记忆片段）

> 出现在第一章 C1-02，约 40 秒，**只给手、竹条、衣角、腿，不给人脸**（见剧情设计 §4.1 镜头纪律）。但为保证人物质感真实，仍需完整建型。

| 人物 | 年龄 | 外观要点 | 预算 |
|---|---|---|---|

## 五、说话方式与台词纪律

### 5.1 三代口音的分层

| 层 | 人物 | 口音处理 | 目的 |
|---|---|---|---|
| 吴县乡音 | 陈安、吴成、赵平、陈安家人 | 现代苏州话作参考，写少量易懂乡音词（覅＝不要、实梗＝这样、姆妈＝妈妈），字幕给普通话 | 让"家"有具体的声音 |
| 丹阳设定 | 丁进、徐直 | **不指认方言语系**：两人同处一个低音区，靠音高、语速、哑度与陈安段的吴语区拉开区分；史实上 214 年口音不可复原，此设定标 `[F]` | 让丁进段与陈安段在听觉上区分 |
| 普通话底子 | 伍长、带队兵 | 咬字清楚、无乡音 | 军令必须一次听懂 |

**陈安家中三句必须由苏州话母语者核音**，这是一条硬要求（现代苏州话不能当 214 年发音复原，只是配音参考）。

### 5.2 台词五条纪律

1. **短。** 战场上一句话超过 12 个字就要拆。
2. **只说眼下。** 没人谈论战局、家乡、未来。
3. **关心靠动作。** 吴成全篇没有一句"小心"，只有"贴这边"。
4. **不解释典故。** 典故在札记里，不在嘴里。
5. **不喊口号。** "先登之功""四面并攻"由**传令兵**喊（**传令呐喊这种做法有时代依据，但这一句台词是本作虚构**），不由角色抒情。

### 5.3 语气样本（原创，非史料引文）

> **陈安（战场，问）**：「哪儿卡住了？」
> **赵平（答得很快）**：「右轮压住牵绳，前头又有木料。我抬车，你抽绳。」
> **陈安（愣了一下）**：「……怎么抽？」
> **吴成（不耐烦）**：「看轮子。别光拉绳。」

> **吴成（前夜，嫌）**：「行縢松了。腿伸过来，拖着要绊的。」
> **陈安**：「我自己会系。」
> **吴成（已经蹲下去）**：「那就系紧。」

> **丁进（箭雨中，停住）**：「他还活着！」
> **徐直（回头吼）**：「别停！」
> **丁进**：「总得把他抬走……」
> **徐直（声音压低，更狠）**：「箭还落着，怎么抬？」

## 七、历史人物的呈现边界

### 7.1 甘宁

- **史载：** 「后从攻皖，为升城督。宁手持练，身缘城，为吏士先，卒破获朱光。计功，吕蒙为最。宁次之，拜折冲将军。」（《甘宁传》`[A]`）
- **本作处理：** 只做**远景剪影 + 旗号 + 传令兵喊"甘宁督攻在前"**。不做近景、不做可交互、不做特写。

**剪影级外观（3,000 面，只求轮廓可辨）——以下身高、站位、甲色都是本作设定 `[F]`，不是史载。**

| 项 | 描述 |
|---|---|
| 体型 | 高壮，比普通兵高半头（约 1.85 m） |
| 甲 | 精甲（鱼鳞甲 + 披膊），亮度略高于伍长的札甲 |
| 首服 | 武弁；**不加红缨**（那是明清形制） |
| 辨识手段 | **没有辨识手段**——66 m 外一个人形约 24 px，身高差 7 cm、甲色深浅都分辨不出。**这个剪影不承担"认出甘宁"的功能**，只表示"这面墙有人在最前面攀城"；玩家不通过看他确认身份 |
| 动作 | 攀城姿态循环（贴墙、单手扶城），不做交互 |
| 位置 | `(-30, -157)`，**S3 段**墙下，距玩家梯位约 66 m，65° FOV 下约 24 px |

**为什么不画"练"：** 原文只写「手持练」，它的形制、颜色、系结方式全无记载。画一条帛带，玩家会以为那是绳梯或攀爬工具——等于用画面给史料补了一个它没有的细节。剪影只交代"有人先攀上去了"这一个事实。

- **不能做：** 不能设计"与甘宁并肩作战"；不能把"练"做成铁链或梯具；**不能把他后来在濡须的百余健儿夜劫曹营安到皖城头上**——该事见《甘宁传》裴注引《江表传》（**出处已核：卷 55 原文页，「寧乃選手下健兒百餘人，徑詣曹公營下」确在裴注内**），但**系年有矛盾**：传序把它排在攻皖之后、建安二十年合肥之前，而「曹公出濡須」通常系于建安十八年（213）或二十二年（217），**早于或晚于 214**。本作只用它证明"甘宁是敢打的人"，**不写具体年份、不搬进皖城**

### 7.2 吕蒙

- **史载：** 「蒙以精锐继之」「蒙手执枹鼓」（《吕蒙传》`[A]`）
- **本作处理：** **只有声音（鼓）**，不做可见模型。
- **理由：** 一旦玩家看见"吕蒙在击鼓"，就会想去找他/保护他；而前线小兵在混乱中本就未必能认出主将。声音足够完成"士气与时机"的表达。

### 7.3 朱光、董和、张辽

- **只出现在战后消息与战史卡里**，不做模型。
- 「获庐江太守朱光及参军董和，男女数万口」`[A]`（**"参军董和"记载待核**，与 10 号 §2.1 同口径）——"口"是人口计数，不得表现为杀敌数或屠城。
- 张辽「至夹石，闻城已拔，乃退」`[A]`——**不在城下交战**。

## 八、建模优先级

| 优先级 | 内容 | 理由 |
|---|---|---|
| P0 | 陈安、丁进、吴成、赵平（4 套一级） | 有近景特写、有死亡演出、有情绪镜头 |
| P1 | 徐直、伍长（2 套二级） | 有台词、有互动，但少特写 |
| P1 | 家庭三人（3 套低配） | **必做**——C1-02 是固定 40 秒演出、上游 D-010 固定开场顺序，砍了就断开场；只可弃面部细节 |
| P2 | 推车兵（**二级，6,000 面**）、带队兵（**三级，4,000 面**） | 功能性强，镜头近但时间短 |
| P3 | 通用兵 #1 / 守军 #2 / 别面假人 | 量大，靠实例化与 LOD 撑 |

> 本表是**建模优先级**，与 12 号 §13.0 的施工裁剪线（P0–P3）不是同一套编号；家庭三人的“必做”与 12 号 §15.2 已对齐。

**面数总账：** 八套角色模型 **54,000 面**（4×8,000 + 3×6,000 + 1×4,000）+ 家庭三人 3,600 + 甘宁剪影 3,000 + 吴成盾 3,000 + 通用兵 **177 个实例**（南面攻方 63 ＝ 71 − 8 名具名、守军 54、别面 60）。通用兵按 LOD 距离分档约 134,100 面（近景 30×2,000 + 中景 60×800 + 远景 87×300），**人物合计约 197,700 面**。总体预算与验收见 [建模与关卡规格](12-皖城建模与关卡规格.md) §12。
