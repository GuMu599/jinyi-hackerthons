# 锦衣黑客松 · 考据资料

这里是一场古代战争题材叙事游戏的背景资料。游戏的设定是：玩家扮演战场上的普通小兵，靠观察军旗、辨听鼓号判断局势，阵亡后不是重来，而是"魂穿"到另一名士兵身上继续，直到战争结束。

资料全部来自联网查证原文。**能核到出处的都标了出处；核不到的一律写"未找到可靠出处"，没有编造。**

如果你只有半小时，看这三个：
1. `docs/02-考据底本.md` —— 一页浓缩版，最重要的结论都在这
2. `docs/资料库/12-史实红线与自查表.md` —— 哪些说法是错的，别写成影视剧
3. `docs/资料库/11-创作素材包.md` —— 台词、器物、六个人物，能直接拿去用

## 资料纪律

1. **每条都标了来源等级**：〔正史〕〔兵书〕〔典章会典〕〔出土文献〕〔演义小说〕〔现代研究〕〔存疑推断〕。
2. **标了置信度**（高/中/低）和依据类型（直读原文 / 二手引述 / 推断）。
3. **找不到可靠出处的，写"未找到可靠出处"**，不补、不猜、不编书名。
4. **区分史实与演义**：比如"八阵配八卦"是唐代李筌的臆说、宋代《武经总要》已斥为"尽出臆度"；"失期，法皆斩"是《史记》的汉代叙述，与出土秦律冲突。

## 已知的问题

- 部分简牍律文的**简号未核**，引用时只能写篇名。
- **敦煌文书、黑水城文书**的军事内容一条都没核到，唐/西夏/元三段是空的。
- 有几个兵书（《纪效新书》《练兵实纪》《武经总要》）是写作者在线上直接读的，**原文没有落盘到 `.tmp_src`**，只在资料库里被引用。
- `.tmp_src` 里 7 个文件是消歧义页或重定向页，没有正文，列在上面了。
